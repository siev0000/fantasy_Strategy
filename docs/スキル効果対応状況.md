# スキル効果の対応状況

## 2026-10-13 確定: 部隊支援・部隊条件パッシブの記載

以下の書式を共通部隊パッシブへ接続済み。CS変換器は既存の対象/条件/効果と数値記法で解釈できる。正式クラス/CS原本登録は未完了で、同名正式行がない場合のみconfig/v39-expedition-defaults.jsonの試作クラス・スキルを使用する。

- `行動:P` とし、`効果`は処理の種類、`対象`は補正を受ける相手、`条件`は発動条件、数値項目は補正量に分ける。クラス名で効果を直接決めず、習得したスキルから処理する。
- `効果:部隊支援` は同じ部隊のメンバーへ能力補正を与える処理。
- `対象:他部隊員` は本人を除く部隊員、`対象:部隊全員` は本人を含む部隊員、`対象:自身` はスキル所持者。
- `条件:部隊クラス_名前` は指定クラスを持つ部隊員がいる条件。`条件:部隊種族_名前` は指定種族を持つ部隊員がいる条件。条件の存在確認には本人も含める。
- `条件:部隊統治者` は `isSovereign` が真の部隊員がいる条件。「王」を架空のクラス名として検索しない。
- 対象・条件とも、同じ所属部隊・同じワールドの生存者だけを参照する。死亡・離脱・世界変更で条件が外れれば解除する。
- 同じスキルの複数所持者からの支援は重複させない。異なるスキルの補正は加算する。再描画・ロード・再計算による恒久加算をしない。
- 未対応の条件・対象を無条件の自身強化へ置き換えない。通常の無条件パッシブと部隊補正で同じ数値を二重適用しない。

| 用途 | 詳細欄の記載例（`行動=P`） |
|---|---|
| コマンダーの部隊支援 | `効果:部隊支援 対象:他部隊員 攻撃+5 防御+5 命中+5` |
| 本人を含む部隊支援 | `効果:部隊支援 対象:部隊全員 防御+5` |
| 特定クラス同伴時の自身強化 | `対象:自身 条件:部隊クラス_ナイト 攻撃+10` |
| 特定種族同伴時の自身強化 | `対象:自身 条件:部隊種族_エルフ 魔力+10` |
| 王の騎士の自身強化 | `対象:自身 条件:部隊統治者 攻撃+10 防御+10 精神+10` |

例の数値は現行の仮補正または書式説明用で、全スキルの正式バランス確定を意味しない。複数条件のAND/OR書式や、同名スキルに異なる補正値がある場合の選択規則は別途確定する。同名スキルは正式テーブルのユニーク行を使う。CS原本の編集・スキル一覧再生成は `SPREADSHEET_DATA_WORKFLOW.md` に従う。

確認日: 2026-10-11。データ登録と効果の実行は別に確認する。効果列の未対応部分があっても、威力・回復・能力補正などの数値部分だけは動く場合がある。

### パッシブの共通適用ルール（2026-10-11）

- `行動=P` の習得済みスキルを対象に、能力・技能・耐性・身体武器値・行動数値の同じ分類処理で加減算する。同名スキルは重複加算しない。
- `条件 / 条件系統 / 攻撃手段` がない能力・技能・耐性・身体武器値は、種族/クラスからの再生成時に常時加算する。身体武器値は既存の値÷10のLv換算に従う。
- 条件付き数値は共通条件判定を通す。現在の対応条件は地形名、技名、攻撃手段、系統/属性、HP割合、既存のガード時（反撃）判定。複数条件があれば全条件を満たす必要がある。
- 無条件の行動補正（威力/回復/ガード/AP等）は行動計算時に加算する。射程は既存の武器・スキル補正との合算経路を使用する。
- `威力 / 全威力` の補正は元の威力へ加算し、補正値だけで元威力を上書きしない。元の技に全威力がある場合も属性の加算分を失わない。
- 常時能力へ適用したスキル名を保持し、戦闘計算時に同じ能力補正を再加算しない。元データからの再生成で値を確定するため、画面更新で補正が蓄積しない。
- `魔防→精神`、`移動速度→移動`、共通技能定義の別名を使用する。それ以外の意味不明な列名は推測して別項目へ変換しない。
- 地形だけを条件にした能力/技能/耐性は現在地の補正として能力画面と実計算に反映する。地形名は通常地形/特殊地形/溶岩の現在有効な地形から取得し、周囲の同地形に隣接しているだけでは適用しない。前回の現在地補正を戻してから再評価し、加算を蓄積させない。
- 行動条件付き能力は通常の能力画面へ常時加算しない。技の威力/射程等の行動表示と戦闘計算は共通の補正処理を使う。隣接等の未対応条件を通常能力表示へ反映済みとは扱わない。
- `scripts/check-v39-passive-base.mjs` と `scripts/check-v39-passive-skills.mjs` でPC1100px/スマホ390pxを確認する。全パッシブの専用効果が完成したことを意味しない。シート管理JSONの追加列・直接変更は行っていない。
