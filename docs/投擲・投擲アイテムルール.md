# 投擲・投擲アイテムルール

更新: 2026-10-13

この文書は、通常武器の投擲可否、投擲用消耗品、将来追加予定クラス「スローイングマスター」の方向性を整理する。
現行実装へ未反映の内容を含むため、実装済み仕様とは区別する。

## 1. 通常武器の投擲

### 確定方針

- 通常の装備武器は、原則としてそのまま投擲できない。
- 通常武器を投擲するには、投擲を許可する特殊技能・特殊効果・付与効果が必要とする。
- 武器に「戻る武器」の魔法・効果が付与されている場合、その武器を投擲可能とする。
- 「戻る武器」で投擲した武器は攻撃後に使用者へ戻るものとし、装備解除、地面への配置、個別の回収処理を行わない。
- 既存の装備データにある `投擲補正` は、それ単独では通常武器の投擲を解禁しない。投擲可能になった武器の命中・威力などを補正する特性として扱う方向とする。具体的な補正内容は別途確定する。
- 肉体武器など、物理的に投擲できない装備をどこまで対象外とするかは実装時に整理する。

## 2. 投擲用アイテム

### 確定方針

- 通常キャラクターが特殊な投擲技能・効果を持たない場合でも、投擲専用の消耗品は使用できる。
- 投擲用アイテムは通常武器とは別の「消耗品アイテム」として管理する。
- 投擲用アイテムは武器と同様にランクを持ち、ランクによって威力・命中・特殊効果などの性能が変化する。
- 投擲用アイテムは使用時に所持数を1消費する。
- 煙玉は投擲用消耗品として採用し、指定地点へ投げて通常の霧を発生させる方向とする。範囲・持続ターン・ランク別性能は未確定。
- 爆弾、投擲短剣、投槍、投斧などの追加種類は候補とし、個別採用は別途確定する。

## 3. 投擲用アイテムの回収

### 検討中

- 使用した投擲用アイテムのうち、破壊されず残る種類については、一部を戦闘後に回収できる仕組みを検討する。
- 候補として、使用地点や対象地点を「調査」した際に一定数または一定確率で回収できる方式を検討する。
- 別ユニットが先に調査した場合、そのユニット側が拾得できる方式も候補とする。
- 煙玉や爆弾など使用時に破壊・消費される種類は回収不可とする方向。
- 回収率、残留期間、敵AIによる拾得、地面アイテムとして個別座標を保持するかは未確定。
- 投擲のためだけに武器1個ごとの落下座標・回収AIを大規模実装しないことを優先し、既存の調査・残留品処理を再利用できる形を検討する。

## 4. 将来追加予定クラス: スローイングマスター

> このクラスは後で追加予定のクラス案であり、現時点のクラスデータへは追加しない。実装済みクラスとして扱わない。

### クラス方向性

- クラス名は「スローイングマスター」。
- 投擲を専門とし、通常では投げられない装備武器を投擲攻撃へ転用できる上位の投擲系クラスとする。
- クラス固有効果として `戻る武器` を持つ方向とし、装備している通常武器を投擲可能にする。
- `戻る武器` によって投擲した武器は攻撃後に使用者へ戻り、武器を消費しない。
- 対象武器の範囲、盾や大型武器を含めるか、肉体武器を除外するかはクラス実装時に確定する。

### 将来追加予定の専用技

- `回転投げ`
  - 武器を回転させて投擲する技能。
  - 切断を強化する方向とする。
  - 切断の加算値・倍率・元武器が切断を持たない場合の扱いは未確定。

- `湾曲投げ`
  - 軌道を曲げて武器を投擲する技能。
  - 複数対象を巻き込む範囲攻撃とする方向。
  - 範囲形状、対象数、連鎖方式、威力減衰の有無は未確定。

## 5. 実装状態

- 通常武器を特殊効果によって投擲可能にする共通処理は未実装。
- `戻る武器` の魔法・付与効果は未実装。
- 煙玉の携帯数・1個消費は共通道具処理で実装済み。ランク・回収は未実装。
- 煙玉は対象選択→説明→実行で射程内1マスに通常霧を設置する。暫定AP20/射程10（地上1・洞窟2マス）/持続3T、消費1、回収不可。道具シートで数値を管理。
- スローイングマスター、回転投げ、湾曲投げは将来追加予定であり、現時点では未実装・クラスデータ未登録。
