# モンスター上位系統・多部位クラスルール

最終更新: 2026-10-16

## 1. 目的

動物・魔獣・幻獣系モンスターを個別専用クラスだらけにせず、既存の基礎種族・属性進化・身体進化を再利用して表現する。

この資料では、上位系統クラスと多部位クラスの確定方針を定義する。

## 2. 上位動物系統

### 2.1 基本構造

動物・魔獣系は、必要に応じて次の要素を組み合わせて表現する。

1. 基礎種族
   - 例: ウルフ / タイガー / ホーク / スネーク など
2. 属性進化クラス
   - 例: フレイムアニマル / フロストアニマル / ウィンドアニマル / スパークアニマル / ポイズンアニマル / シーアニマル / ストーンアニマル / ソルアニマル / ムーンアニマル
3. 身体進化クラス
   - 例: エヴォリューション・ファング / エヴォリューション・クロー / エヴォリューション・ホーン / エヴォリューション・アーマー / エヴォリューション・ウィング / エヴォリューション・テイル
4. 上位系統クラス
   - 幻獣
   - 神獣
   - 凶獣
   - 妖獣
5. 必要な個体だけ固有スキル

### 2.2 幻獣を親系統とする

- `幻獣` は、通常動物を超えた伝説・神話級の獣をまとめる上位系統とする。
- `神獣 / 凶獣 / 妖獣` は、幻獣系の性質をさらに分ける上位系統として必要に応じて重ねる。
- 個体名ごとの専用クラスを原則として作らない。
- フェンリル、ケルベロス、グリフォン、マンティコア、キメラ、スフィンクス、バジリスク、ハイドラ、フェニックス、ユニコーン等は、基礎種族・属性進化・身体進化・上位系統・固有スキルの組み合わせで表現することを基本とする。
- 白虎、朱雀、青龍、玄武、麒麟、白沢、応龍等は、必要に応じて `幻獣 + 神獣` のように上位系統を重ねて表現する。
- 饕餮、窮奇、檮杌、混沌等は、必要に応じて `幻獣 + 凶獣` とする。
- 九尾狐、鵺、鬼車、相柳等は、必要に応じて `幻獣 + 妖獣` とする。

### 2.3 専用クラスを作る基準

- 個体らしさが固有スキル1個程度で表現できる場合は、個体専用クラスを作らない。
- 個体固有の成長体系、複数の専用能力、独自のステータス成長、専用派生先などを持たせる必要がある場合だけ、専用クラスを検討する。
- 既存クラスで表現できる身体構造・属性・系統は、新しい個体専用クラスへ重複定義しない。

## 3. 多部位クラス

### 3.1 マルチヘッド

- `マルチヘッド` は、複数の頭部を持つことによって、頭部を使用する攻撃の攻撃回数を増やす身体構造クラスとする。
- 頭部攻撃が複数回になる代わりに、1回あたりの威力は低下する。
- ケルベロス、ハイドラ、相柳、鬼車等の複数頭部は、個体専用の「三頭攻撃」「九頭攻撃」等を大量に作らず、原則としてこのクラスで表現する。

### 3.2 マルチアーム

- `マルチアーム` は、複数の腕を持つことによって、腕を使用する攻撃の攻撃回数を増やす身体構造クラスとする。
- 腕攻撃が複数回になる代わりに、1回あたりの威力は低下する。
- 武器、拳、爪など、どの攻撃を「腕を使用する攻撃」と判定するかは、実装時にスキル側の部位情報と合わせて確定する。

## 4. 強化攻撃スキルとの組み合わせ

- `マルチヘッド / マルチアーム` によって複数回攻撃となる場合、強化攻撃スキルの威力上昇量を各ヒットへそのまま付与しない。
- 強化攻撃スキルが持つ威力上昇量は、実際の攻撃回数で分割して各ヒットへ配分する。
- 例: 威力上昇 `+30` の強化攻撃が3回攻撃になる場合、上昇量の合計は `+30` のままとし、各ヒットへ分割する。
- これにより、多部位クラスと強化攻撃スキルの組み合わせが攻撃回数ぶん乗算されることを防ぐ。

## 5. 未確定事項

以下はまだ確定していないため、この資料では数値を固定しない。

- マルチヘッド / マルチアームごとの実際の攻撃回数
- 攻撃回数に応じた1ヒットあたりの基本威力減衰率
- 威力上昇量が割り切れない場合の端数処理
- 頭部・腕部に属する攻撃手段をデータ上でどう指定するか
- 複数対象へ攻撃回数を振り分けられるか
- 多部位攻撃に対する命中判定、状態異常判定、ガード等の処理単位
- `幻獣 / 神獣 / 凶獣 / 妖獣 / マルチヘッド / マルチアーム` の具体的なステータス補正・Tier・取得スキル・取得条件
