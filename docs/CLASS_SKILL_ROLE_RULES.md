# クラス別スキル役割ルール

最終更新: 2026-10-06

この文書は、`docs/CHARACTER_STATUS_RULES.md` のクラススキル配置ルールを補足し、各上位クラスの役割差を定義する。
一般的なスキル数・Lv10必須・属性武器クラスの共通配置は `docs/CHARACTER_STATUS_RULES.md` を正本とし、この文書では個別クラスの役割だけを扱う。
スキル名・数値・取得Lvの編集原本は `@game_data` の `CS` / `クラス` シートとする。

## 1. 魔術系

### アークウィザード

- Tier2の純粋な上位魔法職。
- 特定属性へ固定せず、複数属性の攻撃魔法を広く取得する。
- 現在のCS構成は `落下火球 / 氷柱の拡散 / 落雷 / 腐蝕の雨 / 塵旋風 / 水晶槍 / 魔力増幅`。

### キャストマスター

- Tier2の詠唱・発動効率特化職。
- 魔法そのものの種類を増やすより、魔力強化・魔法陣・強化解除など、発動を安定させる補助能力を優先する。
- AP軽減など、現在の効果処理で未確認の独自記法は追加しない。
- 現在のCS構成は `魔力強化 / 魔法陣 / 呪文杖 / 強化破り / 魔力増幅 / 高速詠唱`。

### ワイズマン

- Tier3の賢者型魔法職。
- 魔力・精神・魔術・看破などの恒常強化を重視し、パッシブ比率を高める。
- 現在のCS構成は `魔法陣 / 魔力強化 / 賢者の知識 / 魔法無効化 / 魔力増幅 / 大賢者`。

### ワードキャスター

- Tier3の言霊系魔法職。
- 言葉による強化・拘束・沈黙・吹き飛ばしなどを扱う。
- 基本判定は `精神` を使用する。
- 現在のCS構成は `言霊・命 / 言霊・縛 / 言霊・黙 / 言霊・退 / 言霊の極意 / 力の言葉`。

### ディストラクター

- Tier3の力場系破壊魔術職。
- 力場ダメージ、体幹崩し、拘束、偏向などを扱う。
- 現在のCS構成は `場断裂 / 偏向膜 / 衝圧 / 拘束界 / 分解 / 圧壊掌`。

### ディザスター

- Tier4の力場系最上位職。
- ディストラクターの上位として、高位力場魔法と力場そのものの強化を扱う。
- 現在のCS構成は `分解 / 圧縮界 / 圧壊掌 / 衝圧 / 偏向膜 / 力場支配`。

## 2. 信仰系

### テンプラー

- 防御系の聖騎士。
- 盾・庇護・ガード能力を主軸にし、信仰魔法は防御補助として少量取得する。
- 現在のCS構成は `信仰の盾 / 盾構え / 信仰の聖域 / 完全防御 / 奇跡の護り / 聖堂の守護者`。

### エクソシスト

- 悪・霊・呪いへの対抗を担う祓魔職。
- 沈黙、看破、光、精神防御、強化解除を重視する。
- 現在のCS構成は `沈黙 / 正しき天秤 / 光線 / 信仰の魂 / 強化破り / 祓魔`。

### ピュリファイア

- 治癒・状態異常解除に特化する浄化職。
- 毒・麻痺・呪いの解除、回復、蘇生を主軸とする。
- 現在のCS構成は `毒治癒 / 麻痺治癒 / 回復術 / 洗浄 / 大回復術 / 真の蘇生`。

### インクイジター

- デバフ・看破・弱体化を担う審問職。
- 敵の魔法・強化を封じ、呪い・疲労・精神攻撃などで弱体化させる。
- 現在のCS構成は `沈黙 / 叱責 / 弱体化 / 正しき天秤 / 強化破り / 罪の烙印`。

### ジャッジメント

- 光・裁きによる攻撃特化の信仰職。
- 光属性攻撃と神聖武器を中心に、最終的に強力な裁き攻撃へつなげる。
- 現在のCS構成は `焼け付く光 / 光柱 / 神聖武器 / 光の奔流 / 正しき天秤 / 神罰`。

### ハイクレリック

- 既存構成を維持し、Lv10には `信仰の聖域` を配置する。

## 3. パラディン系

### 共通方針

- パラディン系は純粋な信仰魔法職にはせず、物理戦闘を主軸とする。
- 信仰要素は、武器への光属性付与、光追加攻撃、ガード、庇護、耐性などを少量混ぜる形にする。
- 攻撃型は物理攻撃を主軸に光を追加し、防御型はガード・庇護を主軸に光を防御補助へ使う。
- 基本パラディンのLv10は `聖騎士の心得` とし、攻撃・防御・光耐性を少量伸ばす完成パッシブとする。

### ホーリーブレイド

- Tier2の攻撃型パラディン上位。
- 武器物理攻撃を主軸に、光属性を追加する。
- 現在のCS構成は `光の武器 / 光刃撃 / 武器の攻め / 反撃 / 一閃撃 / 聖断`。
- Lv10 `聖断` は `光の武器` が有効なことを条件とする完成攻撃。

### クルセイダー

- Tier3の攻撃・防御バランス型。
- ホーリーブレイドから物理攻撃を強化しつつ、信仰の護りなどの防御補助も取得する。
- 現在のCS構成は `聖戦撃 / 聖戦士 / 反撃 / 信仰の護り / 十字斬 / 十字聖撃`。

### ホーリーナイト

- Tier2の防御型パラディン上位。
- ガード、反撃、信仰の盾、庇護を主軸とする。
- 現在のCS構成は `守る者 / 反撃 / 信仰の盾 / 聖騎士の守り / 信仰の護り / 聖盾`。

### ホワイトガード

- Tier3のガード特化職。
- ホーリーナイトの上位として、自身だけでなく味方全体を守る能力を強める。
- 現在のCS構成は `真なる護り手 / 盾の扱い / 完全防御 / 奇跡の護り / 白き守護 / 白銀要塞`。

### ダーク系クラスの反転ルール

- `ダーク〇〇` は元クラスと別の戦闘役割へ作り替えず、元クラスの役割・物理部分・ガード部分などを維持した反転版として扱う。
- 基本的な反転対象は `光 → 闇`。スキル名・演出も対応する闇側へ置き換える。
- 物理攻撃、ガード、反撃、回復など、光属性そのものではない要素は原則そのまま維持する。
- `回復 → ダメージ`、`蘇生 → 即死` のような機械的な意味反転は行わない。明示的に別仕様を決めた場合だけ個別変更する。
- 光側のクラス構成を先に完成させ、それを基準にダーク版を作る。
- 現在のダークパラディンは攻撃型パラディンの闇反転として、`闇の武器 / 闇刃撃 / 武器の攻め / 反撃 / 一閃撃 / 闇断` を持つ。
- 将来 `ダーククレリック` なども同じルールで追加予定。正式なクラス行・Tier・取得条件は追加時に確定する。

## 4. ドルイド系

### 共通段階

- ドルイド系は `ドルイド → 各環境ドルイド → 各メイカー → プライモーディアル` の4段階を基本とする。
- Tier1 `ドルイド` は自然の恵みを利用する段階。環境能力として `自然の実` を持ち、マップ上に木の実資源を1つ生成する方針とする。これは仕様確定済みだが、現時点ではCS未反映。
- Tier2の各環境ドルイドは、それぞれの対応地形・環境で `隠密` と `索敵` のボーナスを得る。加えて対応する耐性、魔力上昇、対応魔法を取得する。
- Tier2は各クラスにつき1つ、戦闘魔法とは別にマップや天候へ作用する環境魔法を持つ。
- Tier3の各メイカーは環境生成をさらに強化し、生成時間短縮と対応環境の資源生成を担当する。
- 森系の基準例は、フォレストドルイドが1マスを6Tで森へ変化させ、フォレストメイカーが2Tで森を生成し、森に対応する資源も生成できる形とする。
- アクア系は地形生成だけに限定せず、`霧 → 雨 → 大雨 → 嵐` のような天候操作を主要な環境能力として扱ってよい。

### 環境系統

- アース: 山岳・大地系。
- フォレスト: 森。
- アクア: 水辺・水・天候。
- デザート: 砂漠。
- フロスト: 雪原・寒冷環境。
- ヴォルカニック: 火山・火山性環境。

### プライモーディアル

- Tier4のドルイド系共通最上位職。
- 名前の意味は「原初のもの / 原初の自然」で、個別の環境を扱う段階を越えて、広い範囲の自然環境へ影響する役割を持つ。
- 各メイカーLv10のいずれかから取得する想定。ただし `クラス` シートのOR条件記法は未確定のため、`条件クラス` に独自記法を固定せず `詳細` に条件を記録する。
- 現在のCS構成は `広大な森 / 地形変動 / 大津波 / 砂界 / 極渦 / 大噴火 / 原初の理`。
- 既存の同名環境魔法は既存の先頭定義を再利用し、プライモーディアル用に別定義を重複作成しない。
- Lv10 `原初の理` は完成パッシブで、`魔力+20 隠密+20 索敵+20`。
- 広域環境改変の具体的な対象範囲、複数マスの地形変更方法、資源生成量などは個別効果の実装時に確定する。現在の既存同名スキルの効果を、役割定義だけを理由に勝手に置き換えない。

## 5. エクスキューショナー / 断罪者（追加予定）

- 現時点では追加予定クラスで、`クラス` シートへの正式追加はまだ行わない。
- 役割案は `インクイジター` と `アサシン` の複合。
- 戦闘スタイルは隠密・急所攻撃を利用するが、クラスの存在理由は暗殺ではなく「断罪・処刑」とする。
- 系統は現時点では `信仰系` を第一候補とする。
- 想定役割は、罪印・断罪などのデバフを付与し、その状態を条件とする高威力の処刑攻撃。
- Tier、正式な取得条件、武器制限、Lv10完成技の数値は未確定。確定前に `クラス` シートへ固定値を入れない。
