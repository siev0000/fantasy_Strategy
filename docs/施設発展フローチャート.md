# 施設発展フローチャート

更新: 2026-10-21 / UI58。施設シートの前提・優先度を村の建設候補へ接続。拠点昇格・領土拡張・自動交易は未接続。

## 原本と編集

原本は @game_data「施設」BR1:BU37。36施設へ施設ID・前提施設ID・建設目的・自動建設優先度を設定した。費用・工期・研究Lv・建設上限・地形は既存列を使用する。生成済み施設.jsonは直接編集しない。

前提施設IDは / 区切りのAND条件。空欄は開始点。拠点規模（村/町/都市/大都市）の前提はその段階以上とする設計。通常施設は同じ拠点内の完成施設で満たす。複数施設を同じマスへ置く意味ではない。改築元や研究条件とは別の条件として扱う。

自動建設優先度は仮の基礎点で、100が上限という仕様ではない。食料不足・脅威・死亡などの緊急度、領土の地形適性、周辺からの調達可能性を加味して候補を選ぶ。すべての枝を全村へ強制しない。

## 基本経路

- 村 → 市場・倉庫 → 町 → 学校 → 都市 → 公衆浴場等を整備 → 大都市。
- 初期目標: 村 → 墓地 → 食料生産。標準は農場、水辺では船着き場なども候補。施設を仮配置した収入差を比較し、住民種族の生産技能と地形を共通収入式で反映する。
- 生産: 木材不足なら森の伐採場、石材等の不足なら採石場/鉱山を増産効果から優先する。適した土地の確保と輸送が必要。
- 防衛: 村 → 兵舎/見張り塔/防壁、兵舎 → 射撃場、町+防壁 → 城壁、都市+兵舎 → 司令部。
- 信仰: 村 → 墓地 → 教会 → 修道院/神殿 → 大聖堂。霊廟は墓地+神殿。
- 魔術: 学校 → 魔導塔 → 鍛冶場と合わせて魔術工房 → 結界装置/魔獣研究所/魂の保管庫へ分岐。
- 医療: 村 → 調薬所 → 魔術工房と合わせて霊薬工房。
- 物流: 村 → 船着き場、町+船着き場 → 港。港/鉱山/温泉は全村の共通必須条件にしない。

## 接続状況

村の施設候補は施設シートのID/前提/目的/基礎優先度を読み、通常の地形・研究・施設枠・費用・工期で建設する。初期は墓地を目指し、その後に実際の食料増産が見込める施設を選ぶ。候補地ごとの増産差に種族の得意技能が含まれる。建設資材不足は既存物資支援へ、周辺の脅威は既存討伐支援へ接続する。プレイヤーの手動建設条件へ新列を強制する変更ではない。

墓地/安全/備蓄/守備の4項目は情報表示用の節目として保持する。実行する施設計画は同じplanSchedule.active/同じ建設キューだけを使う。緊急の食料支援・守備補充・討伐は並行して判断する。施設による生産補正と水域採取を村の実収入へ接続した。

適地・研究・施設枠が足りなければ既存の阻害理由を表示し、不正な場所へ建設しない。1施設あたり1棟を候補とし、拠点規模の昇格・土地の自動獲得・自動交易・不足技能を補う施設研究は後続作業。交易や拡張で解決したと見なす処理は入れていない。
