# ChatGPTからの相談・タスク候補

[ChatGPT向けの仕様目次・運用メモ](../CHATGPT_GUIDE.md) / [Codexの統合タスク](../ALL_TASKS_UNIFIED.md)

ChatGPTでの相談、改善案、Codexへの調査・実装依頼の候補をここに置く。追加前にこのページと統合タスクを確認し、同じ案件があれば該当項目を更新する。

- **相談中** — 目的、選択肢、未決事項を記録する。
- **引き渡し待ち** — ユーザーが承認した範囲と、確認できれば完了とする条件を記録する。
- **引き渡し済み** — Codex側のタスクまたは Issue へのリンクを付ける。以後の進捗はそちらで追う。

## タスク候補

### 追記用テンプレート

```markdown
### タスク名

- 状態　相談中
- 対象・現状　画面名や機能名と、困っていること
- 要望　どう変えたいか
- 参照　仕様メモのファイル・節、既存タスクやIssue
- 未決・確認条件　決めたいこと、採用後に確認する動作
- 引き渡し先　引き渡し済みになったらリンクを追加
```
