### スライム系スキル再設計（2026-11-24）

- 状態：相談中。以下は会話で合意した設計方針と現時点の配置案。シート・コードへの反映は未実施。Codexへの実装引き渡しはまだ行わない。
- 対象・現状：スライム、ポイズンスライム、ラヴァスライム、クリスタルスライム、アイススライム等。既存の粘液体当たり・粘液拘束等のスキル構成は仮のものとして再設計する。2026-11-24に確認した編集原本の5種はTier1。種類別の採用スキルは未決定。
- 基本方針：攻撃手段は素手または肉体を基本とする。複数の持続型Aスキルを使い、解除まで肉体特性とステータスを変化させる。強化と引き換えに別の能力が低下する構成を中心とする。
- スキル枠の確保を目的にTier1（Lv1〜10）、Tier2（Lv11〜20）、Tier3（Lv21〜30）へ分ける。各Tierの設計上の10枠はA7・P3を目安とする。ユニット種別ごとの実習得枠はクラススキル構成ルールに従う。
- 段階強化は触手Ⅰ〜Ⅲのみ。他のスキルは独立した能力として扱う。上位Tierでは単純な数値強化でなく選択肢を増やす。同じ横行のスキルは同系統・近い用途とし、Lv1/11/21等の対応する習得位置を想定する。ただし具体的なSkill1〜Skill10への配置は後で決める。
- 独立した消化スキルは作らず、空いた枠には感覚拡張を採用する。捕食は後述の食事効果を基本とする。

#### 圧縮・膨張（2026-11-24・設計合意、未実装）

- 自身のSIZを操作する持続型Aスキル。圧縮はTier2、膨張はTier2の現行配置表を維持する（直近の説明で膨張をTier3とした箇所は配置表と不一致のため、配置変更は行わない）。
- 膨張のSIZ補正は固定値+50と割合+50%の両方（ユーザー指定）。記法案：`対象:自身 効果時間:持続 SIZ+50 SIZ+50%`。同一項目の固定値・割合の併用記法、変換器の重複キー処理、計算順序は実装前に確認する。
- 圧縮はSIZ-50%を暫定値とする。個別の防御・回避等の追加補正は設けず、既存のSIZ補正による能力変動に任せる。判定・追加威力なし。
- 解除時は本来のSIZへ戻す。分裂・融合で管理する肉体量を増減させない。圧縮と膨張は排他、他の持続変形との併用は可能とする方針。
- 持続中のSIZ変動から派生能力を再計算する実行経路、HP比率維持、最低SIZ、重複適用防止、消費AP/HP・維持費は要確認。シート・コードへの反映は未実施。

#### 分裂の仕様（2026-11-24・設計合意、未実装）

分裂は召喚と区別し、元の肉体を分配する専用処理とする。自発的な分裂（A）と切断被弾による強制分裂（P想定）は同じ分裂処理を利用する。

| 項目 | 自発的な分裂 | 強制分裂 |
| --- | --- | --- |
| 分裂後の総個体数（本体を含む） | 2〜7体から選択 | 2体固定 |
| HP配分 | プレイヤーが個体ごとに自由入力 | ダメージ適用後の残HPを均等配分 |
| SIZ | 配分HPに連動 | 配分HPに連動 |
| AP消費 | あり | なし |
| 配置 | 元のマスに本体を残し、周囲の空きマスを選ぶ | 元のマスに本体を残し、隣接空きマスへ自動配置 |
| 再分裂 | 可能 | 可能 |

- 分裂後の全個体のHPが1以上、SIZが10以上になることを条件とする。必要な空きマスがなければ分裂しない。1回の自発分裂の最大7体は六角形マップの本体1体＋隣接6体を根拠とする。
- 分裂系統全体の総個体数に固定上限は設けない。HP・SIZ・空きマスを自然な制約とする。
- 切断被弾時は通常のダメージを適用し、生存して分裂条件を満たす場合のみ強制分裂する。致死ダメージを無効化しない。発動閾値（最大HPの20%は検討例）は未確定。
- HP・SIZ・肉体の総量を分裂によって水増ししない。現在HPの分配に応じて最大HP・SIZを分配する方向で、正確な計算基準・端数処理・自然回復やSIZ補正との関係は未確定。
- 新規効果記法の候補：A `対象:自身 効果:分裂`、P `効果:分裂_被ダメージ_切断`。威力系数値を持たないため判定・追加威力は設定しない。用語辞書・変換器・ランタイムへの登録は未実施。
- 実装設計の残件：Lv維持方式を候補とし、能力・技能・スキル・AP・CT・経験値・持続効果・装備・所持品の継承、軍隊の扱い、死亡・報酬、融合との整合、発動タイミングと連続分裂、配置失敗時の原子性を決める。AP・装備・報酬等の複製を防止する。
- 既存の召喚のユニット生成・隣接マス検査を再利用できるか確認する。現行のSIZ補正だけではHP分配にならないため、分裂後の肉体割合を保存・再計算する専用処理が必要。参照：[召喚・呼集ルール](../rules/units/召喚・呼集ルール.md)、[キャラ成長・ステータス決定ルール](../rules/units/CHARACTER_STATUS_RULES.md)、[モンスター合体ルール](../rules/units/モンスター合体ルール.md)。

- 未決・確認条件：具体的な威力・能力補正・AP/HP消費・維持費・射程・範囲・CT・判定・追加威力・各習得Lv・パッシブ・種類別構成。変形系で威力を計算する場合の追加威力は変装技能を候補とするが、固定能力補正のみのスキルには判定・追加威力を設定しない。光線の参照能力と魔法扱い・詠唱の有無は別途決定する。
- 実装確認事項：持続変形の同時維持、同系統の段階の排他、素手限定の攻撃回数・属性威力補正、複数補正の重複・デメリット処理、移動不可と探知強化、捕食・分裂・融合等。現行の持続強化は同じ補正の最大値を適用し、維持費は発動消費の半分（切り上げ）を支払う仕様。新規効果の実装済み扱いは禁止。
- 参照：[クラススキル構成ルール](../CLASS_SKILL_RULES.md)、[スプレッドシート更新手順](../SPREADSHEET_DATA_WORKFLOW.md) のスキル設計・威力参照の共通原則、[戦闘ダメージ・耐性ルール](../rules/units/戦闘ダメージ・耐性ルール.md)、[スキル効果対応状況](../rules/units/スキル効果対応状況.md)、編集原本 `@game_data` のCS・クラス・用語辞書。

### 捕食・食事カウンターの共通化（2026-11-24）

- 状態：設計方針・検討案。未実装。スライム系スキル再設計から派生した共通機能のタスク。
- ユーザー指定：捕食はスライム専用ではなく他種族も習得可能とする。捕食で敵を倒した場合はそのまま食事扱いとし、対応する食料を消費しない。
- 食事カウンター方式を採用する方向。ユニットごとの食事残量を保持し、捕食撃破時に加算する。記法案は `食事+1`、捕食の撃破時適用と組み合わせる場合は `効果:捕食 食事+1`。正式記法・用語辞書・変換器・ランタイム接続は未確認・未実施。
- 基本動作案：初期値0、食事残量1につき本人の1ターン分の維持食料消費を免除。ターン終了時に1以上なら1消費して食料を支払わず、0なら通常の維持処理。余剰分は次ターン以降に持ち越す。維持判定で食事と食料を二重消費しない。最大蓄積数、軍隊や複数種食料の扱い、飢餓解除、捕食可能対象、死体・戦利品、分裂・融合時の残量分配は未決定。
- 捕食による直接のHP回復・SIZ増加や取り込み拘束・継続消化ダメージは必須としない。以前の取り込み・消化案に代えて撃破時の食事効果を基本とする。

#### 将来案：食事蓄積を条件とするスキル

- ユーザー指定：食事カウンターの蓄積数を満たすことで発動可能になるスキルも用意できるようにする。**今回のスライム系スキル構成には追加しない。** 他種族・将来のスキル向けの検討事項とする。
- 例（仮）：食事残量3以上なら特定のAスキルを使用可能。発動条件として参照するだけの方式と、発動時に食事残量を消費する方式を区別できる設計を検討する。閾値、消費数、正式記法、残量を参照するか累計食事数を別管理するかは未確定。現段階で新しい具体スキルや数値を確定しない。
- 実装検討：共通の発動可否判定と実行直前の再検査、消費時の原子性、UI表示、AI、保存復元、維持食料判定と発動条件の整合、撃破時の重複加算防止。
- 参照：[人口成長・食料不足ルール](../rules/economy/人口成長・食料不足ルール.md)、[スキル効果対応状況](../rules/units/スキル効果対応状況.md)、[スプレッドシート更新手順](../SPREADSHEET_DATA_WORKFLOW.md)。
