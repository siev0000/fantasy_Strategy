#### 分裂の仕様（2026-11-24・設計合意、未実装）

分裂は召喚と区別し、元の肉体を分配する専用処理とする。自発的な分裂（A）と切断被弾による強制分裂（P想定）は同じ分裂処理を利用する。

| 項目 | 自発的な分裂 | 強制分裂 |
| --- | --- | --- |
| 分裂後の総個体数（本体を含む） | 2体（新規1体） | 2体固定 |
| HP配分 | プレイヤーが個体ごとに自由入力 | ダメージ適用後の残HPを均等配分 |
| SIZ | 配分HPに連動 | 配分HPに連動 |
| AP消費 | あり | なし |
| 配置 | 元のマスに本体を残し、周囲の空きマスを選ぶ | 元のマスに本体を残し、隣接空きマスへ自動配置 |
| 再分裂 | 可能 | 可能 |

- 分裂後の全個体のHPが1以上、SIZが10以上になることを条件とする。必要な空きマスがなければ分裂しない。通常分裂の新規生成は1体とする（旧最大7体案を撤回）。巨大粘体系の多重分裂は最大2体、大量分裂は最大4体を生成する。いずれも本体を除いた生成数であり、隣接空きマスへの配置とする。上限以内で生成数を選択可能。
- 分裂系統全体の総個体数に固定上限は設けない。HP・SIZ・空きマスを自然な制約とする。
- 切断被弾時は通常のダメージを適用し、生存して分裂条件を満たす場合のみ強制分裂する。致死ダメージを無効化しない。発動閾値（最大HPの20%は検討例）は未確定。
- HP・SIZ・肉体の総量を分裂によって水増ししない。現在HPの分配に応じて最大HP・SIZを分配する方向で、正確な計算基準・端数処理・自然回復やSIZ補正との関係は未確定。

- 基本動作案：初期値0、食事残量1につき本人の1ターン分の維持食料消費を免除。ターン終了時に1以上なら1消費して食料を支払わず、0なら通常の維持処理。余剰分は次ターン以降に持ち越す。維持判定で食事と食料を二重消費しない。最大蓄積数、軍隊や複数種食料の扱い、飢餓解除、捕食可能対象、死体・戦利品、分裂・融合時の残量分配は未決定。
- 捕食による直接のHP回復・SIZ増加や取り込み拘束・継続消化ダメージは必須としない。以前の取り込み・消化案に代えて撃破時の食事効果を基本とする。

- ユーザー指定：食事カウンターの蓄積数を満たすことで発動可能になるスキルも用意できるようにする。**今回のスライム系スキル構成には追加しない。** 他種族・将来のスキル向けの検討事項とする。

#### 共通カウンターの実装

- Pの `条件系統`・`攻撃手段` に一致した本人の行動に対し、行動成立ごとに加算できる。撃破時の加算は敵1体ごと。Aは必要残量と消費量を別々に指定できる。記法は [スプレッドシート更新手順](../SPREADSHEET_DATA_WORKFLOW.md) を参照。
- 戦闘用の残量は、攻撃した・されたターンを除いて本人のターン終了を数え、既定5回で消える。「管理 → ゲーム設定」で保持ターンを変更できる。残量と期限はセーブに保存し、「スキル」の「発動中のスキル」欄と、既存の「強化・保護」欄の両方で確認する。「強化・保護」には残量が正のカウンターを `名前カウンター / 個数 / 残りnT`（期限なしの場合は `期限なし`）として表示し、同じ `skillCounters` と保持ターン設定を参照する。食事カウンターは期限なし。捕食スキルの原本登録と維持食料への自動充当は保留。
- 「スキル動作確認」の人族・戦士で、検証・3連撃を3回成立させると検証・集中撃を使える。集中撃は3消費する。

- UI確定：既存ヘッダー中央の「エフェクト設定」を切替可能にし、「エフェクト設定／魔法一覧」を選択。魔法一覧モードは系統と魔法の選択欄を1行に横並び。系統を選択すると該当系統の魔法だけを候補にする。魔法欄を押したときだけポップアップのリストを表示し、選択後に閉じる。リスト内および選択欄に個別設定済みのチェックマーク、未設定の印を表示する。系統別の設定済み件数／全件数も表示する。リストを常時表示したり、別の大きなパネルでプレビューを圧迫しない。既存「基本／色／動き／保存」・再生・コマ送り・実マップ確認は再利用する。
