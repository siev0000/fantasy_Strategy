# ユニット耐性ルール

最終更新: 2026-10-15

## 確定ルール

- ユニットの耐性値は、総合Lv・種族Lv・クラスLvでは変化しない。
- 基礎耐性は、ユニットが持っている種族と全保有クラスの耐性値をそのまま加算する。
- 第2クラスを持っている場合は、第2クラスの耐性値も加算する。
- Lvアップ・Lvダウン時に耐性値へ倍率や成長量を掛けない。
- 装備による耐性補正は、上記の基礎耐性とは別に加算する。

```text
基礎耐性 = 種族の耐性 + メインクラスの耐性 + 第2クラス等の保有クラス耐性
最終耐性 = 基礎耐性 + 装備耐性補正
```

## 実装上の扱い

- 基礎耐性は `unit.baseResistances` に保持する。
- 装備補正を反映した値は `unit.resistances` に保持する。
- `frontend/src/composables/unitStatusUtils.js` の `buildUnitResistances` は、種族行1件と保有クラス行の配列を受け取り、各耐性列を単純加算する。
- `frontend/src/components/PhaserMapGeneratorPanel.vue` では、ユニット生成、Lv再計算、第2クラス付与、自動装備後の再計算で同じ耐性計算を使う。

## 戦闘ダメージ式との区別

この文書は「ユニットが持つ耐性値の決定方法」を定める。戦闘時に耐性値をどう使ってダメージを軽減するかは `docs/戦闘ダメージ・耐性ルール.md` を別仕様として扱う。
