# キャラ成長・ステータス決定ルール（実装メモ）

最終更新: 2026-03-05  
対象: `frontend/src/components/PhaserMapGeneratorPanel.vue` / `frontend/src/composables/unitStatusUtils.js`

## 1. 目的

- `技能`（数値）と `取得スキル`（名称リスト）を明確に分離する。
- レベルアップ時の種族/クラス成長ルールを固定し、仕様ブレを防ぐ。

## 2. 用語

- 総合Lv: ユニットの `level`。現行EXP実装の上限は `Lv120`。
- 種族Lv: 種族成長に使う内部レベル。
- クラスLv: クラス成長に使う内部レベル。
- 初期種族ボーナスLv: `5` 固定。計算には加算するが、内部Lv表示には含めない。
- 技能: `指揮/威圧/看破...` の数値系パラメータ。
- 取得スキル: `Skill1..Skill10`（または `スキル1..スキル10`）から得るスキル名。

## 3. レベル成長ルール

- 内部Lvの初期値は `種族Lv0 / クラスLv0` として扱う。
- ただしステータス/技能の計算時は、常に `種族Lv+5` として計算する。

## 3.1 非人族（人族以外）
- 総合Lvに応じて、種族LvとクラスLvを交互に上げる。
- ルール:
  - Lv1: 種族Lv+1
  - Lv2: クラスLv+1
  - Lv3: 種族Lv+1
  - Lv4: クラスLv+1
  - ...（以後交互）

例:
- 総合Lv5 -> 種族Lv3 / クラスLv2
- 総合Lv10 -> 種族Lv5 / クラスLv5

## 3.2 人族

- 種族Lvは上げない（常に0）。
- 総合LvぶんクラスLvだけ上げる。

例:
- 総合Lv5 -> 種族Lv0 / クラスLv5
- 総合Lv10 -> 種族Lv0 / クラスLv10

## 3.3 人族の第2クラス

- 総合Lv10以上で第2クラス選択可能。
- 第2クラスはメインクラスと同名は不可。
- 現在実装の取得量:
  - 第2クラスLvは `1` 扱い（= 第2クラスの `Skill1` を取得対象に含める）。
- 総合Lvが10未満に下がった場合は第2クラスを解除する。

## 3.4 経験値とLvアップ

- 次Lvまでの必要EXPは種族カテゴリごとに次の式を使う。
  - 人族: Lv15未満 `175 + Lv×50`、Lv15以上 `150 + Lv×80`
  - 亜人: Lv15未満 `150 + Lv×50`、Lv15以上 `150 + Lv×80`
  - 魔族: Lv15未満 `100 + Lv×50`、Lv15以上 `200 + Lv×100`
- 戦闘EXPは撃破時だけではなく、敵対対象の実HPを削った割合で発生する。
- 対象1体を最大HP100%ぶん削った時の総EXPは `基準EXP × 対象Lv × 対象種族倍率`。
- 基準EXPと対象種族倍率はプレイ調整用の暫定値として `V39_UNIT_EXP_BALANCE` に集約する。現行値は基準EXP15、人族1.0、亜人1.25、魔族1.5、その他1.0。
- ガード吸収、Miss、オーバーキル分はEXP対象外。同じ対象を回復して削り直しても、1体から支払うEXPは最大HP100%ぶんを上限とする。
- 攻撃者が通常部隊に所属する場合、発生EXPはその部隊の生存メンバーへ均等分配する。単独枠は攻撃者1人が全量を受け取る。
- Lvアップ時は既存の派生計算を再実行し、種族Lv/クラスLv、能力値、技能、取得スキルを新Lvに合わせて更新する。現在HPは最大HPに対する割合を維持する。
- 蘇生によるLv低下時は、低下後Lvの開始EXPへ合わせる。

## 4. ステータス計算ルール

対象ステータス: `HP / 攻撃 / 防御 / 魔力 / 精神 / 速度 / 命中`  
`SIZ` は別計算。

## 4.1 成長ベクトル

- 種族行の各ステータス値を `10` で割って四捨五入し、1レベル成長量にする。
- クラス行も同様に1レベル成長量を作る。

## 4.2 最終ステータス

- 最終値 = `種族成長量 × (初期種族ボーナスLv5 + 種族Lv)` + `クラス成長量 × クラスLv`
- 内部Lv表示は `種族Lv` のみ（初期ボーナス5は表示しない）。
- `SIZ` は:
  - 種族行の `SIZ` を優先
  - なければクラス行の `SIZ`
  - どちらもなければ `100`

## 4.3 フィールド移動値

- フィールド移動値は `速度` を基礎に、`SIZ` 補正と移動系の身体特性補正を順に適用して算出する。
- 算出順は `基礎速度 → SIZ補正 → 移動系身体特性補正 → 移動値` とする。
- SIZ補正はオートマン側 `siev0000/game-project` の既存ルールを踏襲する。
  - `SIZ >= 180`: `補正率 = round(SIZ / 50 + 8)`
  - `SIZ <= 150`: `補正率 = -round((160 - SIZ) / 3)`
  - `151 <= SIZ <= 179`: `補正率 = 0`
  - 速度への反映は `補正後速度 = 基礎速度 / (1 + 補正率 / 100)` とする。大型ほど低下し、小型ほど上昇する。
- 種族・動物の身体構造は `クラス.json` の `脚数` を参照する。脚数0はそのまま「脚なし」として扱い、基礎移動値10（1マス相当）になる。脚数未設定の旧データだけ互換用に2脚扱いとする。
- 基礎移動値は `10 + 脚数 × 5`。したがって脚0=10、脚1=15、脚2=20、脚4=30となる。
- 速度補正は `SIZ補正後速度 / 10` を移動値へ加算する。速度は100で上限を設けず、500以上でも同じ式で伸びる。
- 最終移動値は `round(10 + 脚数×5 + SIZ補正後速度/10 + その他移動補正)` とする。その他移動補正は現時点0で、羽・騎乗などの具体値は別途調整する。
- 固定 `movement` 値は正本として使わず、速度・SIZ・脚数から派生計算する。
- マップ尺度は `移動値10 = 1マス相当`。
- 共通AP100を基準に、平地1マスの基礎消費APは `1000 / 移動値`。10刻み以外の値も切り捨てずAP効率へ反映する。
- 地形・登坂ペナルティには技能 `早業` を使用する。`地形.json` の移動コスト1/2/3/4を100%/150%/200%/250%へ換算し、上り高度差1ごとに+25ポイントを加える。早業1ポイントごとに0.5ポイント軽減し、`最終移動コスト率 = max(100%, 地形コスト率 + 登坂ペナルティ - 早業×0.5%)` とする。早業は100を上限とせず、少数値から連続的に効果を持つ。下り・同高度は高度由来の追加ペナルティなし。通行条件そのものは早業では無効化しない。

## 5. 技能と取得スキルの分離ルール

## 5.1 技能（数値）

- 表示対象: `指揮/威圧/看破/早業/技術/隠密/索敵/農業/林業/漁業/工業/統治/交渉/魔法技術/信仰`
- 技能値の上昇方式はステータスと同じにする。
- 計算式:
  - `最終技能値 = 種族技能成長量 × (初期種族ボーナスLv5 + 種族Lv) + クラス技能成長量 × クラスLv`
- ここは「数値パラメータ」であり、`Skill1..10`（取得スキル名）とは別扱い。

## 5.2 取得スキル（名称）

- 種族行は `種族Lv` ぶん、クラス行は `クラスLv` ぶん、`SkillN/スキルN` を順に取得。
- 人族で第2クラスありの場合は、第2クラスも `Lv1` 分を追加取得。
- 重複スキル名はユニーク化して1件にまとめる。

## 6. キャラ作成時の初期値（現状）

- 統治者: 総合Lv `5〜10` のランダム。
- モブ: 総合Lv `5` 固定。
- どちらも作成時点で本メモの成長ルールを適用して `status / 技能 / 取得スキル` を生成。
- 初期計算では `種族Lv5分` を加算するが、内部Lv表示は `種族Lv0` 扱いとする。

## 7. テスト運用

- テストON時のみ、自キャラ画面で手動レベル変更を許可。
- `Lv-1 / Lv+1` で再計算を即時反映。
- 人族かつLv10以上で第2クラス設定UIを表示して検証可能。

## 8. 実装確認チェックリスト

- `技能` 欄は数値のみ表示される。
- `技能` はステータスと同じ式で増減する。
- `取得スキル` 欄は `Skill1..N` ベースで増減する。
- 自キャラ表示画面（自キャラ一覧）で各キャラの `取得スキル` 要約が確認できる。
- 初期時点で `種族Lv5分` が計算に乗るが、表示上の内部Lvは `種族Lv0` のまま。
- 非人族Lvアップで種族Lv/クラスLvが交互に増える。
- 人族LvアップでクラスLvのみ増える。
- 人族Lv10で第2クラスが設定でき、取得スキルに反映される。
- Lvを10未満に下げると第2クラスが解除される。
- 部隊タブのユニットアイコン外周に現在LvのEXP進捗ゲージを表示し、一周するとLvアップして次Lvの進捗へ切り替わる。
- 戦闘EXPは実HP減少割合から算出され、通常部隊では生存メンバーへ分配、単独では本人へ全量加算される。
