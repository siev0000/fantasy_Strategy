# v39 マップ操作・描画仕様

> v39上側フィールドの操作・描画仕様の正本。既存実装から復旧する際はこの仕様を変更しない。

## 1. 対象

- v39上側 `.playfield` 内のPhaserフィールド
- マップ生成後のカメラ操作
- タイルの標高・深度による色補正

---

## 2. ズーム

以前の実装に存在する `createMapZoomController()` を基準とする。

### 正本メソッド

- `zoomIn()`
- `zoomOut()`
- `zoomReset()`
- `setZoomPercent(value, options)`

### 挙動

1. 拡大・縮小時は選択中タイルを優先してフォーカスする。
2. 選択中タイルが無い場合は自拠点 / village をフォーカス候補とする。
3. 最小ズーム以下にはしない。
4. 最小ズーム時はマップドラッグ不可とする既存ルールを維持する。
5. ズームステップは既存 `resolveZoomStepPercent()` を使用する。
6. `zoomReset()` は100%へ戻す。
7. PCのホイール、画面上の拡大/縮小操作、スマホのピンチは最終的に同じズーム状態へ接続する。
8. Phaser canvas外のUI操作でズームを発火させない。

### 現行v39 runtimeの状態

`frontend/src/v39-field-runtime.js` は現在 `fitCamera()` による初期フィットのみで、操作ズームは未接続。
これは既存仕様の欠落であり、復旧対象。

---

## 3. 標高によるタイル色補正

以前の実装の `heightLevelMap` と `shadeColorByHeight()` を基準とする。

### 陸地

- `heightLevelMap[y][x]` を参照する。
- 低地ほど明るく、高地ほど暗く表示する。
- 既存値:
  - `minLevel = -2`
  - `maxLevel = 8`
  - 明度係数は低地側 `1.18` から高地側 `0.74` まで線形補間する。
- 地形本来の色を基準にRGBへ明度係数を掛ける。
- 森＋丘陵/山岳など、既存の relief 判定を維持する。

### 海

- 海は陸地用 `shadeColorByHeight()` ではなく、既存 `shadeSeaColorByDepth()` を使用する。
- 深度による海色補正を維持する。

### 境界

- `heightLevelMap` の隣接差が大きい箇所に対する既存の高低差境界描画を維持する。
- UI変更のために標高情報を捨てない。

### 現行v39 runtimeの状態

現在の `drawTerrain()` は `terrainDefinitions` の地形色をそのまま塗っており、`heightLevelMap` を反映していない。
これは既存仕様の欠落であり、復旧対象。

---

## 4. 実装ルール

- マップ生成ロジックは `createTerrainMapData()` の既存データを使用する。
- ズームや標高描画のために新しい独自ルールを作らない。
- 以前の `mapZoomController.js` / `PhaserMapGeneratorPanel.vue` のルールを移植する。
- 固定HTML UIをマップ操作の初期化・再生成で破棄しない。
- マップ再生成時はPhaserフィールドだけを更新する。

## 5. 完了条件

- PCでマップを拡大・縮小できる。
- スマホでピンチズームできる。
- 必要な拡大/縮小UIが既存仕様どおり動く。
- ズーム後も選択位置 / 拠点フォーカス規則を維持する。
- 高い陸地ほど暗く、低い陸地ほど明るく見える。
- 海は深度に応じた既存色補正が反映される。
- マップを再生成しても固定UIが消えない。
