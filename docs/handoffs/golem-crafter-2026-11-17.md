# ゴーレムクラフター設計 引き継ぎ（2026-11-17）

## 決定事項
- ゴーレムクラフターは既存ゴーレムの装甲・関節・攻撃機構を改造するクラス。
- 四足型・多腕型・多脚型などの身体構造変更は**上位クラス**に分ける方針。名称・条件・数値は未決定。
- Lv1「装甲改造」は装甲値・防御・耐性・ステータスの変更。Lv5「関節駆動」は素手威力・命中・ガード・武器装備など。両者を混同しない。
- 世界観：魔法は世界に存在する現象の再現。魔力はエネルギーではなく個人が魔法を使用し世界へ干渉する権限。威力は現象をどれだけ強く維持できるかで変わり、魔法の炎は水中でも燃え得る。
- Notionの魔法根本原理への追記は**未承認・未反映**。ゴーレム設計を優先する。

## 検討案（**未確定**・シート未反映）
**Lv1 装甲改造**：重装甲（装甲+60/防御+30/速度-15）、軽量装甲（装甲-20/防御-10/速度+30）、属性耐性装甲（装甲+20/選択属性耐性+50）、反射装甲（装甲+10/被ダメージ20%反射）。

数値はアシスタント提案であり、ユーザーが承認した確定値ではない。上位クラス名「ゴーレムアーキテクト」「ゴーレムマスター」も仮案。四足・多腕・多脚・砲台・蛇体は候補にすぎない。
