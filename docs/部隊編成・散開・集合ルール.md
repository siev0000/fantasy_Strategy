# 部隊編成・散開・集合

更新: 2026-10-16。部隊の所属と、移動への参加状態を分離する。

## 編成できる場所

- 加入・移籍する場合、編成後の全メンバーが同じ自軍拠点の領土内＋外周2マスにいる必要がある。
- 洞窟や遠征中は、全員が隣接でつながっていれば現地編成できる。別マップ同士では編成しない。
- 除隊・解散・名称変更だけなら集合を要求しない。自動任務・荷物・人数の既存制限は維持する。
- 候補には所属と不可理由を別々に表示する。選択済みメンバーの解除は妨げない。
- `V39_SQUAD_MOVEMENT_BALANCE.assemblyBorderRadius` で周辺距離を調整する。

## 所属と移動

| 状態/操作 | 動作 |
| --- | --- |
| 追従 | 追従中の生存・同マップ・任務なしメンバーだけで部隊移動する |
| 単独行動 | 所属は維持し、そのキャラだけ移動する。他メンバーの移動を止めない |
| 全員散開 | 現在マップの操作可能メンバーを単独行動へ切替 |
| 集合 | 初期は移動先頭の周囲。地図指定で集合先を変更できる |
| 集合中止 | 未到着メンバーを単独行動へ戻す。到着済みの追従者は維持 |

「その場待機」は位置を固定する既存機能であり、単独行動とは別。集合指示はその場待機を解除するが、そのターンの行動終了（待機コマンド）は解除しない。

## 集合処理

- 新規編成・メンバー追加後は集合状態にする。所属変更だけでは瞬間移動しない。
- 指示時に残APで移動し、以後はそのプレイヤーのターン終了時に継続する。同一ターンの自動二重処理はしない。
- 既存の経路・地形・高低差・壁・味方通過・AP消費を使う。停止時は重ならない。
- 通常は指定地点と周囲1マス。召喚等で7体を超える場合は範囲を拡大し、最大半径は変数 `rallyMaximumRadius` で制限する。
- 到着したメンバーから追従へ戻す。未到着者のAP不足・距離・その場待機は追従者の移動を止めない。
- 追従者が移動したら未到着者の集合先も更新する。
- AP不足・通行不能・敵隣接・待機は理由を表示。攻撃・回復は既存ルールのまま可能。集合中に手動移動するとそのキャラは単独行動になる。
- 集合担当は未行動確認の対象から外す。所属・状態・集合先・進捗はセーブに保持し、地上と洞窟で共通処理する。

## UIと既存支援

- 部隊の詳細と自キャラの詳細に同じ「部隊操作」を表示。カードには単独行動/集合中を表示する。
- 右クリック/長押しの既存隊列メニューからも単独行動・散開・集合を実行できる。
- 散開・集合中のキャラを隊列交換で遠距離移動させない。追従へ戻してから交換する。
- 所属依存の支援スキルは従来どおり。距離による支援制限は今回新設しない。
- 呼集魔法は通常編制の距離制限の例外。対象自身の領土/同マップ/人数/任務/荷物等の既存条件は維持する。召喚・呼集で既存部隊へ入るユニットは術者の移動状態を引き継ぎ、他の部隊員の散開/集合状態は変更しない。単独の術者が新たに部隊を作る場合は追従で開始する。
