# マップ範囲・気候生成ルール

- 2026-10-20: 雪原の中央の❄地形マークを撤去。白い地形色で識別し、地形/効果/積雪白枠と右上の小さな降雪マークは維持する。旧セーブにも表示変更を適用する。

## 川・積雪の表示（2026-10-19）

- 川の帯の中に小さな流向矢印を描く。並び順が無方向の辺データをそのまま向きと解釈せず、河口/湖への接続から川のグラフ距離が減る向きを使用する。水域につながらない成分・距離が等しく向きを決定できない辺には矢印を出さない。旧セーブにも再計算で対応し、表示のための流向データは保存しない。判定元は `lib/v39-river-flow.js`、色/大きさは既存 `FIELD_TERRAIN_OVERLAY_STYLE.river`。

- 川は既存の六角境界の生成経路を維持し、マス幅18%の水色帯と片側2pxの濃青の縁で連続表示する。河口接続も同じ帯、滝は淡色を重ねる。地形画像・積雪より上で描画し、川の下に地形画像を重ねない。
- 積雪の白枠は不透明度0.85（15%透過）。少しだけ透かす意図に合わせ、逆に解釈していた0.15から訂正。枠の幅と降雪マークは変更しない。
- 調整先は `frontend/src/lib/phaser-map-panel-config.js` の `FIELD_TERRAIN_OVERLAY_STYLE`。生成・高度・水域判定・移動・資源計算・セーブ形式は変更しない。
- `scripts/check-v39-river-snow-display.mjs` が390/1100pxで実ピクセルの水色/縁/合流・積雪合成、更新/解除、経路の不変性、保存/ロードを検証する。

## 山岳の源流・荒野のまとまり（2026-10-19）

- 調整元は `config/v39-map-generation-features.json`。通常のマップ新規生成に適用し、旧セーブの地形や川を作り直さない。
- 連続する山岳/火山が7マス以上なら、その山岳帯に水域へ接続する源流を最低1か所確保する。既存の源流がある帯では追加せず、島全体の本数目標で漏れた帯を補完する。この最低保証は島の本数目標より優先。水域が存在しないマップには生成しない。
- 補完は高い山の候補から高度非増加の経路を優先する。閉じた盆地で水域へ出られない場合は、既存主河川と同様に水際距離を減らす迂回/突破を使用し、高度自体は書き換えない。対象の帯/源流/補完/盆地救済はriverData.mountainSourcesへ保存する。
- 荒野は砂漠の隣1列を変換する旧処理を廃止。気候の地形変換後、平地に核と厚みのある領域を生成する。核は隣接候補4以上、成長は領域へ2辺以上接する場所を優先し、細い通路だけの場所には生成しない。1回の領域は7〜28マス、目標は変換可能な平地の14%。乾いた場所をやや優先し、領域間隔も設ける。隣接領域がつながる場合もある。
- 森林・山岳・丘陵・雪原・砂漠・水域は荒野へ変更しない。勝利対象土地の保護領域と明示的な溶岩冷却跡は維持。wastelandGenerationに実配置数と領域の核/枚数を保存する。冷却した溶岩の線状跡は今回の通常荒野生成とは別。
- `scripts/check-v39-map-landforms.mjs` が無方向辺の反転/合流/非接続、荒野の核/最小規模/細道除外/保護、48〜100マス・4島形状の山岳源流と水域への実接続、流向表示・荒野・保存復元を検証する。

現行実装: 2026-10-19。地上ゲーム開始時のマップ設定に適用する。

## 範囲と形状

「描く範囲」と既存の島形状パターンは別設定。

| 範囲 | 気候 | 形状の制約 |
| --- | --- | --- |
| 全世界 | 中央の低緯度から上下の極地へ低温化 | 既存パターンを選択可能 |
| 一地域・周辺諸島 | 選択した気候帯と高度が基準。上下の気温差は小さい | 既存パターンを選択可能。周辺島の数は形状次第 |
| 単一島 | 選択した気候帯と高度が基準 | realistic / continent のみ。海で分断された小島を除去し、ラップ・島数カスタムを無効化 |

新規開始の既定は「一地域・周辺諸島 / 温暖 / 18℃ / 湿潤度55」。
全世界では気候帯・基準気温・湿潤度入力を無効化して自動設定する。

## 気候と地形

調整元は `config/v39-map-climate.json`。数値はバランス調整可能な暫定値。

| 気候帯 | 基準気温 | 湿潤度 | 森林量倍率 |
| --- | --- | --- | --- |
| 熱帯・多湿 | 28℃ | 75 | 1.4 |
| 高温・乾燥 | 30℃ | 20 | 0.35 |
| 温暖 | 18℃ | 55 | 1 |
| 冷涼 | 9℃ | 60 | 0.8 |
| 寒冷 | -8℃ | 45 | 0.25 |

- プリセット選択後も基準気温（-20〜35℃）と湿潤度（0〜100）を変更できる。
- 従来の島・高度・川・湖生成を使用し、最終段階で12×12地域の気候に地形を合わせる。全世界の緯度低下幅は40℃、一地域3℃、単一島2℃。高度と固定乱数による差も加わる。
- 地域の基準気温0℃以下では常設積雪対象とし、平地・荒野・砂漠は雪原へ変更。森林・山は形状を維持する。雪だけの閾値変更案（−3℃）は取り消し、全世界の気温分布を下記のとおり微調整する。
- 20℃以上かつ湿潤度45以下では平地・荒野を砂漠へ変更。それ以外の砂漠は平地へ戻す。
- 一地域・単一島の森林量は気候帯と指定湿潤度で補正する。
- 海・湖・河川・火山と勝利対象土地の保護領域は気候による塗替えから除外する。
- 新方式は地形から気候を再決定しない。地形塗替えで気候の乱数が変わらないよう高度・水面情報を使用する。

## 保存と互換性

- マップへ `mapScope` / `climateSettings` / `climateProfile` を保存。通常生成・ロビー設定・セーブ読込で共用する。
- 範囲設定のない旧マップや固定テストは旧方式を維持する。雪地形を含む地域の基準気温上限-3℃も旧方式に限って維持する。
- 気候プロファイルはv3。旧版は気候と現在天候を補完するが、保存済み地形を塗り替えない。
- 雪・吹雪の現在気温上限0℃、天候3〜5ターンの既存処理は維持する。
- 洞窟の生成・天候は対象外。季節、風向、積雪・融雪の毎ターン変化は未実装。

- 設定UI: `frontend/src/v39/map/v39-field-settings-final.js`

## 出現敵の気候・天候条件（2026-10-20）

- 原本「出現敵」AE:AGに最低気温/最高気温/出現しやすい天候を追加。数値は℃で上下限を含む。空欄は制限なし。77行に暫定設定を入れ、同シートのみ200件を再生成した。各ヘッダーの注記に単位・空欄・地下・倍率を記載。
- 最低/最高は地域の基準気温を使い、一時的な天候補正と分離する。普通の虫5〜45℃、爬虫類0〜45℃。氷系−40〜15℃、炎系15〜60℃、太陽系5〜50℃を優先設定。これらはシート側で変更可能。
- 出現しやすい天候はスラッシュ区切り。現在天候が一致すると抽選重み2倍、その他は1倍。倍率設定は config/v39-enemy-climate.json。出現率そのものが必ず2倍になる意味ではない。
- 通常敵・通常ボスと配下・初期位置の敵候補評価へ同じ気温フィルターを使用。基準気温で候補を絞ってからLv補正するので、ボス/序盤のLv不足による代替処理でも不適地の種族を復活させない。
- 洞窟は地上気候判定の対象外。気候なしの旧マップは従来の気候生成を使用し、明示的な地下では補正しない。天候変更時に既存個体を削除したり自動再抽選したりしない。新規生成分へ適用。
- ゲーム側の地域気候参照は生成処理ごとに1回構築し、地域単位で再利用。各マスで保存ワールド全体を取得しない。

## 雪範囲の微調整と特産品の気候条件（2026-10-20）

- 常設雪の閾値は config/v39-map-climate.json の snowTemperature=0℃。全世界のみpolarInsetRatio=0.02として、冷却に使う緯度から0.04を引く（下限0）。100×100では従来の気温境界を上下それぞれ約2マス極側へ寄せる微調整で、気温差は最大約1.6℃。冷却幅40℃・高度補正・乱数は維持し、中央、一地域型、単一島は変更しない。実表示は12×12の気候地域単位なので境界の見た目は段階的に変わる。新規生成に適用し、保存済み地形/気候は自動で塗り替えない。
- 原本「特産品」N:Qに最低気温/最高気温/最低湿潤度/最高湿潤度を追加。基準気温は℃、湿潤度は0〜100で上下限を含む。空欄は制限なし。現在の一時天候ではなく地域の基準値を使う。全20行のうち食料・薬草12行に暫定値を設定。
- バナナは18〜40℃かつ湿潤度55以上、オレンジは10〜35℃かつ35以上、リンゴは0〜28℃かつ30以上。キノコは−5〜30℃かつ50以上、薬草は0〜30℃かつ35以上。詳細値は原本で変更できる。
- 鉱石と特殊資源は今回は気候条件なしとし、素材確保の最低配置/広域補充を維持する。補充対象に気候条件を設定した場合も、その条件内の適正マスだけを使用し、無理に不足を埋めない。
- 地形/高度/予約地/溶岩の既存条件と組み合わせる。地下には地上気候を適用しない。保存済みの特産品を天候変化で消したり再抽選したりしない。
- 敵と特産品は共通 v39-climate-conditions.js で境界値と空欄を判定し、気候参照は地域単位で再利用する。採取周期・収量・特産品の保有マス数という扱いは変更なし。

## 連続する峡谷（2026-10-20）

- 調整元: config/v39-map-generation-features.json の canyons。マスごとの峡谷化18%抽選を廃止し、川沿いの高地・落差を起点に六角形で連続する道筋を選ぶ。
- 通常の中心線は4〜8マス。候補選択時12%で10〜15マスの大峡谷を試み、長さ不足なら通常規模へ戻す。10%は小さな1〜2マスを試みる。適地・分断回避で棄却するため最終比率は確率と一致しない。
- 前進方向を保ちながら曲がり、片側にだけ幅を加えて幅1〜2マス相当にする。既存峡谷の隣に別地域を生成しない。小マップでも同じ長さ条件だが、適地不足時は無理に生成しない。
- 起点は丘陵/山岳/火山の高度2以上、隣接落差2以上で川に接する場所。延長先は高度1以上かつ川の接触域から2マス以内。勝利土地の保護領域へ入れない。
- 高度を掘り下げず、地形の移動条件「飛行」は変更しない。通常徒歩の高度差1以内の陸地成分を生成前後で調べ、峡谷で新たに分断する案は棄却する。幅追加だけが分断する場合は幅を戻す。横断可能な浅瀬・橋を新設した仕様ではなく、既存陸地に迂回を残す方式。後の災害・施設等まで通行を保証するものではない。
- 峡谷を確定してから洞窟/沼地を生成し、峡谷を上書きしない。生成記録 canyonGeneration（中心線・占有マス・長さ・種別）と specialCounts を通常マップとセーブへ保持する。既存セーブは自動再生成しない。
