# マップ範囲・気候生成ルール

現行実装: 2026-10-19。地上ゲーム開始時のマップ設定に適用する。

## 範囲と形状

「描く範囲」と既存の島形状パターンは別設定。

| 範囲 | 気候 | 形状の制約 |
| --- | --- | --- |
| 全世界 | 中央の低緯度から上下の極地へ低温化 | 既存パターンを選択可能 |
| 一地域・周辺諸島 | 選択した気候帯と高度が基準。上下の気温差は小さい | 既存パターンを選択可能。周辺島の数は形状次第 |
| 単一島 | 選択した気候帯と高度が基準 | realistic / continent のみ。海で分断された小島を除去し、ラップ・島数カスタムを無効化 |

新規開始の既定は「一地域・周辺諸島 / 温暖 / 18℃ / 湿潤度55」。
全世界では気候帯・基準気温・湿潤度入力を無効化して自動設定する。

## 気候と地形

調整元は `config/v39-map-climate.json`。数値はバランス調整可能な暫定値。

| 気候帯 | 基準気温 | 湿潤度 | 森林量倍率 |
| --- | --- | --- | --- |
| 熱帯・多湿 | 28℃ | 75 | 1.4 |
| 高温・乾燥 | 30℃ | 20 | 0.35 |
| 温暖 | 18℃ | 55 | 1 |
| 冷涼 | 9℃ | 60 | 0.8 |
| 寒冷 | -8℃ | 45 | 0.25 |

- プリセット選択後も基準気温（-20〜35℃）と湿潤度（0〜100）を変更できる。
- 従来の島・高度・川・湖生成を使用し、最終段階で12×12地域の気候に地形を合わせる。全世界の緯度低下幅は40℃、一地域3℃、単一島2℃。高度と固定乱数による差も加わる。
- 地域の基準気温0℃以下では積雪対象とし、平地・荒野・砂漠は雪原へ変更。森林・山は形状を維持する。
- 20℃以上かつ湿潤度45以下では平地・荒野を砂漠へ変更。それ以外の砂漠は平地へ戻す。
- 一地域・単一島の森林量は気候帯と指定湿潤度で補正する。
- 海・湖・河川・火山と勝利対象土地の保護領域は気候による塗替えから除外する。
- 新方式は地形から気候を再決定しない。地形塗替えで気候の乱数が変わらないよう高度・水面情報を使用する。

## 保存と互換性

- マップへ `mapScope` / `climateSettings` / `climateProfile` を保存。通常生成・ロビー設定・セーブ読込で共用する。
- 範囲設定のない旧マップや固定テストは旧方式を維持する。雪地形を含む地域の基準気温上限-3℃も旧方式に限って維持する。
- 気候プロファイルはv3。旧版は気候と現在天候を補完するが、保存済み地形を塗り替えない。
- 雪・吹雪の現在気温上限0℃、天候3〜5ターンの既存処理は維持する。
- 洞窟の生成・天候は対象外。季節、風向、積雪・融雪の毎ターン変化は未実装。

## 実行経路と検証

- 設定UI: `frontend/src/v39/map/v39-field-settings-final.js`
- 正規化・地形補正: `frontend/src/lib/v39-map-scope.js`
- 生成: `frontend/src/lib/map-generator.js`
- 気候・天候: `frontend/src/lib/v39-weather.js`
- 実ランタイム/保存復元: `frontend/src/v39/map/v39-field-runtime-final.js`
- `node scripts/check-v39-map-scope.mjs`: 320/390/1100pxで入力・制約・生成・保存復元、単一島数、温暖/乾燥/寒冷、緯度差を確認する。ロビー設定の受渡しは確認するが、遠隔通信全体の試験ではない。
