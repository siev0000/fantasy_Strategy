# 一般村：種族別依頼イベント案

> 状態: 仮案。イベント内容・発生条件・友好度変化量・報酬量は未確定。
>
> 基本方針:
> - 一般村との関係値 / 友好度は全種族共通の1本の値を使う。
> - 種族差は「友好度の上げ方」「友好度で解放される行動」「最終的な支配方法」に持たせる。
> - 各種族について、まず5件ずつ依頼イベント候補を用意する。
> - 同じ依頼を全種族で名前だけ変えて使い回すのではなく、種族らしい解決手段を混ぜる。
> - ここに書くイベントは企画段階の仮案であり、実装時はデータ定義から追加できる構造を優先する。

## 人間 / ヒューマン
1. **街道の安全確保** — 村と交易路の間に出る盗賊・モンスターを排除する。
2. **不足物資の援助** — 食料・木材・石材など不足している物資を届ける。
3. **村人の救出** — 行方不明者、誘拐された村人、襲撃から逃げ遅れた住民を救出する。
4. **道路・設備の復旧** — 壊れた橋、道路、井戸などの復旧を支援する。
5. **村同士の仲裁** — 近隣村との争い、交易条件、土地利用問題などを仲裁する。

## 森人 / エルフ
1. **穢された森の浄化** — 村周辺の森に発生した汚染、呪い、異常植物などを除去する。
2. **精霊の鎮静** — 村人と精霊の衝突を解決し、暴走した精霊を鎮める。
3. **薬草の確保** — 希少な薬草や治療素材を集め、病人の治療を助ける。
4. **密猟者の排除** — 森を荒らす密猟者や乱獲者を追い払う。
5. **聖域の保護** — 古木、泉、森の祭壇などをモンスターや開発被害から守る。

## 土人 / ドワーフ
1. **崩落した坑道の救助** — 鉱山崩落で取り残された村人を救出する。
2. **鍛冶場の復旧** — 壊れた炉や鍛冶設備の修理に資材・技術を提供する。
3. **鉱脈の調査** — 周辺の山・洞窟を調査し、新しい鉱脈を探す。
4. **坑道の魔物退治** — 鉱山内部に入り込んだモンスターを排除する。
5. **不足工具の調達** — 採掘・鍛冶に必要な工具や金属資材を届ける。

## 獣人 / ビーストマン
1. **狩場を荒らす魔獣の討伐** — 村の狩場に居座る大型魔獣を排除する。
2. **群れの救出** — 家畜や村人の狩猟隊を襲撃者から救う。
3. **食料となる獲物の確保** — 肉などの食料を狩猟で確保し、村へ届ける。
4. **縄張り争いの解決** — 近隣の獣・他集団との縄張り争いを力や交渉で解決する。
5. **強者の証明** — 村が指定する強敵を倒し、力を示す。

## 竜人 / ドラゴニュート
1. **強大な魔物の討伐** — 村では対処できない大型モンスターを倒す。
2. **古代の竜遺物の回収** — 山岳・遺跡などから竜に関係する遺物を探して持ち帰る。
3. **山道の確保** — 落石、魔物、崩落などで塞がれた道を安全にする。
4. **貢物の護送** — 村の重要な貢物・交易品を目的地まで守る。
5. **決闘・試練の達成** — 村が認める戦士や怪物との試練を達成し、実力を示す。

## 大鬼 / オーガ
1. **大量の食料を届ける** — 村の食料不足を大規模な食料援助で解決する。
2. **怪力が必要な障害物の撤去** — 巨岩、倒木、瓦礫などを除去する。
3. **村を脅かす強敵の討伐** — 村の守備軍では倒せない敵を正面から撃破する。
4. **捕らわれた戦士の救出** — 村の戦士を敵勢力や魔物から奪還する。
5. **威圧による問題解決** — 盗賊、敵対集団、取り立て屋などを力を示して退かせる。

## 巨人 / ジャイアント
1. **崩れた地形の復旧** — 大規模な落石や土砂崩れを除去する。
2. **巨大建造物の修復** — 城壁、橋、大門など大型構造物の復旧を手伝う。
3. **大型魔獣の排除** — 村に近づいた巨獣を討伐する。
4. **石材の大量運搬** — 村の建築に必要な大量の石材を運搬する。
5. **巨石の設置** — 防壁・祭壇・目印などとして使う巨石を指定地点へ運ぶ。

## 鬼妖 / ゴブリン
1. **罠の設置** — 村周辺にモンスター・盗賊対策の罠を仕掛ける。
2. **盗まれた物資の奪還** — 奪われた食料・資材を追跡して取り返す。
3. **廃墟からの回収** — 危険な廃墟から使える道具・部品・資材を回収する。
4. **秘密の抜け道の確保** — 村から外へ抜ける安全な隠し道を探す・整備する。
5. **壊れた道具の応急修理** — 農具、罠、簡易装置などを手早く修理する。

## 悪魔 / デヴィル
1. **禁じられた願いを叶える** — 村人が通常の手段では解決できない願いに、悪魔の力で応える。
2. **復讐の契約** — 村が憎む盗賊・敵対者・怪物などを排除する代わりに契約を結ぶ。
3. **力を授ける** — 村の守備兵や代表者へ力を与え、脅威を退ける。
4. **生贄の契約** — 村が危機から救われる代価として、生贄や魂の提供を受け入れる契約を結ぶ。
5. **村全体との契約** — 高友好度時に村が悪魔勢力の保護と力を受け入れ、将来的な村ごとの吸収・直接支配へつながる。

## 天使 / エンジェル
1. **負傷者の治療** — 襲撃や病で傷ついた村人を治療する。
2. **呪い・穢れの浄化** — 村や周辺土地に残る呪い、瘴気、邪悪な影響を除去する。
3. **死者の魂を鎮める** — 村に留まる死者・幽霊・未練を浄化し、魂を安らかにする。
4. **村への加護** — 一定期間、村の防衛・回復・災害耐性などを高める加護を与える。
5. **聖域の再建** — 破壊された祠、祭壇、聖域などを復旧する。

## 吸血鬼 / ヴァンパイア
1. **夜間の護衛** — 夜に襲う魔物・盗賊から村を守る。
2. **血の契約** — 村へ保護を提供する代わりに、定期的な血の提供を受ける契約を結ぶ。
3. **死体の引き取り** — 村で発生した死者の遺体を引き取り、村側の問題処理と吸血鬼側の資源確保を両立する。
4. **墓地の怪異処理** — 墓地や地下墓所で発生したアンデッド・怪異を排除する。
5. **眷属による保護** — 高友好度時に村の一部住民へ力を与え、守備や夜間警戒を強化する。
