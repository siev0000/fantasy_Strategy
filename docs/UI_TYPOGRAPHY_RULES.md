# UI文字サイズの管理

調整元は `frontend/src/v39/ui/v39-typography.css` に統一する。

- `--pc-base-font`: PCの通常文字。初期値15px。
- `--mobile-base-font`: 幅699px以下の通常文字。初期値12px。
- `--font-body`: 選択された基準サイズに表示設定の倍率を掛けた通常文字。
- `--pc-min-font / --mobile-min-font`: 読ませる補助文字の下限。初期値PC11px／スマホ10px。8〜13相当の小文字へ適用し、表示設定倍率にも連動する。6・7相当の装飾専用文字は別扱い。
- `--font-secondary / --font-compact / --font-heading`: 補助文字・小ラベル・見出し。通常文字に対する比率で定義する。
- `--font-size-N`: 既存デザインを保つサイズ段階。PC基準15pxのときN相当になり、基準値・端末・設定倍率に連動する。装飾や大きな文字も同じ調整元を使う。

各画面・Vueコンポーネント・JSで生成するCSSでは、`font-size` にこれらの変数を使用する。固定pxや同じ計算式を再定義しない。非表示用の0、親を継承するem/rem、アイコン寸法から算出するバッジは別扱いとする。

共通CSSはHTMLのheadから読み込み、初回描画から適用する。旧 `v39-readable-fonts.js` の後付け上書きは廃止し、部隊・土地・行動の文字サイズ補正は描画元へ統合済み。文字サイズだけを修正するための追加styleや!importantを増やさない。既存レイアウト用の!importantは本整理の対象外。

Phaser/canvas上の地図ラベル・ダメージ数値のサイズはHTML文字とは別管理であり、この整理では変更しない。

確認: `node scripts/check-v39-test-turns-fonts.mjs`。PC/スマホ、設定120%、基準変数変更、後付けstyle不在、建設ターン進行を検証する。

部隊一覧のユニット名は1行表示とし、表示幅を超える場合のみ共通文字サイズに縮小率を掛ける。名前全文はtitleにも保持する。再描画・一覧幅変更・文字サイズ設定変更・フォント読み込み後に再測定し、幅に余裕ができたら通常サイズへ戻す。盾・障壁が並ぶ座標行も同様に1行へ収める。

通知履歴は専用の --font-log（補助文字下限の95%）を使う。通知だけ少し小さくするユーザー指定の例外で、PC/スマホ基準と設定倍率には連動する。新着ポップアップは --font-secondary を使う。

自キャラステータスの一覧は squadMemberList と共通の v39-unit-card.js を使い、squad-card/selected、Lvリング、座標、HP/AP、盾/障壁を同じ構造・共通スタイルで表示する。名前の縮小測定も共通。スマホのモーダルは一覧約40%/詳細残り幅の2列とし、能力/スキル/装備/成長タブを維持。重複した大きな名前見出しと独立した8pxゲージは使わない。検証は scripts/check-v39-character-squad-layout.mjs。

### 自動任務と座標目盛り（2026-10-12）

- 共通ユニットカードの2行目、座標の右に自動任務アイコンを表示する。鉱床輸送・拠点間輸送は🔁、入口警備は🛡、経路未設定・停止・通路閉塞は⚠。死亡者や任務なしのキャラには出さない。既存の選択枠線は変更しない。
- マップ下端に横座標X、右端に縦座標Yを小さく表示する。カードの座標と同じ0始まり。選択マスの番号は黄色。六角形の奇数行は半マスずれるため、横目盛りは選択行に合わせ、未選択時は偶数行基準にする。
- 拡大・スクロールへ追従し、縮小時は最小28px間隔で間引く。右下の拡大縮小ボタン付近は避ける。目盛りはクリックを遮らない。
- 管理→表示設定「マップの座標目盛り」でON/OFF。初期値ON、端末のlocalStorageへ保存。地上・洞窟で共通。ワールド切替・再生成で古い目盛りとイベントを破棄する。
- DOM目盛りの文字サイズは共通 `--font-compact`。カメラ/選択状態が変わった時だけ更新し、地形やFogを描き直さない。
- 検証: `scripts/check-v39-coordinate-ruler.mjs`。390/1100px、座標一致・拡大・選択行・設定保存・再生成・地下切替・任務アイコンを確認する。配布ビルド回帰にも含める。

### 自キャラ・部隊の共通詳細表示（2026-10-12）

- ステータス・技能・耐性は `frontend/src/v39/unit/v39-unit-detail.js` の `renderV39UnitAbility` を両画面で使う。表示名・順序・地形補正・技能のゼロ値除外を別々に実装しない。
- 見出し・タブ・折りたたみ・能力欄のCSSは `frontend/src/v39/unit/v39-unit-detail.css` に置き、`.squad-detail-pane` に共通適用する。モーダル側に能力欄のコピーや別の文字サイズ設定を追加しない。
- タブは同じ `renderV39DetailTabs` を使う。部隊画面の能力／行動と、自キャラ画面の能力／スキル／装備／成長という用途の違いは維持する。
- フィールドの既存IDは `fieldIds:true` の場合だけ付ける。モーダルに同名IDやフィールドの行動イベント属性を付けない。
- フィールドの再更新時は `updateV39UnitAbility` で変更のない描画を省き、閉じたセクションを保持する。
- `scripts/check-v39-character-squad-layout.mjs` で両画面の能力HTMLと文字サイズ・余白を比較し、320px／390px／1100pxで検証する。

### 共通スキル表示・自キャラ装備変更（2026-10-12）

- `v39-unit-skills.js` の `renderV39UnitSkills` と `v39-unit-skills.css` を部隊の行動欄と自キャラのスキルタブで共用する。取得スキル・身体／装備攻撃・テストスキル・パッシブの一覧、威力・AP・射程・説明の計算をコピーしない。
- 自キャラ画面のスキルカードは説明表示専用。クリックしても攻撃を開始せず、APを消費しない。フィールドの攻撃イベント属性は `interactive:true` の場合だけ付ける。
- 自キャラの装備タブは現在の装備のみを一覧表示する。部位を押すと選択モーダルを開き、候補と現在の装備を比較してから確定する。外す場合もモーダルで選択・比較・確定する。候補選択や取消では在庫・装備を変更しない。変更前の装備は在庫へ戻す。軍隊ユニットの固定装備・死亡者は変更不可。
- 地上は選択拠点の既存在庫変更処理を使用する。洞窟は所属部隊（単独・運搬担当は個別）の携帯在庫を使用し、装備性能を再計算する。処理は `v39-unit-equipment-access.js` にまとめる。
- `scripts/check-v39-character-skills-equipment.mjs` で共通スキル表示／CSS、閲覧によるAP非消費、地上・洞窟の装備解除／再装備、他キャラ／他プレイヤーのデータ維持を検証する。

- 装備比較モーダルは 39-equipment-picker.js/css にまとめる。装備性能・補正・特性／付与と、キャラクター能力の変化を表示する。スマホは候補一覧を上、比較を下に配置し、確定／取消ボタンを常時表示する。在庫や担当プレイヤー・拠点・ワールドが変わったら未確定の選択を破棄する。

- 装備モーダルは候補未選択・交換在庫なしでも現在の性能と特性／付与を表示する。変更後は未選択を表す記号で表示し、差分・能力変化の試算は候補選択後のみ行う。
