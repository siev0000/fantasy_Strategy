# 施設研究解禁の切替

2026-10-12: 必要研究Lvは削除しない。施設の資材・工期・土地・拠点段階の条件も維持する。

## 切替方法

`frontend/src/lib/v39-gameplay-balance.js` の `V39_RESEARCH_BALANCE.constructionUnlockMode` を変更し、再ビルドする。

- `level`（現在の既定値）: 従来の必要研究Lvによる建設条件。
- `item`: 必要研究Lvに加えて、指定した研究項目の完了が必要。複数指定時は全項目の完了が必要。

今回はゲーム内の表示設定ではなく、全勢力共通のルール切替とする。セーブの研究EXP・完了ID・施設を変更しない。切替は新たな建設の判定に適用し、建設済み/建設中の施設を取り消さない。

## 研究と施設の対応

対応関係は未確定。原本シート・生成JSONは今回変更せず、仮設定用 `config/v39-construction-research-defaults.json` に施設名→研究IDの配列を保持する。初期状態は空。
研究IDは `研究.json` の `ID` を使用する。名称や研究Lvから推測しない。
個別研究方式では、必要研究Lvがあるのに対応が空の施設は「解禁研究が未設定」として建設不可。必要研究Lvも指定研究もない施設は研究条件なし。
存在しない研究IDや未完了の研究を指定した場合は建設不可。研究画面に対象施設を表示し、建設画面に研究完了状態を表示する。

正式な対応が決まったら `@game_data` 原本へ列を追加して再生成し、仮設定からデータ参照へ移す。JSONだけに列を足さない。

調査カテゴリ統合・項目別前提研究は実装済み。現在研究Lvは同じカテゴリの完了項目最大Lv+1（実装済み段階を上限）に変更した。詳細は [研究フローチャートルール.md](./研究フローチャートルール.md)。施設の解禁方式切替・未設定対応の扱いは維持する。
