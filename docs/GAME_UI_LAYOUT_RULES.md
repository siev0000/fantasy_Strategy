# ゲーム操作UIの構成

更新: 2026-10-16。機能の有無だけではなく、判断と操作のしやすさを検証する。

## 共通契約

- 2026-10-21: 村の交渉は `negotiation_hub_fixed_layout.html` を基準に会話/クエスト/取引/情報の4タブへ整理。相手は上右、自分は下左、発言は反対側。元の資源ヘッダーと下端の閉じる/文脈別実行を固定し、4タブは本文の上端へ追従。交渉役・スキル・履歴は情報へ。村の取引は同じハブ内へ既存rendererをマウントし、新しい全面モーダルを重ねない。独立した国家間取引画面は維持する。参考HTMLの仮会話/相場や小さすぎる文字サイズは移植しない。

- 2026-10-18: 拠点はユニット画面と同じ左右分割。左は拠点名・段階・人口の縦一覧、右は選択拠点の名前と概況/生産/運用。左右は独立スクロールし、右ヘッダーとタブは固定。拠点切替で右タブを維持する。発展は概況、施設は生産、取引/物流は運用へ配置し、横拠点タブと常設操作列は廃止。入口は拠点の描画元で生成し、既存の発展/取引モーダル・物流画面へ接続する。

- 2026-10-18: 左の「物流」は交流と別タブ。任務一覧/詳細/設定モーダルを所有し、基本行動へ運搬の担当者/搬送先パネルを混在させない。入口警備は土地、物資ルートは物流、取引契約の変更は既存取引画面へ分担する。物流が開いている間だけ現在の計算済み経路と停止/待機をフィールドに表示する。詳細は `物流・運搬ルートルール.md`。

- 2026-10-17: フィールドの部隊詳細は「能力 / 基本 / スキル」の3タブ。基本は移動/待機/調査/採取/会話/休息/洞窟出入り・階層移動/道具使用・補充・製造/鉱床運用。スキルは武器・身体武器攻撃/習得スキル/魔法/パッシブ/召喚・呼集・合体。攻撃手段はスキルへ統一する。操作ロジック/AP/対象選択条件を複製せず、既存のイベント委譲の共通親 `detailTechniqueList` を使い、基本の描画先 `detailBasicList` と技能の描画先 `detailTechniqueRows` を分ける。内部タブキーはstatus/basic/action（actionはスキル）で、移動確認と現地操作への自動遷移だけbasicを選択する。ユニットを切り替えても表示タブは維持する。

- 2026-10-17: 自キャラステータスの表示名を「ユニット一覧」に統一。部隊タブは固定ヘッダーの件数付き部隊セレクト/新規部隊/編制変更から操作し、左側に選んだ部隊のメンバーだけを表示する。部隊一覧を縦に全展開しない。単独も選択でき、空の部隊は空表示。部隊選択と詳細タブは他タブから戻っても維持する。

- 2026-10-17: 自キャラの「キャラクター」一覧は活動中の生存者・施設格納生体・霊廟の保管遺体を同じ共通カードで表示する。一覧内の選択欄で「すべて / 活動中 / 施設内 / 霊廟」を件数付きで絞り込み、既存4タブは増やさない。保管先施設名/座標（地上以外は洞窟）をカードと詳細へ表示。保管中も能力/スキル/装備/成長を閲覧可能とし、編成/装備変更/道具設定/上位職取得は表示しない。死亡者一覧の霊廟表示も維持する。状態配列へ表示用データを再登録せず、閲覧用の合成一覧を作る。

- 共通ステータスはPC/スマホとも2列固定。「攻撃 / 防御」「魔力 / 精神」「命中 / 速度」「SIZ / APP」「移動 / 飛行」を表示する。飛行は技能値を参照するが技能欄では重複表示しない。フィールド・ユニット一覧・合成の共通描画へ適用する。

- 一覧で対象を選び、詳細で状態・効果・費用・条件を確認して実行する。内部IDや実装説明を主要情報にしない。
- 選択中は枠と背景と文字で示す。操作できない場合は理由を確認できるようにする。
- ヘッダーとタブは固定し、一覧と詳細だけをスクロールする。入れ子の全面モーダルを増やさない。
- 文字は共通のPC15px/スマホ12pxと表示倍率を使う。全文を縮小して押し込まない。
- 元の資源ヘッダー、旧研究一覧、既存のゲーム条件・費用・保存データを維持する。
- 既存の描画元を変更する。別のDOM監視や代理クリックで完成画面を上書きしない。

## 画面ごとの契約

| 画面 | 一覧 | 詳細・操作 |
| --- | --- | --- |
| 合成 | 下画面左の共通カード。素材枠を横に切替、候補確認後に明示選択 | 上画面は合成結果。下画面右は共通の能力/スキル/装備/成長を閲覧専用で表示。素材/結果の切替でもタブを保持。確定操作は固定フッター |
| 自キャラ | 共通カード。ユニット一覧の各タブは立ち絵付き、Lvは画像右下、HP/APを維持。部隊タブも同じメンバーカードを並べる | 全対象で共通の能力/スキル/装備/成長。部隊の内部IDは不要。死体回収・死亡者一覧も共通表示 |
| 研究 | 小型カード、Lv別一覧とフローチャートを切替可能 | PCは右側、スマホは詳細へ切替と戻る。研究開始は固定フッター。条件と効率は分離 |
| 拠点 | 左に段階・名前・人口の拠点一覧 | 右に概況/生産/運用。発展は概況、施設は生産、取引/物流は運用。拠点切替でも右タブを維持 |
| 土地 | 選択マスの情報 | 地形/高度/所有者などをコンパクトに表示。建設・開拓などの操作を上部にまとめる |
| 交流 | フィールド下部。選択マスにいる既存の交流対象 | 村/放浪者/守護者の既存処理を利用。会話/取引は既存の専用画面へ。未発見対象を一覧に漏らさない |
| 取引 | 提供/要求を横に比較。スマホも2列の物資欄 | アイコン+数量、選択して数量編集。配送/日程は別の折畳み。提案は固定フッター |
| 会話 | 相手上・自分下の発言と人物 | 発言欄と選択肢を分離し、回答欄だけスクロール。交渉役変更・能力・スキル・履歴は補助欄。回答後は同じ場所で切替。テスト操作は折り畳む |

## 検証

- フィールド下部「部隊」の部隊員/単独カードもユニット一覧と同じ画像・切り出し・Lv右下・経験値枠を使う。画像なしの場合だけ従来アイコンへ戻す。HP/AP・座標・自動操作表示・選択操作は維持し、別の画像対応表やカードCSSを増やさない。`scripts/check-v39-squad-portraits.mjs`で320/390/1100pxの画像一致/読み込み、画像クリック、タブ保持と部隊切替を検証する。

ユニットの表示対象だけを切り替えた場合は、開いている詳細タブを維持する。自キャラ画面の「能力/スキル/装備/成長」はキャラクター一覧・部隊一覧・部隊員の切替で能力へ戻さない。フィールドの「能力/基本/スキル」もカード選択・マップ上の選択で維持する。ユニット固有のスキル展開や装備操作メッセージは新しい対象向けにリセットする。

部隊編制の候補は初期状態で「単独＋編集中の部隊」、新規作成時は単独のみを表示。「他の部隊も表示」で移籍候補も選べる。各候補に所属を独立表示し、自動任務などの選択不可理由で所属を隠さない。他部隊から選択済みの候補は表示を戻しても残し、保存前に元所属→移籍先を表示する。チェックを外した現部隊員は単独へ戻る。表示切替・取消では所属やAP・座標を変更しない。

編成の地理条件と、所属を維持した単独行動/散開/集合は [部隊編成・散開・集合ルール.md](./部隊編成・散開・集合ルール.md) を参照。部隊操作は自キャラとフィールド詳細で共通表示し、長押しだけの機能にしない。

320/390/1100pxで、実データを使い選択→詳細→実行/戻るを確認する。スクリーンショットで密度と主従を確認する。自動テスト通過のみを「使いやすい」の根拠にしない。未修正・要再検証はUI_FIX_QUEUEへ残す。
