# 戦闘エフェクト属性共通設定

最終更新: 2026-10-09
状態: 仕様確定済み / 設定保存・編集UI実装済み / スキル自動適用は未実装

この資料は `docs/戦闘エフェクトルール.md` の属性表現を具体化し、カテゴリ設定と属性設定の責務を分離する現行ルール資料。

## 1. 確定方針

戦闘エフェクトは、基本カテゴリと属性設定を別々に管理する。

```text
戦闘エフェクト
= 基本カテゴリ
  - 基本形状
  - Scale
+ 属性共通設定
  - 色 / グラデーション
  - グラデーションの動き
  - 属性装飾
```

属性設定はカテゴリごとに複製しない。
同じ属性は、斬撃・刺突・飛翔弾・爆発などどのカテゴリで使用しても同じ属性設定を参照する。

例:

```text
炎属性
= 赤～黄のグラデーション
+ 上方向への移動
+ 炎の属性装飾

炎の斬撃
= 斬撃カテゴリ + 炎属性

炎の爆発
= 爆発カテゴリ + 同じ炎属性
```

## 2. カテゴリ設定が持つ項目

18カテゴリの仮分類ごとに保持する設定は次の2項目だけとする。

- 基本形状エフェクト
- 基準Scale倍率

カテゴリ設定には、Tint、グラデーション、移動方式、移動方向、移動速度、属性装飾を保持しない。

## 3. 属性共通設定が持つ項目

1属性につき1つの共通設定を保持する。

- 属性装飾エフェクト
- 着色方式: なし / 単色 / グラデーション
- 単色Tint
- グラデーション色A / 色B
- 開始位置 / 終了位置
- 着色強度
- 移動方式: 固定 / 一方向 / 往復循環
- 移動方向: 上 / 下 / 左 / 右
- 移動速度

移動方式の初期値は `固定` とする。

## 4. 属性一覧の取得元

属性名・系統名をUIコードへ固定配列として重複定義しない。

現行実装では `data/source/export/json/スキル一覧.json` を参照し、次から設定対象名を抽出する。

- `系統`
- `取得条件` / `条件` に含まれる `属性:...`

ゲームデータ側へ新しい属性・系統が追加された場合、設定画面もそのデータを元に候補を生成する。

## 5. 設定画面

エフェクト設定画面の上部で編集対象を切り替える。

```text
[カテゴリ] [属性]
```

### カテゴリ編集

- 18カテゴリから選択する。
- `基本` で基本形状とScaleを編集する。
- 色・動きはカテゴリ設定として編集しない。

### 属性編集

- ゲームデータから取得した属性・系統を選択する。
- `基本` では属性装飾を編集する。
- `色` でTint / グラデーションを編集する。
- `動き` でグラデーションの移動方式・方向・速度を編集する。
- プレビュー用の基本形状とScaleは現在選択中カテゴリを使用するが、属性設定データには保存しない。

## 6. 保存とJSON

ブラウザ内ではカテゴリ設定と属性設定を別々に保持する。

- カテゴリ: `v39-effect-category-settings-v1`
- 属性: `v39-effect-attribute-settings-v1`

設定画面のJSON書き出しでは両方を1ファイルへまとめる。

```json
{
  "schema": "v39-effect-composite-settings",
  "version": 1,
  "categories": {
    "slash": {
      "name": "斬撃",
      "baseEffect": "斬撃",
      "scaleMultiplierPercent": 100
    }
  },
  "attributes": {
    "炎": {
      "decorationEffect": "",
      "tint": "",
      "gradientEnabled": false,
      "gradientColorA": "#FFFFFF",
      "gradientColorB": "#FFFFFF",
      "gradientDirection": "up",
      "gradientMotionMode": "fixed",
      "gradientStartPercent": 0,
      "gradientEndPercent": 100,
      "colorStrengthPercent": 100,
      "gradientSpeedPercentPerSecond": 80
    }
  }
}
```

## 7. 実装状態

### 実装済み

- カテゴリ設定を基本形状・Scaleだけに分離
- 属性ごとの共通設定保存
- `スキル一覧.json` からの属性候補生成
- 設定画面の `カテゴリ / 属性` 切り替え
- 属性装飾・色・グラデーション・動きの編集
- カテゴリ設定と属性設定の一括JSON書き出し / 読み込み

### 仕様確定済み・未実装

- 実際の各スキルを基本カテゴリへ分類する処理
- スキルの属性を判定し、カテゴリ設定と属性共通設定を合成して戦闘再生へ渡す処理
- 各属性の正式な色A / 色B / 装飾エフェクトの初期値

上記未実装部分が完了するまでは、属性設定画面で設定値を作成・保存できても、全スキルの戦闘再生へ自動適用されるとは扱わない。
