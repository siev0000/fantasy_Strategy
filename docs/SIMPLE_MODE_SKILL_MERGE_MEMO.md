# 簡単モード技能併合メモ

状態: **設計案 / 未実装**

詳細モードでは現在の技能を個別に扱うが、簡単モードでは近い役割の技能をまとめ、管理項目を減らす。

## 簡単モード技能案

| 簡単モード技能 | 元技能 |
|---|---|
| 指揮 | 指揮 |
| 威圧 | 威圧 |
| 欺瞞 | 騙す / 変装 |
| 察知 | 看破 / 索敵 |
| 隠密 | 隠密 |
| 技巧 | 早業 / 装置 |
| 運動 | 軽業 / 飛行 / 遊泳 |
| 知識 | 鑑定 / 知識 |
| 制作 | 制作 / 芸術 |
| 政治 | 統治 / 交渉 |
| 魔術 | 魔術 |
| 信仰 | 信仰 |
| 生産 | 農業 / 林業 / 漁業 / 鉱業 |

合計13技能を基本案とする。

## 検討事項

- `飛行` と `遊泳` は種族差・地形差を強く残したい場合、簡単モードでも独立させる余地がある。
- その場合は `運動` を `軽業` のみ、または地上身体操作系として扱い、全体を14〜15技能程度にする。
- 詳細モード側の技能データを正本とし、簡単モード専用の技能値を別管理するより、元技能から集約して表示・判定する方式を優先する。
- 併合時の技能値算出方法（平均 / 最大値 / 加重平均など）は未確定。
- 関連ステータスの扱いも、複数技能を併合した場合に1つへ固定するか、行動ごとに元技能側の関連ステータスを使うか未確定。

## 現在の技能判定方針

通常の技能判定は以下を基準とする。

```text
(技能 + 関連ステータス × 0.25) × Random(0.75, 1.00)
```

関連ステータスがない技能は以下。

```text
技能 × Random(0.75, 1.00)
```

農業 / 林業 / 漁業 / 鉱業は現時点では関連ステータスなし。

## 攻撃種別の階層化と簡単モード案

詳細モードでは攻撃種別を以下の階層で扱う案とする。

| 種別 | 上位カテゴリ | 備考 |
|---|---|---|
| 近接 | 物理 | 近接攻撃全般 |
| 素手 | 近接 | 素手・戦篭手など |
| 盾 | 近接 | 盾による攻撃 |
| 杖 | 近接 | 杖での物理攻撃 |
| 射撃 | 物理 | 射撃攻撃全般 |
| 弓 | 射撃 | 弓系 |
| 射出弓 | 射撃 | クロスボウ系 |
| 銃 | 射撃 | 銃器 |
| 砲 | 射撃 | 砲撃兵器 |

階層イメージ:

```text
物理
├─ 近接
│  ├─ 素手
│  ├─ 盾
│  └─ 杖
└─ 射撃
   ├─ 弓
   ├─ 射出弓
   ├─ 銃
   └─ 砲
```

簡単モードでは、個別種別を上位カテゴリへまとめる案を基本とする。

- 素手 / 盾 / 杖 → `近接`
- 弓 / 射出弓 / 銃 / 砲 → `射撃`

`近接` と `射撃` 自体は、親カテゴリであると同時に汎用種別としても使用できる構造を想定する。
個別分類がない近接攻撃は `近接`、個別分類がある攻撃は `弓` などを保持し、必要に応じて上位カテゴリも参照できるようにする。
