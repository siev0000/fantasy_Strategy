# 性格会話の現行ルールとシート追記メモ

更新: 2026-10-21

## 編集元と反映

- 原本は `@game_data` の「性格会話」。現在は18性格、19列。
- 最新XLSXから `python -B scripts/game_data_converter.py --input path/to/game_data.xlsx --sheet 性格会話` で `性格会話.json` を再生成する。JSONを手編集しない。
- 「性格」は重複不可。同じセルの改行はセリフの候補区切り。1回の発言につき1候補を抽選する。
- `{一人称}` / `{二人称}` / `{名前}` を使うと発言者の設定を差し込む。既存の文章を機械的な口調変換で書き換えない。

## 保存と表示

- ユニット・一般村の会話代表・放浪者は初回の状態登録時にランダムで性格を選び、`conversationPersonality` を保存する。性格未設定の旧セーブも初回に補完する。
- 村の代表の口調はvillage.leaderの性格を使用し、守備兵の補充で変えない。村側conversationPersonalityは互換用に同じ値を保持する。自分側は選択した交渉役の性格を使用する。
- 再描画・ターン進行・JSON保存/復元で再抽選しない。発言の候補抽選は開始時または新しい発言時のみ。
- 性格は現時点では口調だけに影響し、AIの好戦性や交渉成功率は変更しない。
- 情報タブに相手と交渉役の性格を表示する。
- 性格名がシートから削除されたセーブは名前を保持し、台詞だけ「真面目」へフォールバックする。

## 接続済み

| 場面 | シート列 | 注意 |
| --- | --- | --- |
| 会話を開く | 交渉開始 | 相手の台詞 |
| 村の交流・属国化の結果 | 交渉成功 / 交渉失敗 | 実行失敗と交渉不成立を区別 |
| 通常依頼の受注 | 承諾 | 受注した依頼名などの結果文も残す |
| 通常依頼の報告 | 交渉成功 | 専用列は今後追加候補 |
| 村への襲撃 | 挑発 | 自分の台詞。戦闘ルールは変えない |
| 取引の承諾判定 | 交渉成功 / 交渉失敗 | 予約/成立状態の事実も残す |
| 番号付きイベント回答 | イベント側の固有回答 | 性格の汎用文で置き換えない。上記プレースホルダーだけ対応 |

性格会話の返答と、実際の成功/報酬/不足などの結果文は別扱い。結果文を台詞で消さない。画面に入りきらない全文は情報の会話履歴で確認する。

| 追加候補 | 用途 | 現在の代替 |

同じシートに列を追加し、別の性格シートへ分散させない。空欄なら既存文を残す。追加後は変換・接続・読み戻し確認が必要。

## 既存列で未接続の場面

好条件/悪条件、値下げ/値上げ要求、脅迫/威圧、煽り、降伏要求、金品要求、終了はデータとして読めるが、現在は自動価格評価や専用ボタンへ接続していない。発言だけで取引条件を変更したり、閉じた瞬間に交渉結果を書き換えたりしない。

## 不足チェック

`window.getV39NegotiationRules().getV39ConversationDataGaps()` で既存19列の空欄を性格名・項目名付きで確認できる。今回取り込んだ18性格には既存列の空欄はない。上の追加候補は空欄エラーとは別の未実装項目として管理する。

## 村長・リーダーの自動生成（2026-10-21）

- 一般村の初回状態登録/旧セーブ読込時、leaderがなければ村の種族・村Lvから交渉専任NPCを生成して保存。IDは村ID-leader、通常は「村名の村長」、ゴブリン/オーガは族長、悪魔はリーダー。称号・基本クラス・最低Lvはconfig/v39-village-leaders.json。
- village.leaderに名前・種族・クラス・画像解決に使う情報・Lv・性格を保持し、以後は既存人物を使用。名前/性格は再描画や守備兵の入替で再生成しない。村側の従来性格を引き継ぎ、未設定ならランダム。
- フィールドの操作ユニット/守備兵/軍事人口とは別枠。現時点では非戦闘員であり、守備兵の全滅判定・訓練枠・物流使者に加えない。村長の死亡/交代・捕虜化は未実装。既存の廃村に新しい代表は自動補充しない。
- 村の会話と独立取引の会話は同じgetV39VillageSpeakerを使用する。情報タブに名前・称号・性格・一人称/二人称を表示する。

## 村長・交渉総合テスト

1. タイトルの「テスト操作」→「専用」→「村・交流テスト」を開き「会話・報酬交渉」。現在のゲームを置換するため、必要なら先に保存する。旧「村長・交渉総合テスト」に対応する。
2. 通常/友好90/ゴブリン/守備兵不在の4村と各村に交渉担当を配置。担当は交渉/威圧の自己強化テストスキルを所持。自国に十分な物資・銀/黒木・4種類の特産品を用意する。
3. 会話（村の様子/交流/休息/属国化/襲撃）、クエスト（物資/討伐/番号付き）、取引（提供/要求/配送/日程/一覧）、情報（村長/性格/交渉役/スキル/履歴）を通常操作で確認する。友好の村は属国化を試せる。襲撃等は実際に状態が変わるため、必要なら開始し直す。
4. モーダルを閉じてテスト操作へ戻り、「選んだ村と話す」で担当と相手を切替。「性格・台詞を確認」は18性格と既存16場面の台詞を表示するだけのプレビューで、降伏や資源移転など未接続ルールは実行しない。
5. 構成はconfig/v39-negotiation-hub-test.json。TEST_交渉支援/TEST_威圧支援はシート管理対象外のテストスキル.json。通常クラスやCSは変更しない。

検証: scripts/check-v39-village-leaders.mjs。実際のテスト開始ボタン、4村長、守備兵不在の画像、全タブ、スキルの実消費/物資支援、特産品候補、全16場面のプレビュー、守備兵除去/ネイティブ保存読込/旧データ補完を確認する。
