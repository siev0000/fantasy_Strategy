# 一般村の防衛・廃村・再入植

更新: 2026-10-20

- 守備隊は村から3マス以内の敵対的な敵を迎撃する。通常の移動AP・射程・攻撃・同一スキルの再使用制限を共用する。同ターンの防衛再実行は行動を増やさない。
- 対象へ接近し、HP30%未満なら村へ後退する。村の3マス外へ深追いしない。敵が周辺におらず、前ターンも戦闘せず村に隣接していれば最大HPの10%を回復する。数値は暫定で `config/v39-npc-defense.json` に集約する。
- 再編時は守備隊のHP/AP・座標・技能クールダウン・死亡期限を保持し、通常の状態更新で位置や死亡状態を戻さない。
- 人口0で廃村にする。守備隊が全滅しても住民が残る限り村は存続し、通常守備軍1部隊だけを再訓練する。村事件専用テストの戦闘判定は従来どおりにする。
- 守備兵不在をターン処理で検知すると訓練を開始し、暫定3ターン後に最低限の通常守備軍1部隊を補充する。期間はイベントシートの守備隊計画「目標ターン」、未設定時のみconfigの `replacementTrainingTurns`。通常の種族別軍隊初期Lv・通常軍隊人数・装備生成を共用し、その人数以上の住民が必要。兵士は人口内の軍事人口として数え、追加の住民や物資は生成しない。村周囲3マス以内に配置先がなければ空くまで待つ。
- 兵士が既にいれば補充せず、訓練中に生存兵が戻れば中止する。死亡者は死体として保持し、新兵には別IDを付ける。死体消滅や再表示による自動復活は行わない。訓練状態は保存し、同一ターンの重複進行を防ぐ。完了ターンの迎撃はせず、次ターンから通常防衛に参加する。
- 廃村は村の場所・領域・施設・残った在庫を保持し、住民は避難した扱い（人口0）とする。死んだ守備隊は死体の通常ルールへ渡す。勝手な補充・報酬・属国収入を発生させない。会話/依頼/休息/取引/略奪は停止する。
- 地上の廃村から1マス以内へ自軍の生存者を向かわせると、土地/交流欄に再入植を出す。既存の選択拠点から住民5人を移し、村を所有拠点として再利用する。人口内訳ごと移すため、人口を生成しない。他勢力が領有している土地は取得できない。
- 一般村の在庫が未定義だった旧データ/新規生成だけ、初期の金を人口×1、穀物を人口×5で用意する。既にある在庫は空でも尊重し、初期値へ毎ターン戻さない。計画処理では共通生産計算の実収入/維持費を反映する。正式イベントの謝礼も実在庫から支払う。魂は生成しない。
- 廃村・再入植先・防衛の最終行動ターンは既存セーブに含む。

検証: `check-v39-village-replenishment.mjs`、`check-v39-village-campaign.mjs`、`check-v39-npc-campaign.mjs`。長期の襲撃密度/維持可能性は引き続き調整対象。

## 村への襲撃（UI54）

- 会話タブの「村を襲撃」を確認して実行すると、その村と襲撃プレイヤーを敵対状態にし、フィールドへ戻って通常戦闘を行う。友好度は敵対表示になる-60以下とする。
- 敵対は村ごとのhostilePlayerIdsで保持し、他プレイヤーへ波及させない。旧保存にlastPlayerRaidだけがある場合も襲撃者の敵対を補完して読む。守備兵を敵リストへ複製・移動せず、村のdefenseUnitsをそのまま使う。
- 平時の村兵への直接攻撃はAP消費前に拒否。敵対後は通常の射程・射線・範囲・AP・ダメージ・EXP・死亡/死体処理を適用し、近接攻撃には守備兵も反撃する。非敵対村/無関係プレイヤーを巻き込む許可は追加しない。
- 守備兵は村周囲の通常防衛範囲内で敵対プレイヤーも迎撃する。武器/身体武器/習得Aスキルから使用可能な攻撃を選び、AP・CT・退避・同ターンの重複防衛抑止を維持する。地上外のプレイヤーを攻撃しない。
- 襲撃直後に戦力比較だけで資材を生成したり住民を減らしたりする旧簡易処理は廃止。再押下で略奪を繰り返せない。勝利後の包括的な占領/略奪/和平・再交渉はこの修正で完成扱いにしない。
- 襲撃者から見た守備兵の枠を赤くし、敵対状態と守備兵HPは保存する。守備兵の全滅だけで住民の残る村を自動消滅させない。
- 検証: check-v39-village-raid.mjs。390/1100で実UI襲撃、平時攻撃拒否、敵対後の実ダメージ/反撃/迎撃/撃破、他プレイヤー分離、保存、資材の無生成を確認する。
