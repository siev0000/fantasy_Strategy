# ドキュメントの入口

仕様を探すときはここから。全ファイルは [文書一覧](INDEX.md)、追加・更新時は [文書運用ルール](DOCUMENTATION_RULES.md) を参照する。

## 最初に読む資料

- [現状ゲーム仕様メモ](現状ゲーム仕様メモ.md): 現在の仕様の概要と実装先。
- [統合タスク一覧](ALL_TASKS_UNIFIED.md): 残作業の入口。詳細の進捗は対応する Issue と照合する。
- [スプレッドシート更新手順](SPREADSHEET_DATA_WORKFLOW.md): `@game_data` が編集原本。生成JSONを先に直さない。
- [クラス・スキル配置ルール](CLASS_SKILL_RULES.md): クラス作成・再設計前の必読資料。
- [ユニット画像生成ルール](UNIT_PORTRAIT_GENERATION_RULES.md): 画像生成・編集前の必読資料。
- [画像素材準備リスト](references/画像素材準備リスト.md): 画像の制作依頼・受領・ゲーム反映状況の共通一覧。

## 目的別の置き場所

- `rules/units/`: 能力・成長・戦闘・部隊・召喚・合体・アンデッド。
- `rules/world/`: 地形・気候・災害・洞窟・敵出現・調査。
- `rules/economy/`: 資源・人口・施設・研究・物流。
- `rules/diplomacy/`: NPC勢力・一般村・交流・クエスト・取引。
- `rules/ui/`: 画面構成・操作・文字・エフェクト。
- `development/`: 起動方法・構成・データ管理・開発手順。
- `tests/`: テスト画面の入口・確認手順。
- `tasks/`: UIなど特定分野の詳細作業一覧。
- `design/`: 設計案・未決事項。採用済み部分と未実装部分を区別する。
- `references/`: 素材準備・参考資料。画像・参考HTMLは `references/assets/`。
- `history/`: 旧メモ・置き換え前の資料・移動履歴。

各ファイルへのリンクは [文書一覧](INDEX.md) にまとめている。`rules/` 内にも暫定値・未実装の節があるため、配置場所だけで実装済みと判断しない。

## 仕様の優先順位

1. 現行コード・`data`・`config`
2. [現状ゲーム仕様メモ](現状ゲーム仕様メモ.md)
3. 対象分野の現行ルール文書
4. [統合タスク一覧](ALL_TASKS_UNIFIED.md)
5. 将来設計・検討案
6. 旧メモ・草案・`progress.md`

`仮`・`暫定`・`将来`・`未実装` の記載は実装確認なしに確定仕様として扱わない。スプレッドシートの列・記載方法は上記の更新手順を優先する。

## 旧資料について

- [MEMO.md](MEMO.md) は既存参照を維持するため同じ場所に残す。新しい仕様・タスクの集約先にはしない。
- 旧 `NEXT_TASKS.md` / `RULE_TASKS.md` は [文書一覧の履歴欄](INDEX.md) から参照できる。新しい全体タスク一覧を増やさない。
- 整理前の入口は [旧README保存版](history/docs-index-before-2026-10-23.md)、旧パスと移動先は [移動記録](history/document-moves-2026-10-23.json) に保存した。
- 今回の分類は内容の削除・ゲーム仕様の変更ではない。古い記述の内容統合は実装との照合を行ってから別途進める。
