# ChatGPT向けの仕様目次・運用メモ

『fantasy_Strategy』は、勢力を率いて領土と拠点を運営し、ユニットを育成・編成して戦うターン制ゲーム。資源・人口・研究・施設が領土運営を支え、装備やクラスがユニットの行動を決める。他勢力との交流・諜報や、固定マップの作成も扱う。

相談を受けたら、まず対象の欄から該当する資料を読む。広い質問では [ドキュメントの入口](README.md) と [現状ゲーム仕様メモ](現状ゲーム仕様メモ.md) を使い、個別資料は [文書一覧](INDEX.md) で探す。

## 仕様を説明するとき

- 実際の挙動は現行コード・設定・ランタイムデータを優先し、概要と分野別ルールで背景を確認する。資料が食い違う場合は [仕様の優先順位](README.md#仕様の優先順位) を参照する。
- 回答には根拠にしたファイルと節名を添える。資料しか読めない場合や参照している版が古い場合は、現行実装との照合状況を書く。
- 「実装済み」「暫定実装」「決定済み・未実装」「検討中」を区別する。作成した案には、ユーザーが判断する点と、採用された場合の確認条件を添える。
- シート管理データの入力原本は `@game_data`。ユーザーがシートを編集し、Codexは依頼時に既存バッチで取り込む。入力案を作るときは [更新手順](SPREADSHEET_DATA_WORKFLOW.md) の列名・記法を確認する。

## タスクの追記と引き渡し

ChatGPTでの仕様相談、改善案、Codexに確認してほしい依頼は [ChatGPTタスク候補](tasks/CHATGPT_TASKS.md) に追記する。同じ内容が既にある場合は、既存項目に追記する。ユーザーが承認した実装範囲をCodexへ渡し、Codexは [統合タスク](ALL_TASKS_UNIFIED.md) または対応 Issue を更新する。

ChatGPTからリポジトリへ書き込めない場合は、タスク候補のテンプレートに沿ったMarkdownを返す。必要な資料にもアクセスできない場合は、上の目次から対象のファイル名を伝える。
