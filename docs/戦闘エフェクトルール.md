# 戦闘エフェクトルール

最終更新: 2026-10-08  
状態: 仕様確定済み / 組み合わせ設定・管理画面は未実装

この資料は、v39フィールド戦闘で使用する攻撃・補助エフェクトの構成方針を定める現行ルール資料。
現在の再生実装は `frontend/src/v39/combat/v39-effect-player.js` を参照し、未実装部分は `docs/戦闘エフェクト設定タスク.md` と合わせて管理する。

## 1. 基本方針

- 属性・スキルごとに完成済みエフェクトを大量に個別制作する方式にはしない。
- エフェクトは基本的に、再利用可能な **基本形状エフェクト** と **属性装飾** を組み合わせて表現する。
- 属性差は、基本形状の Tint / 色調変更、小型の属性エフェクト・粒子等の追加で表現する。
- 威力、通常範囲、炸裂範囲などに応じて、同じ基本形状の表示サイズや配置を変える。
- スキル名ごとの個別ハードコードを増やさず、可能な限りデータ駆動で組み合わせを決定する。
- プレイヤー攻撃、敵攻撃、反撃、範囲攻撃で別のエフェクト再生基盤を作らず、同じ設定・同じ再生処理を使用する。

基本形は次の考え方とする。

```text
戦闘エフェクト
= 基本形状
+ Tint / 色調
+ 属性装飾
+ 威力によるScale
+ 範囲・炸裂によるScale / 配置
```

## 2. 属性付き攻撃の表現

属性攻撃は、基本形状を属性ごとに作り直すのではなく、基本形状へ色調と小型装飾を重ねる。

例:

```text
闇の斬撃
= 斬撃
+ 黒～紫系Tint
+ 小型の闇エフェクト / 粒子
```

同様に、以下のように再利用する。

- 炎の斬撃: `斬撃 + 赤～橙系Tint + 火花 / 小炎`
- 氷の斬撃: `斬撃 + 水色系Tint + 氷片`
- 雷の斬撃: `斬撃 + 青白系Tint + 小型放電`

この考え方を斬撃だけでなく、飛翔弾、射撃、ビーム、爆発、薙ぎ払い、範囲放射等にも適用する。

## 3. 威力・範囲による大きさ

- 攻撃威力が高いほど、原則として基本エフェクトのScaleを大きくできるようにする。
- 通常範囲や炸裂範囲が大きい攻撃は、その範囲に合わせてエフェクトのScaleまたは配置数・配置位置を調整する。
- 範囲攻撃を必ず1枚の巨大エフェクトだけで表現する必要はなく、基本形状を複数地点へ配置する方式も使用できる。
- 威力からScaleへ変換する具体式、Scale上限・下限、範囲ごとの複数配置数はまだ未確定とする。
- 未確定の数値は実装時に共通設定へ集約し、スキルごとのコードへ固定値を散在させない。

## 4. 既存再生基盤の再利用

現行 `playV39MapEffect` は以下をすでに扱えるため、新しいエフェクトシステムでもこの機能を再利用する。

- エフェクト名による再生
- `:` 区切りによる複数エフェクト列
- `scalePercent`
- `angleDeg`
- `tint`
- `colorStrengthPercent`
- `hueAnimationDegPerFrame`
- `grayscaleBase`
- `renderStyle`
- 再生時間・シーケンス間隔

現行の通常再生時間は1.5秒を基準とする。
同等のTint・Scale・複数再生機構を別実装として作り直さない。

## 5. 基本エフェクト分類

最終的な基本エフェクト数はまだ確定していない。
現在登録されている全スキルを分類し、不足・重複を確認してから決定する。

初期分類候補は以下。

### 攻撃系候補

1. 斬撃
2. 刺突
3. 打撃
4. 爪・牙
5. 飛翔弾
6. 射撃
7. ビーム
8. 波・薙ぎ払い / ブレス
9. 爆発
10. 落下・落雷
11. 雨・連続落下
12. 範囲放射

### 補助系候補

1. 回復
2. 強化
3. 弱体・呪い
4. 状態異常
5. シールド
6. 召喚・特殊

上記の `12 + 6 = 18種類` は確定数ではない。
同じ見た目・用途で統合できるものは統合し、既存スキルを分類できない場合だけ新しい基本形状を追加する。

## 6. エフェクト設定画面

管理画面に `エフェクト設定` を用意する方針とする。

設定画面では、少なくとも次の要素を確認・設定できるようにする。

- 基本形状エフェクト
- 属性装飾
- Tint / 色調
- 基準Scale
- 実エフェクトのプレビュー

UIへ仮エフェクト名や仮設定を直接埋め込んで後から実データで上書きする方式にはしない。
最初から実際のエフェクトカタログ・設定データを参照する。

## 9. 敵攻撃時のカメラ演出

敵ターンの攻撃は、エフェクトだけを即時再生して誰が攻撃したか分からなくならないよう、攻撃前に戦闘構図を作ってから再生する。

基本順序は次のとおり。

```text
攻撃イベント開始
→ 攻撃者と対象を確認できるカメラ構図へ移動
→ 短時間停止
→ 攻撃エフェクト
→ ダメージ表示
→ 次の敵行動
```

- 近距離攻撃では、攻撃距離ごとに細かく倍率を変えず一定の戦闘ズームを使用する。
- 現行調整値では3マス以内を近距離扱い、戦闘ズーム倍率は1.5とする。
- 遠距離攻撃では、攻撃者と対象の両方が画面内へ入る最大倍率を算出し、周囲に2マス相当の余白を取る。
- 遠距離攻撃の後に別の遠距離攻撃が続く場合、微小な倍率差ではズームを変更せず、拡大・縮小の繰り返しを抑える。
- 攻撃前停止は現行500msとする。
- 攻撃者が未発見の場合は、その攻撃者の位置を見せるための構図にはしない。対象側だけを映して着弾を表示し、Fog・索敵による非表示ルールを維持する。
- 敵ターン中に変更したズームは、敵ターン終了時に敵ターン開始前の倍率へ1回だけ戻す。
- カメラ演出は戦闘ダメージ、命中、AP、待機、CTなどのゲーム内ターン処理には影響させない。
- 調整値は `V39_ENEMY_TURN_PRESENTATION_CONFIG` に集約し、演出処理へ同じ数値を重複して直書きしない。
