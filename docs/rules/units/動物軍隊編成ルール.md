# 動物の軍隊化

更新: 2026-10-18。初回実装。集積所・倉庫とは別工程。

## 操作

- 「ユニット一覧」から通常の動物・蟲を選択し「軍隊化」。既にまとめた個体は「軍隊編成 N体」。
- 代表個体を含め2〜5体を選び、右の平均Lv/EXP/人数補正を確認して確定する。
- 複数駒の「部隊」編制とは別。軍隊は1駒で移動・戦闘し、既存の部隊にも参加できる。
- 代表個体は固定。他の個体を外し、同種の別個体へ入れ替えられる。代表も外したい場合は一度解散する。
- 活動中は同じマップの周囲2マス、施設内は同じ格納施設内から選択する。活動中と施設内を直接混ぜない。
- 外した個体と解散した個体は、周囲の通行可能な空きマスへ単独で配置。配置不可なら全処理を取り消す。施設内なら同じ施設へ戻し、格納上限も検証する。
- 軍隊化/入替/解散の結果ユニットはAP0。編制操作で移動や攻撃の回数を無限に増やさない。

## 対象と制限

- クラスの種類が「動物」「蟲」、かつヒーロー/ネームド/統治者/召喚ではない個体。
- 同種・同じクラス構成が必要。初回は通常個体のみ。合成・強敵・アンデッド個体は対象外。
- 内部個体を持たない既存の徴兵軍隊・敵軍隊を、架空の個体へ分解しない。
- 自動輸送/取引/警備/教官等の任務中、荷物/携帯道具あり、詠唱/一時効果/盾/障壁/スキル再使用待ちの間は編成不可。
- 種族別の人数上限拡張、異種混成、合成個体や変異個体の軍隊化は未対応。

## Lv・成長

- 元個体のID・Lv・EXP・装備を `animalArmy.members` に保持する。軍隊は元個体を消費・合成する機能ではない。
- 表示Lvは個体の「Lv＋次LvへのEXP進捗率」の平均を切り捨てる。端数は軍隊の次Lv必要EXPへ換算して表示する。
- 例: Lv3とLv6で進捗0なら平均4.5。軍隊はLv4＋次Lvの50%相当のEXP。解散すると元のLv3/Lv6へ戻る。
- UI204: 必要EXPは通常軍隊と同じ `1＋(人数−1)×0.5` 倍。受取EXPを `人数÷必要EXP倍率` で分配用プールへ換算し、構成個体へ均等分配する。整数の余りは順送りし、小数は軍隊側へ持ち越す。従来の人数分配へさらに倍率を重ねて二重に遅くしない。個体自体の必要EXPは変えず、軍隊表示のEXP分子/分母へ同倍率を適用する。詳細は[キャラ成長ルール](CHARACTER_STATUS_RULES.md)の軍隊EXP節。
- 個体を追加/交換すると平均を再計算する。元個体のEXPはその個体とともに移動する。
- 通常の動物・蟲の成長上限はLv15（設定可能）。ヒーローと合成個体の成長は別。既存Lv15超の個体を自動でLv15へ下げない。
- 合成個体は既存の合成成長処理を維持し、今回の通常動物上限で停止させない。施設徴兵の上限も既存処理を維持する。

## 戦闘・HP・保存

- 能力/スキルは表示Lvと同じ種族・クラスから既存処理で算出。最高Lv個体だけが持つスキルを全員に付けない。
- HP倍率は `1＋(構成人数−1)×0.5`、攻撃回数は構成人数。既存の軍隊戦闘プロフィールを利用する。
- 編成時は構成個体の合計現在HP/合計最大HPの割合を引き継ぐ。解散/入替時は編成後のHP割合変化を元個体へ戻し、全回復させない。
- 生存軍隊の内部に個別の戦死者/人数減少は持たせない。元個体が生きている軍隊の解散で丸めにより死亡しないよう最低HP1とする。
- 食料維持の人数は実際の構成個体数で扱い、既存の人型軍隊の固定係数を適用しない。
- 既存セーブに内部個体を追加保存。ロード時に再抽選・再生成しない。活動中と施設内の軍隊をともに保持する。

## 設定・テスト

- `config/v39-animal-army.json`: 最小/最大人数、編成/配置半径、通常Lv上限、人数HP補正、対象種類。
- 人数上限5はユーザー指定の確定値。データを増やすのでなく、この設定で変更できる。
- 「テスト → 専用 → 動物軍隊テスト」: ウルフを活動中4体（Lv3/6/9/12）、研究所内6体（Lv4/7/10/5/8/12）用意する。現在のゲームを置き換える。
- `scripts/check-v39-animal-army.mjs`: 320/390/1100幅の画面操作、平均・端数EXP・入替・解散・施設内操作・HP/AP・EXP分配・ヒーロー除外・任務/CT/別マップ/範囲/空きマス判定・保存読込。
