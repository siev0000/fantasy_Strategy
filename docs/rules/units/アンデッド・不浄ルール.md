# アンデッド・不浄ルール

更新: 2026-10-20

この文書は、アンデッドの発生・成長・AIと、マスの浄化/不浄、死の霧の関係について今回確定したルールをまとめる。
浄化・不浄イベント・霧のエリア制限・死の刃・AI除外は実装済み。召喚所属選択と上位化は未実装。

> 2026-10-13確定: `霧・交流クエスト・守護者ルール.md` に残る「洞窟の死の霧が階層全体へ広がる」という記述は旧仕様とし、本書の「発生地点を含む1エリアを覆う」を優先する。

## 1. 浄化・不浄

- 2026-10-17: `効果:魂回収` で魂を保管した死体は `soulCollected` を持つ。自然/魔法のアンデッド化、蘇生、再回収は不可。魂保管で死体やその荷物自体は消さず、通常の期限/荷物回収へ渡す。魂の合成は `モンスター合体ルール.md` を参照。

- 各マスは「浄化」値を持つ。
- `0` を中立とし、負の値を不浄が蓄積した状態として扱う。
- 浄化値自体の下限は `-20`（2026-10-20確定）。正方向の上限は未確定。死亡・死体放置・死の霧・死の刃などの共通増減で下限を適用し、既存マップを表示/読込するときも下限未満の値を補正する。補正後の値から聖水等で回復できる。
- この下限は自然アンデッド化の発生閾値とは別。今回、発生閾値 `-5` や発生確率・判定間隔は変更していない。`-10` 等への発生閾値の変更案、AIの埋葬・回収対策、ゲーム設定UIは未実装。
- 生存ユニットが死亡へ変わった時、その死亡マスの浄化を即時 `-1`。軍隊も1ユニットの全滅を1件として数え、内部人数の減少は別件にしない。既存の死体配置、読込、死体状態の再更新は新たな死亡ではない。召喚体の消滅は対象外。住民人口の増減をユニット死亡に流用しない。
- 原本施設「墓地」は1棟につき毎ターン2件、自拠点の領土内の死亡による即時低下を防ぐ。敵味方ではなく死亡した領土で判定。同一拠点の複数棟は加算し、他拠点・領土外へは流用しない。使った枠は保存/読込や施設の建て直しで戻らず、次の `timeline.turnNumber` に再び使える。
- 保護数は施設シート `死亡浄化保護数` が正本。0は保護なし。墓地の建築2ターン・信仰Lv1・棟数制限なしは暫定。拠点→運用→施設でそのターンの保護残数を表示する。
- 墓地の保護は死亡時の `-1` だけ。以下の死体放置、死の霧、死の刃の低下は防がない。墓地を作るだけで死体を回収/消去したり、自然発生判定を無効化したりはしない。
- 死体が放置されているマスは、死体が残っている間、毎ターン浄化値を `-1` する。
- 現行は同じマスに複数の死体があっても低下量は毎ターン1。
- 浄化値が `-5` 以下のマスは、不浄イベントの発生候補になる。
- `-4` 以上では、浄化不足を理由としたアンデッド・死の霧の発生判定を行わない。

## 2. 不浄イベント

### 通常死体とアンデッドの残骸（2026-10-20）

- 放置期限は通常死体・地面の死体資源が10ターン、アンデッドの実体ある残骸が5ターン。`frontend/src/lib/v39-gameplay-balance.js` の `V39_CORPSE_LIFETIME_BALANCE.organicTurns` / `remainsTurns` で変更できる（ゲーム設定UIは未追加）。既に期限を確定した死体は保存された期限を維持する。旧形式のフィールド死体は死亡ターンを基準に新期限へ補正し、旧死体資源は読込時から10ターン。
- 死体資源はマス内の追加分ごとに期限を保存する。追加しても古い分の期限は延びず、消費は古い分から扱う。霊廟の保管中は残り期限を停止し、取り出し後に再開する。地上/洞窟ともそのワールドの処理で期限切れを除去する。
- 期限切れで死体そのものを除去しても装備・その他の物資は残留品として地面へ残す。以後その死体による浄化低下・アンデッド化は止まるが、既に下がった浄化値や発生済みの霧は自動解除しない。
- 通常の生物は従来どおり有機的な死体を残す。アンデッドは再び通常死体にはならず、ゾンビ/スケルトン等の実体のあるものは残骸を残す。ゴースト/レイスは死亡後の通常ライフサイクル処理で消滅し、フィールドの死体として残さない。
- アンデッドの死亡と残骸の放置は、死亡時/毎ターンの浄化低下や死体由来の死の霧の材料に数えない。自然アンデッド化・通常のアンデッド化魔法・通常蘇生・魂回収の対象にもせず、無限再利用を防ぐ。残骸専用の再生/利用スキルは未実装。
- 装備は死亡時に残骸の荷物へ移し、元の装備欄を空にする。実体のないユニットは装備・携帯荷物・全滅部隊の貨物を地面へ残して消滅する。敵/自軍/一般村守備兵に共通適用し、保存後や繰返し処理で二重に落とさない。
- 残骸そのものを食用の死体資源へ変換しない。アンデッドが生前から運搬していた実際の死体資源は別物なので、他の運搬物資とともに保持する。既存マップの不浄や既存の死の霧は、残骸を対象外にしただけでは消去しない。
- 元種族・現職・正の取得済みクラス・アンデッド化履歴/フラグから共通判定する。合成の材料としてのみ含まれるゴーストは、実体ある合成獣のゴースト化と混同しない。
- 検証: `scripts/check-v39-undead-remains.mjs`。自然/魔法の再変化拒否、浄化低下対象、通常死体の既存変化、消滅/装備と貨物/重複抑止/保存復元を確認する。

### 通常死体への基本行動案（未実装）

- 近くに対象がある場合だけ基本行動に「死体処理」を1項目表示し、対象と処理方法を選ぶ構成を提案中。埋葬（自然再発生防止）、霊廟への回収（既存保管処理）、適性/スキルによる解体・死体食・魂回収をまとめる。新しい埋葬/解体行動、AP/条件、AIによる選択はまだ確定・実装していない。既存の死体食/魂回収/霊廟保管を廃止した意味ではない。

### 虫のアンデッド化（2026-10-19）

- 虫はゾンビ/ヴァンパイアに対応し、スケルトン/骸骨にはなれない。現在のクラス原本の種類「蟲」と、虫画像対応表の種族/別名で共通判定する。
- 自然発生の既存抽選（ゾンビ/スケルトン）では、虫の死体はスケルトンを候補から外して重みを再計算する。ヴァンパイアの自然発生確率を新設する変更ではない。
- 魔法などでスケルトンを明示した場合も虫の死体は変換しない。生成、死体消費、継承を行わず、そのまま残す。ゾンビ/ヴァンパイアは元種族とLv・装備の既存継承規則を使う。
- 専用虫6シートは各種の5/11番がヴァンパイア、6/12番がゾンビ。白い姿をスケルトン枠とみなさない。
- アンデッド画像は属性クラスや通常画像の直接指定より優先する。取得済みLvが正の前提職/合成クラスも確認し、Lv0は無視する。未対応の属性姿は別属性へ推測で割り当てない。

- 浄化値が `-5` 以下になっただけで、毎ターン必ずアンデッドや死の霧を発生させるわけではない。
- 不浄イベントでは「死の霧」「アンデッド」「何も発生しない」のいずれかを判定する。
- 同じマス・同じターンに、死の霧とアンデッドを同時発生させない。
- 暫定値は死の霧8%、アンデッド8%、何もなし84%。イベント成立した同じマスは5ターン再抽選しない。共通バランス変数で変更できる。
- アンデッドの自然発生は、既存の抑制ルールである「1ターン最大2体」「同じマスは5ターンのクールダウン」を維持する。

## 3. 死の霧

### 地上

- 不浄イベントで死の霧が発生した場合、発生地点を中心として周囲1マスまで、最大7マスを死の霧にする。
- 発生時の浄化低下は、中心マスを `-2`、周囲1マスを `-1` とする。
- 死の霧が存在しているマスは、霧が残っている間、毎ターン浄化値を追加で `-1` する。

### 洞窟

- 洞窟内で死の霧が発生した場合は、発生地点を含む **1エリア全体** を死の霧で覆う。
- 洞窟の1階層全体へ自動的に広げる旧仕様は使用しない。
- 「1エリア」は部屋単位で、次の部屋・エリアへ切り替わる境界までの範囲とする。部屋・通路の接続床全体をひとまとめにして階層全体へ広げない。
- 通路の所属と部屋の切替境界は生成時のエリア情報へ接続する。部屋内を起点に隣接床へ距離順で所属を割り当て、通路途中で別の部屋エリアへ切り替える。旧マップで部屋情報がなければ接続床単位へ補完する。複層Z座標は採用せず、現行の平面マップ・ワールド切替を維持する。
- 死の霧による浄化低下の基本ルールは地上と共通とする。ただし、洞窟1エリアへ適用する際の中心・周辺の扱いに追加調整が必要な場合は別途確定する。

## 4. 魔法で生成したアンデッド

- 魔法によって死者・アンデッドを発生させた場合、生成時に術者側で所属を選択できる。
- 選択肢は「自分の部隊へ入れる」「フリーBotとして解き放つ」の2つとする。
- 自分の部隊へ入れた場合は術者側の所属として扱う。
- フリーBotを選択した場合は、プレイヤーの直接命令を受けず、アンデッドAIで自律行動する。
- 自然発生したアンデッドはフリーのアンデッドとして扱う。

## 5. アンデッドAI

- アンデッドAIは、攻撃対象の選定時にアンデッドを対象から除外する。
- 所属勢力が異なる場合でも、AI判断ではアンデッド同士を基本的に攻撃しない。
- プレイヤー所属のアンデッドも、アンデッドAIによる能動攻撃の対象から除外する。これは意図した仕様とする。
- ただし攻撃を受けた場合は、攻撃者がアンデッドでも通常の反撃条件を満たせば反撃する。能動攻撃対象の除外を反撃禁止やダメージ無効へ流用しない。
- 周囲にいる非アンデッドを主な攻撃対象とし、撃破と成長によって勢力を拡大する方向で行動する。
- 移動、索敵、攻撃、AP消費などの基礎処理は既存の敵AI・戦闘処理を再利用し、アンデッド専用に同等処理を作り直さない。
- プレイヤーが直接操作しているアンデッドについて、手動攻撃まで禁止するかは本項では確定しない。今回確定するのはAIの攻撃対象選定ルールとする。

## 6. アンデッドの成長と上位化

- アンデッドは敵を倒して経験値を得てLvが上がる。
- 一定の成長条件を満たしたアンデッドは、上位アンデッドへ発展する。
- 上位アンデッドへの具体的な必要Lv、進化先、種別ごとの対応表は未確定。
- 上位アンデッドは指揮官として扱い、周囲のアンデッドを率いる集団・社会形成の起点になる。
- 指揮下へ入れる範囲、配下上限、複数の上位アンデッドが存在する場合の所属決定は未確定。

## 7. 死の刃による不浄化

- 上位アンデッドというだけで撃破対象を即時・無条件にアンデッド化する旧案は使用しない。
- スキル「死の刃」を持つユニットが敵を倒したとき、死体が残る撃破マスの現在の浄化値を `5` 減らす（`適用後の浄化値 = 現在の浄化値 - 5`）。
- `-5` へ固定する効果ではない。例: 浄化値 `3` は `-2`、`-4` は `-9` になる。浄化値の上限・下限は別途確定する。
- この効果はマスの不浄化であり、撃破直後のアンデッド生成を保証しない。発生は共通の不浄イベント判定へ接続し、自然発生数上限と同マスクールダウンを維持する。
- スキルを持たない上位アンデッドに同じ効果を自動付与しない。プレイヤー・AIで同じ撃破効果を使う。
- 死体を消費してアンデッドを生成する際の種別・継承情報は、下記「死体からの継承」に従う。所属選択は引き続き未実装。

## 8. 実装状態（2026-10-13）

- 2026-10-17: `v39-death-purification.js` に死亡遷移と保護判定を集約。状態ブリッジの通常更新/敵AI高速更新/自軍更新から呼ぶ。実際に死亡候補がいる時だけ旧ユニットを検索し、同じ死体を重複計上しない。表示中/保存済みワールドへ別々に反映し、非表示マップは変更対象だけ複製する。`map.deathPurificationProtection` にターンと拠点別使用数を保存する。専用確認は `npm run check:cemetery`。

- 実装済み: マスの浄化値、死体/死の霧による毎ターン低下、不浄イベントの排他的抽選、地上7マス/洞窟1エリアの死の霧。
- 実装済み: 死の刃所持者の撃破マスを現在値から5減らす。プレイヤー・敵/反撃・村戦闘が同じ処理を使用する。
- テスト専用データに死の刃を追加し、戦闘試験官Lv11で取得する。通常クラスへの正式割当ては原本での追加が必要。
- 実装済み: アンデッドAIはプレイヤー所属を含むアンデッドを能動攻撃対象から除外する。攻撃された相手への反撃・報復は通常処理を維持する。
- 自然発生は同ワールドで最大2体/T・同じマス5T。死の霧内の既存死体変化は有限の死体と配置先に制約され、別途この上限を適用しない。浄化-5以下で発生源100%、その他50%。個体死体のLvは下記の継承計算に統一する（旧発生源+3Lvは出自不明の資源死体に限る）。生成成功時のみ死体を消費する。
- 発生したばかりの死の霧から同じターンにアンデッドを重ねて生成しない。次ターンから死体変化を判定する。
- 調整先: V39_UNDEAD_SPAWN_BALANCE / V39_FOG_BALANCE。浄化・エリア・抽選済みターンはセーブ対象。
- 未実装: 魔法生成時の自軍加入/フリーBot選択、上位化・指揮官化・集団/社会形成。旧即時無制限増殖は採用しない。

## 霊廟での遺体保管（2026-10-17）

- 信仰施設「霊廟」を原本「施設」37行に追加。暫定条件は信仰Lv1・建築2ターン・建築数/保管数上限なし。費用は既存の施設費用数式から生成する。`格納種別:死体` を共通施設一覧で判定する。
- 拠点→運用→施設→霊廟→「回収する」。同じワールドの施設上/隣接1マスにある自軍/敵の個体死体と、既に回収済みの自軍遺体から選択して「回収して保管」。他プレイヤー所有の死体・生体・召喚体・期限切れのフィールド死体は対象外。数値だけの資源「死体」は対象外。
- 同マスへ移動しただけでは遺体そのものを自動回収しない。既存の荷物回収は継続し、持ち切れなかった荷物は死体に残す。一般村の死体は今回の保管対象外。
- 保存先は `deadUnitReserve[].corpseStorage`（施設名/マス/世界/残存ターン）。フィールドと部隊から取り除き、元種族・取得クラス/各Lv・装備・荷物・魂回収済みの印を保持する。生体格納/魂保管/合成用素材へ二重登録しない。
- 保管遺体はフィールドの死体・霧発生数・自然アンデッド化候補に含めず、死体に由来する浄化低下も発生しない。既に発生した死亡時の浄化-1や、その土地自体の霧効果は取り消さない。墓地の死亡2件保護とは別。
- 取り出すと霊廟マスへ死亡状態・AP0で配置し、保管時に残っていた消滅期限から再開する。保管中の蘇生は不可、取り出して通常の蘇生/アンデッド化を行う。保管中は施設や領土を失ってもデータを消さず、同じ自軍施設を復旧するまで取り出せない。
- セーブ/読込時は遺体の死亡状態を保持して派生能力を再構築する。合体テストに霊廟(5,5)、保管済みホース/ウルフ/デヴィルの遺体3体と、回収確認用ホースの死体(6,5)を配置。`npm run check:corpse-storage` でスマホ/PCの実UI・回収・保存・自然処理除外・取り出しを検証する。

## 10. 死体からの継承（2026-10-14）

- 死の霧・不浄イベントによる個体死体の変化と、効果 `アンデッド化` は共通処理を使う。
- 元種族を保持し、アンデッド職を現職にする。元の取得職は前提職一覧として保持する。元種族の内部Lvと、各取得職のLvを **それぞれ半分・切り捨て** にする。種族の初期ボーナスLv5は継承Lvの計算へ足さない。
- アンデッド職Lvは `min(10, floor(元総合Lv / 2))`。新しい総合Lvは、半減した種族Lv＋半減した全取得職Lv＋アンデッド職Lv。端数は合計後ではなく各項目で切り捨てる。
- 例: オーガ種族Lv8＋ファイターLv10＋ウォーリアーLv7（総合25）→種族4＋ファイター5＋ウォーリアー3＋アンデッド10（総合22）。強敵の追加属性職も半減して継承する。
- 残存する装備だけを引き継ぐ。空の装備を初期装備で埋めず、持ち去られた装備を再生成しない。携行荷物は既存と同じく地上へ残す。軍隊の編成人数・戦闘倍率は保持する。
- Lv配分を `undeadGrowthStart` と `prerequisiteClassLevels` へ保存し、能力・技能・取得スキルとロード時再計算へ反映する。半減後Lv0の職は引き継がない。総合Lv0になる死体は生成せず残す。
- ゾンビ・スケルトンは元種族の専用画像を参照する。動物は既存の動物専用アンデッド画像を使う。ゴーストの画像は元種族に依存しない。
- 現行の `アンデッド化` はゾンビ/スケルトンから従来の重みで選ぶ。魔法生成は現在、自軍の単独ユニットとして加入する。所属選択、ゴーストを明示生成する効果書式は未実装。
- 自然変化の確率・霧条件は維持する。魔法は霧・浄化条件を必要とせず、選択範囲の同ワールドの死体を対象にする。生成可能な死体/空きマスがない場合、詠唱開始前に拒否する。通常のAP・詠唱・CTは共有する。
- 出自情報のない旧「死体」資源は元種族・装備を復元できないため、従来の汎用個体生成を維持する。個体死体の情報を新たに捨てる処理は追加しない。
- 検証: `scripts/check-v39-undead-inheritance.mjs`。取得職ごとの半減、上限10、装備0/残存、種族別画像、自然変化、実際の行動欄からの発動、Lv0拒否、AP/CT、保存復元を確認する。
