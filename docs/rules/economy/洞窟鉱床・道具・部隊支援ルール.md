# 洞窟鉱床・道具・部隊支援（2026-10-13）

この文書は今回の暫定実装の現行ルール。正式数値が決まったものとは区別する。
生成JSONは直接編集していない。シートに存在しない道具・研究・クラスは `config/v39-expedition-defaults.json` で補完する。
正式な同名の道具・クラス・研究が存在すれば正式行を優先する。部隊支援の判定・補正と村の追加依頼はまだこの仮設定を使用する。
シートへ移す際は項目と読込処理を一緒に移行する。薬系研究・製造施設・道具・装備の道具枠を原本へ反映し、対象JSONを再生成済み。道具は正式行を使用するが未確定のバランス値は暫定とする。

## 鉱床の自動輸送・入口警備

- UI209: 手動採取は単独でも可能。単独は本人の `cargoByUnitId`、部隊は共有 `cargo` を使い、採取の詳細欄に「手持ち 現在量/容量」と資源・装備の内訳を表示する。容量は既存SIZ計算と都市補正を共用し、別ワールドの部隊員を容量に加えない。単独一覧の他ユニットは採取・回復の仲間扱いにしない。
- UI216から洞窟内の鉱石/宝石は累計AP100で1個。残りAPでも進捗を担当者/地点別に保存し、取得数だけ鉱床残量を減らす。積載余力が1未満ならAP・鉱床残量を消費しない。自拠点へ戻った際は既存の搬入処理で荷下ろしし、鉱石は鉄として加算する。荷物は既存のセーブ対象で、新しい在庫データを重複作成しない。
- 検証: `scripts/check-v39-gather-cargo-headless.mjs`。単独/部隊、容量表示、満載時の消費なし、旧単独データ、保存復元、帰還搬入と二重搬入防止をNodeで確認。画面確認はユーザー側で行う。

- 2026-10-18更新: 新規の運搬は左の「物流」タブに集約し、部隊/単独1体で物資・数量・運搬元/先・往復を設定する。基本行動の大きな運搬設定は撤去し、入口警備は土地タブに分離。現在の正本は [物流・運搬ルートルール.md](物流・運搬ルートルール.md)。以下は既存の軍隊単体任務の互換処理を含む。

- 攻略して鉱床化した奥地の運搬は物流へ表示し、旧軍隊輸送も中断/再開/解除できる。担当軍隊の入口警備/解除は土地タブから操作する。
- 担当軍隊・搬入先の選択は同じプレイヤー/奥地の更新で保持する。候補が消えた場合は有効候補へ戻し、別プレイヤー/奥地へは引き継がない。軍隊の状態表示だけが変わる場合は選択欄自体を再作成しない。
- 担当は自軍の生存軍隊のみ。輸送・教官任務との兼任は不可。通常の個別積載物は先に荷下ろしする。
- 地上に物理入口が接続されている鉱床が対象。地上を持たない洞窟単独テストでは輸送経路がないため指定できない。
- 自分の操作ターン終了時、残りAPで通常経路を歩く。階層入口の通過は暫定AP20。瞬間移動・無料移動はしない。
- 輸送は奥地入口まで移動して現地在庫を積み、次の操作ターン終了から拠点へ戻る。拠点の占有マスで搬入し、再び往復する。
- 積載上限は既存のSIZによる運搬容量。鉱床の汎用「鉱石」は搬入時に「鉄」へ変換し、宝石は宝石のまま在庫へ加算する。
- 任務・積載物・往復方向・処理済みターンを保存する。同じターンの二重処理を防ぐ。積載中は任務変更不可。
- 鉱床を失っても積載分は拠点へ搬入できる。空荷になった後は停止し、行動欄の任務から解除可能。
- 警備指定は地上の入口へ移動して駐留する。既存軍隊を使い、専用警備NPCを増やさない。戦闘は通常の攻撃・反撃・敵AIを使う。
- 通路・入口が生存ユニットで塞がれていれば停止して次のターン再試行する。複数入口には別の軍隊を配置する。自動指定は主入口を使用。

調整箇所: `frontend/src/lib/v39-gameplay-balance.js` の `V39_CAVE_MINE_BALANCE`。

## 地上生物の実侵入と再巣化

- 所有鉱床へ繋がる入口の周囲3マスにいる実個体が、通常移動APで入口へ向かう。戦闘中、または周囲2マスに生存プレイヤーユニットがいる場合は通常AIを優先する。
- 入口に生存する所有者の軍隊がいる間は侵入不可。警備を倒すか警備が離れない限り通過しない。別プレイヤーや洞窟側の入口占有も通過を阻む。
- 入口通過時に地上の個体・元部隊から除外し、同じIDのまま地下へ移す。巣の食料があれば暫定上限20を持ち込み、元巣の在庫から差し引く。
- 奥地鉱床へも床通路・物理出入口を通って進む。各階層間の移動APと生存者の占有を判定する。
- 鉱床内の同種族2体・必要食料が揃い、プレイヤー不在で5ターン経過すると巣と新ボスを作り、鉱床所有を解除する。プレイヤー滞在は1ターンにつき進捗1を戻す。条件不足時は進捗保持。
- 残った鉱床在庫は新しい巣の物資へ移す。侵入者が生存する間は既存の採掘停止ルールが働く。
- 未鉱床化の攻略済み奥地の再巣化は、従来の仮流入方式を維持する。今回の実侵入は所有鉱床に繋がる入口が対象。

調整箇所: 同ファイルの `V39_CAVE_NEST_BALANCE` と `V39_CAVE_MINE_BALANCE`。

## 薬草・水薬・霊薬・聖水の携帯と使用

### 確定仕様（2026-10-13、基本処理を実装済み）

- 薬草は持続回復用の天然素材兼回復道具とする。即時回復はなく、次のターンからHP5回復×6ターン、基礎合計回復量30とする。
- 水薬は標準回復薬とする。基礎即時回復HP20に加え、次のターンからHP5回復×6ターンを持ち、研究補正なしの基礎合計回復量は50とする。
- 霊薬は魔法の力を込めた上位回復薬とする。基礎即時回復HP80のみで、継続回復は持たない。
- 最大HPを超えて回復しない。死者の回復・蘇生には使用しない。
- 薬草と水薬の継続回復は同系統として加算しない。新たに継続回復を使用した場合は、後から使用した効果で残り期間を上書きする。
- 薬系研究Lvによって、即時回復を持つ薬の即時回復量を `研究Lv × 5` 増加させる。薬草は即時回復を持たないためこの補正対象外とする。
- 水薬の即時回復量は `20 + 薬系研究Lv × 5`、霊薬は `80 + 薬系研究Lv × 5` を基本式とする。
- 薬系研究Lvは薬の携帯上限を増加させない。携帯上限そのものの正式個数は別途確定し、現行の暫定3個を自動的に正式値とは扱わない。
- 薬系研究Lvによる生成量補正は、Lv1〜2は基礎生成量、Lv3〜4は基礎生成量+1、Lv5〜6は基礎生成量+2、Lv7以上は基礎生成量+3とする。
- 生成量補正は生産・加工時にのみ適用し、戦闘へ持ち込める個数は増やさない。
- 道具・アイテムデータの `必要素材` は1セルで管理し、`素材名_個数/素材名_個数` の形式で記載する。`/` は素材同士の区切り、`_` は素材名と必要個数の区切りとし、空白は入れない。素材が1種類の場合は `薬草_1` のように記載し、必要素材がない場合は空欄とする。
- `必要素材` の例として、霊薬は `薬草_2/宝石_1` とする。変換時はこの記法を素材名と個数へ分解して扱い、シート側で `必要素材1` / `数量1` / `必要素材2` / `数量2` のような固定列を増やさない。
- 水薬の製造機能は「調薬所」の完成で解禁し、調薬所は魔法Lv2で建造可能とする。
- 霊薬の製造機能は「霊薬工房」の完成で解禁し、霊薬工房は魔法Lv5で建造可能とする。
- 薬系の個別研究は水薬・霊薬の製造機能そのものの解禁条件にはせず、即時回復量・生成量などのボーナスを与える。
- 基礎生成量、水薬など霊薬以外の未確定な必要材料、正式な携帯上限は研究・道具データ作成時に別途確定する。

### 聖水・浄化（2026-10-13、実装済み）

- 聖水は信仰系の消耗品とし、HP回復効果は持たない。使用したマスの「浄化」値を上昇させる。1回あたりの上昇量は未確定。
- 聖水は「教会」の完成で製造可能とし、製造には信仰系の担当者を配置する。必要クラス・必要クラスLv、必要素材、基礎生成量は未確定とする。
- 神殿は聖水の基本製造に必須とはせず、聖水の生成強化または上位の聖用品を扱う施設候補とする。
- マスの浄化値は `0` を中立とし、負の値を不浄が蓄積した状態として扱う。正方向の上限・負方向の下限は未確定であり、`-10` はまだ正式値としない。
- 死体が放置されているマスは、死体が残っている間、毎ターン浄化値を `-1` する。現行は死体数が増えても1/Tとし、同マスの低下量を増やさない。
- 浄化値が `-5` 以下のマスは不浄イベントの発生候補とする。`-4` 以上では浄化不足を理由としたアンデッド・死の霧の発生判定を行わない。
- 不浄イベントでは、同じマス・同じターンに死の霧とアンデッドを同時発生させず、「死の霧」「アンデッド」「何も発生しない」のいずれかとして判定する。各結果の確率は未確定とする。
- 不浄イベントで死の霧が発生した場合、発生地点を中心として周囲1マスまで（最大7マス）を死の霧にする。発生時の浄化低下は中心マス `-2`、周囲1マス `-1` とする。
- 死の霧が存在しているマスは、霧が残っている間、毎ターン浄化値を追加で `-1` する。
- アンデッドの自然発生は既存の抑制ルールである「1ターン最大2体」「同じマスは5ターンのクールダウン」を維持する。
- 死の霧そのものの発生確率、不浄イベントの具体確率、浄化値の自然回復は今回確定しない。現行は浄化-5以下からの排他的イベントへ接続済み。詳細と暫定確率はアンデッド・不浄ルールを参照。

### 現在の使用・製造・補充

- 自キャラステータスの装備タブとユニット作成画面でデフォルト携帯を指定する。装備の道具枠は鎧1/服2/法衣3/装備なし0。軍隊全体で1ユニット分を扱う。
- 生存する操作キャラの行動欄に、使用可能枠に携帯在庫がある道具を出す。説明確認→実行。暫定AP20、同じ道具は1ターン1回、使用は1個消費。
- 薬草: 即時0、次ターンから5×6T。水薬: 即時20、5×6T。霊薬: 即時80、継続なし。完成した薬系研究の薬即時回復列を合算し即時回復へ加える。継続回復量は増やさない。
- 製造担当者が地上の自軍拠点内にいて、対象施設が完成・健全なら行動欄から製造予約できる。水薬=調薬所、霊薬=霊薬工房、聖水=教会、煙玉=魔術工房。研究Lvは施設建設側の条件、個別薬研究は製造解禁には不要。
- 必要素材を予約時に支払い、施設種別ごとに1予約を保持。担当者不在/死亡・施設損壊で停止し、条件復帰で再開。全勢力ターン一巡で進み、完成品は現地在庫へ加算。行動欄の製造中カードから取消し、素材を元の在庫へ返せる。二重返却しない。
- 薬生成量列の完了研究を合算し、薬の基礎生成量へ最大+3。原本はLv3/+1、Lv5/+1、Lv7/+1。携帯上限は増やさない。
- 聖水はHP回復なし、使用したマスの浄化を暫定+5。製造担当者の信仰は暫定1以上。煙玉は選んだ射程内の1マスへ通常霧を暫定3T設置。死の霧を通常霧で上書きしない。
- 必要素材は原本の素材名_個数/素材名_個数形式。暫定は水薬=薬草1、霊薬=薬草2/宝石1、聖水=薬草1、煙玉=木材1。基礎生成量1、製造1T、携帯上限3は暫定値。
- 補充は現地の完成品を本人のデフォルト携帯不足分だけ消費して受け取る。研究完了だけで薬草→水薬をその場加工する旧処理は廃止。無償補充・遠隔拠点在庫の引落しはしない。
- 洞窟の発見済み薬草/キノコ群生地の周囲1マスから、暫定AP30で素材1を採取。採取用在庫は最大3、5Tごとに1再生。従来の群生地休息回数とは別。
- 携帯素材・道具は拠点内で預けられる。死亡時は死体荷物へ移り、回収可能。死亡処理の重複で増殖しない。キノコの使用効果は未確定。
- 在庫・デフォルト携帯・製造予約・継続回復・使用済みターン・群生地再生記録は保存対象。共通処理はv39-consumables.js、暫定値は道具シートとV39_CONSUMABLE_BALANCEを参照。

## 部隊支援の暫定値

- コマンダー: 生存して同じ部隊・同じワールドにいる他のメンバーへ攻撃/防御/命中+5。自分自身には付かない。
- ロードナイト（ルビ: 王の騎士）: 同じ部隊・同じワールドに生存する王（`isSovereign`）がいる場合、自身の攻撃/防御/精神+10。
- 同種指揮官が複数いても重複しない。死亡・離脱・別ワールドで解除する。再描画・派生能力再計算で恒久加算しない。
- 能力表示・実戦計算・敵AIの判断へ接続する。暫定クラスはナイト/ファイターの基礎データを使用し、Tier2・前提職Lv10として補完する。
- 2026-10-13: クラス名依存の支援分岐を廃止。部隊指揮/王への忠誠を試作クラスのSkill1で取得し、共通の対象/部隊条件パッシブで処理する。書式はスキル効果対応状況.md。正式なクラス/CS原本への転記と補正バランス確定は残作業。

## 一般村の追加依頼

- 「村の周囲を警備」: 受注後、村の周囲1マスに自分の生存ユニットがいるターンを3回数える。不在中は進まない。地下ユニットは数えない。
- 「近隣拠点の施設整備」: 村から8マス以内の自軍拠点で、受注後に新たな施設を1つ建設する。建設待ちや受注前の既存施設は数えない。
- 報告して友好度を暫定12獲得する。二重報酬を防止し、従来の依頼クールダウンを使う。
- 既存の物資納品は、受け取る側の村の現地在庫にも加算するよう修正した。
- 既存の受注・報告UIを共用し、進捗と条件を表示する。村の汎用イベントエンジン全体が完成したという意味ではない。

## 手動確認用の追加テストデータ

- 自動任務は空いている迂回経路を優先するが、迂回できない場合は途中の自軍ユニットを通り抜けられる。味方が連続している場合も、その先の空きマスまで通常APを払えるときだけ通過し、AP不足なら手前の空きマスで停止する。目的地が占有されている場合は手前で「味方ユニットの移動待ち」となり、空けば再開する。重なった状態で停止・押し退け・瞬間移動はしない。敵・壁・通行不能地形は引き続き経路を遮断する。拠点間輸送・教官移動にも同じ経路処理を使う。

- 自動輸送がONのユニットと鉱床の輸送/警備任務中のユニットは、ターン終了時の未行動確認対象から除外する。未操作・AP満タンでもターン終了可能。自動任務は通常のターン終了処理で進める。任務中の経路閉塞は再試行するため除外を維持するが、拠点間輸送をOFF/解除したユニットは通常の確認対象へ戻す。
- `scripts/check-v39-auto-turn-end.mjs` で、自動担当が先頭にいても手動キャラを確認し、手動キャラ待機後は通常のターン終了が成功すること、停止後に再び確認されることを検証する。

- テストモードの「テスト」タブ → 「鉱床・道具・部隊支援」から開始する。現在のゲームを置き換えるため、確認ダイアログを表示する。必要なゲームは先に保存する。
- 「輸送・道具・支援テスト」: 地上24×24と地下14×14を用意する。検証拠点、所有鉱床（鉱石10・宝石5）、発見済み薬草群生地、一般村を配置する。
- 支援検証王・指揮官・王の騎士を同じ部隊へ配置。能力欄で指揮官補正と王の騎士の条件付き補正を確認する。
- 道具試験官は地下に配置し、HPを半分にする。薬草・水薬を各2個、素材薬草を5個持つ。行動欄から使用・採取を確認する。
- 鉱床輸送兵は自動輸送を設定済み。通常のターン終了を進めて鉱床在庫の積込と検証拠点への搬入を確認する。
- 入口警備兵は任務未設定。鉱床表示中の行動欄「鉱床の運搬・入口警備」で輸送兵の任務を解除してから、入口警備兵を選び警備を指定する。通常の移動・AP消費で入口へ向かう。
- 一般村（10,5）を選択し、土地タブで警備・施設整備依頼を受注する。警備は周囲1マスへ地上ユニットを移動、整備は検証拠点に新しい施設を建てて報告する。事前配置の兵舎は整備実績に数えない。
- 「侵入・再巣化テスト」は別シナリオ。軍隊の任務を未設定にし、地下の味方を地上へ配置して、入口付近へウルフ2体と食料のある巣を置く。通常ターンの移動・侵入と、不在5ターン後の再巣化を確認する。
