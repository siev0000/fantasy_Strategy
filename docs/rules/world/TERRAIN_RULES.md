# 地形生成ルールメモ

## 目的
- 島マップを安定生成し、プレイしやすい平地ベースを維持しつつ、山・丘・森・川の地理的な納得感を出す。

## 現在の実装フロー
1. マップサイズと島形状から、今回配置する勝利対象土地の種類・必要地形を先に決める
2. 全マスを `海` で初期化
3. `島形状パターン` を使って陸地を生成
4. 高度マップを生成（島中央ほど高く、海沿いほど低くなりやすい）
5. 高度順位で `山岳` / `丘陵` / `平地` を割り当て
6. 森クラスタを生成
7. 砂漠クラスタを生成（最低6塊、縦中央帯バイアス）
8. 孤立補正（孤立山→丘、孤立森→平地）
9. 地形まとまり補正（塊に寄せる同化）
10. 湖・雪原・火山を条件生成
11. 事前計画に従い、実際に選ばれた勝利対象に関係なく全種類の成立地形を生成する。中心から半径3の必要核は保証するが、対象を地形の輪郭から特定できないよう外縁は不規則に生成する。宇宙の海は半径3を確保できる自然の深海域を使う
12. 高度Lvと川を生成する（川は地形上への重ね表示）

勝利対象土地の正確な座標は、全勢力の初期拠点が決まった後に確定する。これにより、対象の種類と成立地形はマップ生成前から決まっている一方、初期拠点からの最低距離も維持する。

## 勝利対象用地形

- 地形だけで実際の勝利対象を判別できないよう、以下の成立地形は毎回すべて生成する。実際の勝利対象マーカー・守護者・勝利判定を付けるのは事前計画で選ばれた対象だけとする。
- 勝利対象本体: 大都市と同じ中心＋周囲6マス、合計7マスを占有する。占領時は7マスを一括で領土化し、7マスすべての支配を勝利判定に使う。
- 太陽の山: 本体7マスの外側へさらに2リングを確保し、中心から半径3の37マスを必須山岳核にする。さらに約50%の山岳を不規則に追加する。中心高度Lvは、そのマスを除くマップ最高高度Lvより1高くする。
- 星の火口: 本体7マスの外側へさらに2リングを確保し、中心から半径3の37マスを必須山岳核にする。さらに約50%の山岳を不規則に追加し、中心と隣接6マスのうち3マスを火山にする。
- 黄昏の樹: 中心から半径3の37マスは必ず森林にする。総森林数は36〜47で61マス、48〜60で91マス、61〜72で127マス、73〜100で169マスとし、外縁へ必ず張り出しを作って正六角形を崩す。
- 宇宙の海: 島生成によってできた高度Lv-1以下の海域を利用し、本体外側2リングを含む半径3・37マスが海である地点へ置く。
- 高地型3種は中心から外側へ高度Lvを1リングごとに1段ずつ下げる。対象地形の外側にも必要な麓を延ばし、飛行なしでも隣接高度差1以内の経路で進入できるようにする。
- 必須核の外側は全種類で自然または不規則な輪郭を使い、半径3だけの整った六角形を対象判別の手掛かりにしない。
- 半径、外縁追加率、火山数、高度勾配、マップサイズ別森林規模は `V39_VICTORY_LANDMARK_BALANCE.terrainGeneration` で調整する。

## 島形状パターン
- `標準諸島 (balanced)`
- `リアル島 (realistic)`
- `大陸型 (continent)`
- `多島海 (archipelago)`
- `双子島 (twins)`
- `列島型 (chain)`

## 地形ごとの主ルール

### 平地
- 島内の基準地形。まず陸地を平地化してから他地形を上書きする。

### 山
- 高度が高いマスから優先して割り当てる。
- 島中央ほど高度が高くなりやすいため、山岳は中央寄りに出やすい。

### 丘
- 山岳に次いで高度の高いマスへ割り当てる。
- 中央高地の周辺帯に形成されやすい。

### 森
- 平地/丘を対象にクラスタ生成。
- 山周辺が過密な場所は優先度を下げる。

### 砂漠
- 陸地の `35%` を目標に生成。
- 最低クラスタ数は `6`。
- 海に隣接しない平地を中心に生成。
- 縦方向バイアスあり:
- 画面中央（上下の中間帯）で高確率
- 上端/下端へ行くほど低確率

### 湖
- 後処理のみで生成（直接候補には入れない）。
- 条件:
- 山岳が2マス以上隣接（山麓）
- または森が4マス以上隣接かつ海隣接なし（森の中心）
- 上限: マップ総マスの `3%`
- 追加:
- 砂漠タイル群の重心（砂漠中央付近）に `オアシス湖` を1つ優先配置
- オアシス条件:
- 候補マスの周囲6近傍のうち、5以上が砂漠であること

### 川
- 山岳を起点に海/湖へ向かう流路を作る。
- `河川` タイルに置換せず、`川オーバーレイ` として地形に重ねる。
- 例: `山 + 川`, `丘 + 川`, `平地 + 川`
- 流速仕様（暫定）:
- `流速 = 基本流速(1) × 勾配補正(高度差) × 地質係数 × (1 - 森林率×0.4)`
- 川計算のため、全マスが `高度` / `地質係数` / `森林率` を持つ前提とする。

## 魔法によるタイル変換

- アクティブスキルの `効果` を `○○_変換` とすると、対象タイルを `○○` へ変換する。
- 変換先は `地形.json` の `地形` 名から解決し、`変換レイヤー` を正本とする。
  - `基本`: `grid` の基本地形を置換し、そのマスの特殊地形を解除する。
  - `特殊`: 基本地形を残したまま `specialMap` へ特殊地形を設定する。
- 初回対応: `平地 / 森 / 荒野 / 砂漠 / 雪原 / 沼地 / 湿地 / 薬草の群生地`。
- `変換元許可=false` の地形、および現在溶岩が存在するマスは変換不可。
- 湖・海・河川・火山・溶岩・洞窟・峡谷などは、別の高度・水系・災害データとの同期が必要なため初回は変換対象外。
- 薬草の群生地は特殊地形として重ね、`回復=1`。確保中の薬草群生地1マスにつき、所属拠点の領土内ターン回復へ+1する。
- 初期テスト用として `ジオマンサー（地形術師）` に8種類の変換魔法を持たせる。
- タイル変換魔法は使用時に予約され、次のターン進行時に発動する。待機は `1T`。
- APと射程はJSONから調整する。射程値は共通尺度の10=1マスとして扱う。

## 表示仕様
- ヘックスは `pointy-top`（角が頂点）  
- 行オフセット方式で噛み合わせ  
- `mapGrid` 内で自動スケーリング表示
- `雪原` は基本地形として扱い、積雪・降雪表示とは分離する。
- `snowCoverMap[y][x] = true` のタイルは基本地形色・高度シェーディングを変更せず、既存の外枠線を残したまま、その内側約20%を白いリング状に描画する。
- `snowfallMap[y][x] = true` は現在雪が降っている表示状態とし、地形を変更せず小さな `❄` をタイル上へ表示する。
- 森・砂漠などの基本地形アイコン、特殊地形アイコンは積雪中も維持する。
- 現時点では積雪・降雪の表示基盤と保存状態のみ実装し、天候発生率・積雪開始・融雪などの本格天候ロジックは未実装。

## 主要調整パラメータ（現行）
- 島の陸地率: パターンごとに `landMin / landMax`
- 全サイズの多島海で、島シード数を維持したまま各島の陸地目標へ `1.2` を掛ける。陸地率の実効範囲は約 `33.6%〜48%`。調整場所は `map-generator.js` の `地形生成設定.島構成.多島海設定.平均島面積倍率`。カスタム島設定には適用しない。
- 山割合目安: 陸地の約 `14%`
- 丘割合目安: 陸地の約 `16%`
- 森割合目安: 陸地の約 `24%`
- 砂漠割合目安: 陸地の `35%`（最低6クラスタ）
- 湖上限率: 島面積（陸地）の `3%`
- 高度生成: 中央隆起 + 海岸減衰 + ノイズ + 平滑化
