# 攻撃エフェクト描画ルール

最終更新: 2026-10-07

## 1. 位置づけ

この文書は、v39戦闘で攻撃・魔法のエフェクトを「いつ」「どこへ」表示するかを定義する現行ルールである。

数値・攻撃判定・待機ターン・CT・ダメージ式そのものは既存の戦闘実装・データを正本とし、この文書では変更しない。

## 2. 共通ルール

- 攻撃エフェクトはスキルデータの `アニメ` を参照する。
- 攻撃技で `アニメ` が未設定の場合は、既存仕様どおり `斬撃` を既定値として使用する。
- 回復・強化などの支援技は、`アニメ` が未設定の場合に `斬撃` を自動表示しない。
- エフェクトは実際に攻撃・魔法が解決された対象マスへ表示する。
- 視界外の別ワールドや別マップで発生したエフェクトを、現在表示中のマップへ誤描画しない。

## 3. プレイヤーの通常攻撃

プレイヤーが自分の行動中に即時解決する攻撃は、従来どおり攻撃解決時に対象マスへエフェクトを表示する。

## 4. 敵から攻撃された場合

敵ターンでは、戦闘計算と表示を分離する。

1. 敵AIの戦闘結果を先に確定する。
2. 表示対象となる攻撃イベントを敵ターン演出へ渡す。
3. 対象マスへ攻撃エフェクトを再生する。
4. その攻撃に対応する戦闘フィードバックを表示する。

攻撃者が未発見・非表示であっても、**攻撃を受けた対象マスが現在の視界内にある場合は着弾エフェクトを表示する**。

ただし、攻撃者自身の未発見位置や視界外の移動経路を追加で公開するものではない。

## 5. ターン終了時に発動する待機魔法

`待機` により発動が予約された魔法・攻撃は、詠唱開始時ではなく、**待機ターンが満了して実際に効果が解決されるタイミング**で攻撃エフェクトを表示する。

ターン終了処理中はゲーム状態更新・複数ワールド処理・描画バッチが行われるため、現在表示中のワールドで発動した待機魔法のエフェクトは、ターン解決中に消費せず一度描画待ちへ送る。

その後、

1. ターン終了処理を完了する。
2. マップの描画バッチを解除して最新状態を反映する。
3. ターン処理用のローディング表示を解除する。
4. 対象マスへ待機魔法の攻撃エフェクトを再生する。

という順で表示する。

現在表示していない地下・別ワールドで解決された待機魔法は、現在のマップへエフェクトを表示しない。

## 7. 今回の確定事項

2026-10-07以降、攻撃エフェクトはプレイヤーの即時攻撃だけに限定しない。

- 敵から攻撃を受けた時も表示する。
- 待機魔法がターン終了処理で実際に発動した時も表示する。
- 表示対象外ワールドのエフェクトを現在マップへ誤表示しない。

この表示ルールは攻撃判定・ダメージ・AP・待機ターン・CTの計算ルールを変更しない。
