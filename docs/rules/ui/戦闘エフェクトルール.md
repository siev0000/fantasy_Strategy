# 戦闘エフェクトルール

## 魔法発動時の演出

- 魔法を発動したときは、術者位置にエフェクト設定の補助系カテゴリ「魔法詠唱」を表示し、最初のフレームが描画されてから詠唱エフェクトの再生時間の半分だけ待ち、対象位置で既存の攻撃エフェクトを再生する。速度100%では750ms。初期素材は「魔法陣」で、カテゴリ設定から変更できる。詠唱状態を示す足元の印とは別の再生演出。命中・ダメージの処理時点は変更しない。
- 攻撃者の短い動きは対象側の攻撃エフェクト開始に合わせる。ダメージ数字・状態値は攻撃エフェクトの再生時間の約75%で表示し、対象HPバー・ユニットカード・マップ上のHPと死亡表示はエフェクト終了後に反映する。敵ターンの再生も同じ順序にする。内部の戦闘結果は先に確定し、表示だけを遅らせる。
- カテゴリ設定には再生速度25～400%（初期値100%）を置く。攻撃系カテゴリには揺れ開始・揺れ終了・ダメージ表示の時点を再生全体の0～100%で置く。初期値は揺れ0～15%、ダメージ75%。開始と終了が同じなら揺れない。再生速度を変えても各時点の割合は維持する。威力500/1000の揺れ強度と威力1000超の暗転条件は維持する。

## 高威力攻撃の画面演出

- 攻撃スキルの表示威力が500以上なら、攻撃エフェクトの最初のフレームで小さな画面揺れを出す。1000以上では揺れを大きくし、1000を超えた場合だけ短い暗転も出す。魔法詠唱エフェクトの段階では発動しない。威力は現在の能力・持続強化を反映した値で、命中後の実ダメージによって変えない。
- 500未満と支援スキルでは発動しない。判定は戦闘エフェクトの再生時に一度行う。

## UI252: 災害の着弾アニメーション

- 落雷嵐の着弾も既存「落下・落雷」カテゴリを参照。帯電ループとは別の1回再生で、基本画像/倍率/位置をエディターと共有。旧手描き稲妻を廃止。保存先は従来どおりブラウザ内。


## UI251: 災害アニメーションの設定共有

- カテゴリの「落雷エリア（帯電）」は帯電1、「竜巻（災害）」は竜巻ループを使用。フィールドは `resolveV39FieldEffectDescriptor` で同じカテゴリの基本画像・倍率・回転・位置を取得し、画像側の色設定も共用する。基本画像はアニメーション追記フォルダのカタログから選べる。
- 帯電は各対象マス、竜巻は災害範囲全体に合わせる。落雷の着弾線、雨/雪/霧等の別方式の表示を画像アニメーションへ一括変換しない。設定の永続化は既存のブラウザlocalStorage/JSON出力を使用し、リポジトリへ自動保存はしない。

## プレビュー操作と威力拡大方向（UI163）

- 攻撃方向の選択欄は表示せず、プレビューのマスをタップして対象・方向を指定する。内部の方向値と距離入力は維持する。プレビュー表示倍率の初期値は100%。距離・範囲変更では自動縮小せず、「全体表示」でだけ画面へ収める。
- 「カテゴリ → 基本 → 威力による拡大方向」で縦横両方 / 横だけ / 縦だけを選択する。`powerScaleAxis` は `both` / `x` / `y`、未設定・不正値は従来どおり `both`。回転前の画像基準で指定し、威力不足による縮小にも同じ軸を使う。
- 通常の画像設定とカテゴリ設定へ保存し、JSON入出力・実戦の自動カテゴリ選択・通常再生・静止画・コマ送り・実マップ確認へ反映する。属性タブは着色の設定なので、この項目は表示しない。伸長ビームは既存の距離合わせを優先し、長手方向を拡大しない。選択した軸が長手方向だけの場合、威力では太さも変更しない。
- 共通プレイヤーへ `powerScale` と `powerScaleAxis` を渡し、`resolveEffectPowerAxes` で各軸へ一度だけ適用する。範囲のマス数・戦闘判定・災害の範囲は変更しない。素材全体表示は威力拡大を行わない。
- 竜巻は既存の共通カテゴリ定義を使用する。古い保存設定があっても追加カテゴリを読み込み、風大の4〜6コマを参照する。Node検証: `scripts/check-v39-effect-power-axes.mjs`。画面確認はユーザー担当。

## 竜巻のコマ範囲・常設再生（UI162）

- エフェクト一覧/分類へ「竜巻」を追加。素材を複製せず「風大.webp」の4〜6コマを参照する別名として登録する。定義は `config/v39-atmosphere-display.json.tornado` のsourceEffect/firstFrame/lastFrame。管理画面の通常再生・静止画・コマ送りも同じ範囲を使い、全画像表示だけは原本全体を表示する。

- 同じ画像は既存の共有テクスチャローダーを通じて複数個体/別ワールドで共用し、毎巡ロードしない。終了・視界消失・Scene休止/終了でstop/destroyし、画像/マスク/タイマーを破棄する。同期的に停止してから遅延ロードが完了しても再生し直さない。

### 威力による表示拡大（UI150）

- UI151/152: 正の威力が基準未満なら `威力 / 基準威力`、基準以上なら `1 + (威力−基準威力) / 増分威力` とする。初期は基準100・増分200・上限2倍。50→0.5倍、100→1倍、200→1.5倍、300以降→2倍。上限3なら500→3倍。極小威力は視認用下限0.1倍、威力0/不明の支援・素材プレビューは通常1倍。旧平方根方式は廃止。初期値/入力範囲は `config/v39-terrain-destruction.json` の `effect`、正規化/計算は `lib/v39-effect-power-scale.js`。対象マスや攻撃範囲/射程/命中判定は変えない。範囲の既存サイズ補正へ威力倍率を乗算し、範囲エフェクトにも1倍未満の縮小を許す。ビームは太さだけに適用する。
- 「管理 → 表示設定 → 威力によるエフェクト拡大」で基準威力/＋1倍ごとの威力/最大倍率を変更する。端末の `v39-display-settings-v1.effectPowerScale` に保存し、旧設定は初期値へ補完する。ゲームのセーブやマルチのホスト共有ルールには含めない。設定変更/初期化後は以後の再生と開いているプレビューへ反映する。地形ダメージ/戦闘ダメージ計算は変更しない。ロジック検証は `scripts/check-v39-effect-power-scale.mjs`。

## 1. 基本方針

### 発射元から対象への伸長（UI92 / 2026-10-23）

- 設定画面の「基本 → 表示位置・伸長」で、通常の着弾表示 / 発射元→対象（横画像：左→右） / 発射元→対象（縦画像：上→下）を選択する。設定キーは `placementMode`（`target` / `beam-x` / `beam-y`）。未設定・不正値は従来の `target`。
- 伸長時は発射元ユニットと対象マス中心の中点に置き、画像の指定軸だけを両者の距離に合わせる。攻撃方向へ自動回転し、倍率は太さだけに適用。移動する弾ではなく、発射元と対象を結ぶ表示。画像の透明余白もコマ寸法に含むため、ビーム用画像は長手方向の余白を少なくする。
- UI93: 角度補正は伸長時も編集・保存でき、攻撃方向に対する画像の角度へ加算する（縦画像はさらに−90度）。中点と長さは維持し、中点を中心に画像を回転するため、補正0以外ではコマの長軸端はユニット中心と一致しない。UI94: 位置X/Yも通常表示と同じローカル座標補正として有効。最終角度で回転した補正ベクトルを中点へ加え、長さは維持する。補正により描画端も移動する。向き設定のみ自動追従のため無効化する。範囲攻撃でも伸長を優先し、長さを範囲の外接円へ拡大しない。発射元なし・同一位置の場合は従来の着弾表示へ戻す。攻撃範囲やダメージ判定は変えない。
- 幾何計算は `v39-effect-transform.js` の `resolveV39EffectBeam` をフィールドとプレビューで共用。実再生/コマ送りは既存 `phaser-effect-player.mjs` の非等方拡縮で描画し、静止画にも同じ寸法を適用。前コマ残像・マスク・グラデーションガイドも寸法に追従する。
- 画像設定・カテゴリ設定の自動保存/JSON入出力に含める。旧設定は通常表示として読める。確認: `scripts/check-v39-effect-beam.mjs`（端点・距離・両軸・自身・再生/コマ送り・保存/入出力・実フィールドと攻撃カテゴリ自動選択）。
- 同一ブラウザ・同一オリジンのカテゴリ保存値は、ゲーム側の `getV39EffectCategories` → `resolveV39CombatEffect` → `playV39MapEffect` が再生ごとに参照する。ゲーム再起動や設定画面の再表示は不要。スキルの明示的な `アニメ` は従来どおりカテゴリ自動選択より優先する。属性タブではカテゴリ専用の伸長設定を表示しない。端末・URLが異なる場合の共有は自動ではなく、JSON入出力または配布デフォルト更新が必要。

### 攻撃時の自動選択（2026-10-10）

- UI148: 弓は独立カテゴリ（初期「射撃」）、毛皮は独立カテゴリ（初期「刺突」）。「射撃攻撃」「遠距離攻撃」は射撃カテゴリの別表記として解決する。別表記は `config/v39-effect-categories.json` の `aliases` を原本とし、表示名や設定を複製しない。検証は `scripts/check-v39-effect-attack-means.mjs` / `scripts/check-v39-auto-combat-effects.mjs`。明示アニメ指定と防御効果の優先は変えない。
- スキルの `アニメ` があれば最優先し、属性による自動着色を追加しない。複数画像の `:` 区切りも既存処理を使用する。
- 未指定の `攻撃手段:武器` は、メイン武器（武器1、なければ武器2）の切断→斬撃、貫通→刺突、打撃→打撃を使う。装備そのものの通常攻撃は、その攻撃行の `装備元` を使う。
- 現行装備シートには攻撃属性の専用列がないため、既存武器の分類は `config/v39-weapon-effect-types.json` に置く。将来、武器元データに `攻撃属性` があればそちらを優先する。生成JSONへ独自列は追記しない。
- 武器以外は攻撃手段と同名のカテゴリを選ぶ。未対応手段は斬撃、分類できない武器は武器カテゴリを暫定フォールバックとする。
- 着色はスキルに含まれる属性の正の威力値だけを比較する。攻撃者の属性ステータスや、系統名だけから色は選ばない。同値はスキル内の記載順。属性なし・値0は無着色。
- 属性のTint/グラデーション設定だけを反映し、属性装飾画像は自動追加しない。位置・向き・倍率は基本カテゴリ設定を使い、今回の再生だけへ適用する。設定画面の保存内容を上書きしない。
- 味方、敵、村防衛、蘇生、敵ターンの後再生は共通処理を使用する。設定画面を開かなくても配布デフォルトの属性色を使用できる。

### 設定画面の攻撃方向プレビュー（2026-10-10）
- 攻撃側・対象側に既存ユニット画像を表示する。6方向を選ぶと攻撃側の位置が対象の周囲へ切り替わる。対象位置にエフェクトを重ねる。
- 基本設定の「エフェクトの向き」は固定向き／攻撃方向に回転。回転は元画像の右向きを0度の基準として扱う。既存設定と旧JSONの省略値は固定向き。
- `orientToAttack` をエフェクト設定とカテゴリ設定の保存・JSON入出力に保持する。カテゴリ編集と属性プレビューを往復しても向きを維持する。

- スキル名ごとの個別ハードコードを増やさず、可能な限りデータ駆動で組み合わせを決定する。
- プレイヤー攻撃、敵攻撃、反撃、範囲攻撃で別のエフェクト再生基盤を作らず、同じ設定・同じ再生処理を使用する。

基本形は次の考え方とする。

```text
戦闘エフェクト
= 基本形状
+ Tint / グラデーション色調
+ 属性装飾
+ 威力によるScale
+ 範囲・炸裂によるScale / 配置
```

## 2. 属性付き攻撃の表現

属性攻撃は、基本形状を属性ごとに作り直すのではなく、基本形状へ色調と小型装飾を重ねる。

例:

```text
闇の斬撃
= 斬撃
+ 黒～紫系Tint / グラデーション
+ 小型の闇エフェクト / 粒子
```

同様に、以下のように再利用する。

- 炎の斬撃: `斬撃 + 赤～黄系グラデーション + 火花 / 小炎`
- 氷の斬撃: `斬撃 + 水色～白系Tint / グラデーション + 氷片`
- 雷の斬撃: `斬撃 + 青～白系Tint / グラデーション + 小型放電`

この考え方を斬撃だけでなく、飛翔弾、射撃、ビーム、爆発、薙ぎ払い、範囲放射等にも適用する。

### 2.1 2色グラデーション

- 1枚のエフェクト内で色Aと色Bを線形補間し、単色Tintとは別に2色グラデーションを使用できる。
- グラデーションON時は単色Tintよりグラデーションを優先する。
- 色A・色Bは任意に設定できる。
- 移動方向は `上 / 下 / 左 / 右` を選択できる。
- 移動速度は `% / 秒` で設定する。`0` は固定グラデーションとする。
- 色タブの `開始位置 / 終了位置 (%)` で色Aから色Bへ変化する範囲を指定する。各0〜100%、初期値は開始0%・終了100%。上下方向は画像上端から下端、左右方向は左端から右端を基準にする。
- 開始より手前は色A、終了より先は色B。開始と終了が近いほど境界がくっきりし、同じ位置なら段階的に切り替わる。開始が終了を超えるUI操作では、もう片方も同じ位置へ合わせる。
- `着色強度 (%)` は0%で元画像、100%で設定色の補正を最大適用する。単色Tintにも共通で使い、透明度やエフェクト全体の大きさは変更しない。
- 移動速度が0のときは上記の固定配置、移動中はその配色を色A→色B→色Aの周期で循環させる。
- フレーム内の色境界を描くため、再生対象の1コマだけを色加工する。通常コマと残像用の小型Canvasを再利用し、スプライトシート全体や全コマの加工画像は複製しない。
- 移動中は色境界の位相を時間で進め、色A→色B→色Aの連続パターンを循環させる。
- 例として炎表現では、赤と黄を指定して上方向へ移動させることで、色が燃え上がる方向へ流れる見た目を作れる。
- グラデーションはエフェクト画像そのものを複製せず、再生時の色処理として適用する。

## 3. 威力・範囲による大きさ

- 攻撃威力が高いほど、原則として基本エフェクトのScaleを大きくできるようにする。
- 通常範囲や炸裂範囲が大きい攻撃は、その範囲に合わせてエフェクトのScaleまたは配置数・配置位置を調整する。
- 範囲攻撃を必ず1枚の巨大エフェクトだけで表現する必要はなく、基本形状を複数地点へ配置する方式も使用できる。
- 威力からScaleへ変換する具体式、Scale上限・下限、範囲ごとの複数配置数はまだ未確定とする。
- 未確定の数値は実装時に共通設定へ集約し、スキルごとのコードへ固定値を散在させない。

## 4. 既存再生基盤の再利用

現行 `playV39MapEffect` は以下を扱い、新しいエフェクトシステムでもこの機能を再利用する。

- エフェクト名による再生
- `:` 区切りによる複数エフェクト列
- `scalePercent`
- `angleDeg`
- `tint`
- `gradientEnabled`
- `gradientColorA`
- `gradientColorB`
- `gradientDirection`
- `gradientSpeedPercentPerSecond`
- `colorStrengthPercent`
- `hueAnimationDegPerFrame`
- `grayscaleBase`
- `renderStyle`
- 再生時間・シーケンス間隔

現行の通常再生時間は1.5秒を基準とする。
同等のTint・グラデーション・Scale・複数再生機構を別実装として作り直さない。

管理画面で設定した上書きは、既存の `playV39MapEffect` 内で解決する。
そのため、プレイヤー攻撃・敵攻撃・反撃等で別々の設定処理を持たせない。
設定画面内プレビューも `v39-effect-player.js` が解決した同じ再生情報を使用し、設定画面専用のエフェクト名・Tint・グラデーション・Scale定義を持たない。

同じ見た目・用途で統合できるものは統合し、既存スキルを分類できない場合だけ新しい基本形状を追加する。

## 6. エフェクト設定画面

タイトル画面とゲーム中の管理タブの両方から `エフェクト設定` を開けるようにする。
どちらの導線でも同じ設定画面・同じ設定状態・同じ `localStorage`・同じJSON入出力を使用し、タイトル専用の設定データや設定UIは別に持たない。
タイトル・管理の両方から同じ全画面モーダルを開く（UI126）。下画面内への埋込み・入口ごとのDOM移動は行わない。スマホは画面全幅・全高、PCは最大幅1100px・画面全高で表示する。ヘッダーとプレビューを残し、設定項目は独立スクロールする。戻る操作は入口に応じて `← タイトル` / `← 管理` とし、Escapeでも閉じて開いたボタンへフォーカスを戻す。「実マップで確認」は有効なマップがある場合だけモーダルを閉じて再生する。設定状態・保存形式・再生エンジンは共通のまま維持する。
設定画面は仮データではなく、起動時に読み込まれた実際のエフェクトカタログを直接参照する。

### 6.1 スマホ向け画面構成

設定画面はスマホ縦持ちを主対象とし、縦方向を次の2領域へ分ける。

```text
上部: エフェクトプレビュー
下部: 設定項目
```

- 上部には対象エフェクト選択と再生ボタンを置き、その下のプレビュー領域で選択中エフェクトを再生する。
- 上部プレビューはマップ生成前でも使用できる独立した小型Phaserプレビューとする。
- 中央1マス＋周囲6マスを実フィールドの六角寸法・行間隔で表示する。中央に攻撃者を置き、周囲マスのクリックまたは方向選択で対象を移動する。中央は自身対象とし、別の対象画像を重ねない。
- タイル・ユニット画像・エフェクト・位置補正を同じ倍率で枠内へ拡大する。ユニットは実マップと共通の画像占有率、エフェクトは通常攻撃の基準50%と画像フォルダ倍率（アニメーション1は2倍）を使用し、設定Scale倍率を加算ではなく乗算する。エフェクトだけの300pxフィットは行わない。
- 再生方式は `1回再生 / ループ / コマ切り替え / 元画像全体` から選ぶ。初期値は `1回再生` とし、画面を開いた時や対象・設定の変更時にはアニメーションを自動再生しない。
- `1回再生 / ループ` の待機中は選択中エフェクトの1枚目を静止表示し、再生ボタンを押したときだけ既存Phaser再生へ切り替える。1回再生の終了後は1枚目の静止表示へ戻す。
- `元画像全体` はアニメーション再生を行わず、選択中の基本形状エフェクトのスプライトシート全体を縦横比を維持してプレビュー枠へ収める。これは編集用表示であり、戦闘時の表示方法・Scale・画像データは変更しない。
- `1回再生 / ループ` は再生ボタンを押して開始する。コマ切り替えは横スライダーと前後ボタンで静止表示する。追加装飾のコマも基本形状の後に続けて選択できる。
- コマ切り替え中も再生ボタンで全体を1回再生でき、終了後は選択していた静止コマへ戻る。再生中・再生完了・画像読み込み失敗は既存の状態表示欄に表示する。
- プレビューでは現在の基本形状、追加装飾、Tint、グラデーション、移動方向・速度、基準Scale倍率を即時反映する。
- 設定変更時は再生を停止し、次の再生から反映する。コマ切り替え中は選択コマの見た目を更新する。
- 実際のマップ上での確認機能も残し、マップ生成後だけ `実マップで確認` を使用できる。
- スマホではタップ操作を前提として、主要ボタン・タブ・選択欄の高さを約40px以上確保する。

### 6.2 下部設定タブ

#### 向き・位置の微調整

- `基本` で「固定向き / 攻撃方向に回転」を選択する。既存設定の初期値は固定向き。
- 攻撃方向に回転する場合、元画像の右向きを0度とし、攻撃者から対象への方向を使用する。
- `角度補正` は-180〜180度。固定向きでは指定角度、方向連動では攻撃方向に補正角度を加算する。元画像が上向きなら90度補正で右向き基準に合わせられる。
- `位置X / Y` は各-300〜300のワールドpx。元画像の右・下方向を正とするローカル位置補正で、画像と同じ最終角度（攻撃方向＋角度補正、または固定角度）で回転してから対象中心に加算する。例えばXを正にした場合、右向きでは右、左向きでは左へずれる。明示的に再生角度が指定された場合もその角度へ追従し、カメラの拡大縮小にも追従する。
- スライダーと数値入力の両方で調整でき、既存のScale倍率と併用する。
- カテゴリの形状設定として保存し、属性編集はカテゴリの向き・位置を引き継ぐ。個別エフェクト設定にも同じ変換項目を保持する。
- 保存・JSON書き出し/読み込みで `rotationDeg / offsetX / offsetY` を保持し、項目のない旧設定は各0として読み込む。
- 静止・再生・コマ送り・戦闘で同じ補正を適用する。元画像全体の確認表示には補正を適用しない。

下部の設定領域は、縦長画面で全項目を一度に並べないよう4タブへ分割する。

- `基本`
  - 基本形状エフェクト
  - 各番号タブの「画像一覧」から画像選択モーダルを開く（UI278）。元シートの代表コマと名前を表示し、名前で検索できる。選択は開いた番号だけに反映し、倍率・角度・基準点などは保持する。従来のリスト選択も維持する。
  - 上部のカテゴリ選択横の `+` で基本カテゴリを追加する。追加後は `カテゴリ名` を編集でき、画像・向き・角度・位置・Scaleを個別に保持する。既存カテゴリとは独立した編集用設定を使用する。
  - 追加カテゴリはlocalStorageと設定JSONに定義・設定を保存する。JSON読み込みでは定義も復元し、旧JSONは既存カテゴリのみとして読み込む。属性編集時には追加ボタンを表示しない。
  - `assets/effect/アニメーション追記/*.webp` はビルド時に自動取得して基本形状・装飾・画像一覧・再生対象へ追加する。元ファイル名（拡張子を除く）を識別名とし、通常倍率1倍で読み込む。新しい画像を追加した場合は再ビルドする。
  - 画像一覧のサムネイルは表示領域に入ったものだけ同時最大4枚で読み込み、シート全体の画像複製は保持しない。
  - 追加装飾エフェクト
  - 基準Scale倍率
  - 選択中設定の初期化
- `色`
  - 着色方式リスト：なし / 単色 / グラデーション（同時使用しない）
  - 選択方式に必要な設定だけ表示する
  - グラデーション色A / 色BはPC・スマホとも横並び
  - 各色は基本色リストと詳細カラーピッカーから指定できる
  - 開始位置 / 終了位置 / 着色強度
- `動き`
  - グラデーション移動方向
  - グラデーション移動速度
- `保存`
  - 実マップで確認
  - JSON書き出し
  - JSON読み込み

下部タブの中だけをスクロール可能とし、上部プレビューは設定中も画面内へ残す。

グラデーションONで `色` / `動き` タブを操作中は、表示画像1コマの枠と開始・終了位置を点線で表示する。上下方向は画像の上端0%・下端100%、左右方向は左端0%・右端100%を基準にする。点線は移動前の基準位置であり、再生中の色の移動に追従する境界ではない。画像の拡大率や追加装飾の切り替えに合わせて枠を更新し、戦闘画面には表示しない。

プレビューの高さは画面全体ではなく設定パネルの高さを基準にする。管理タブ内でも設定タブ・スクロール領域・保存状況を枠内に収める。
ループは基本形状と追加装飾の全再生が完了してから繰り返す。方式切り替え・設定変更・画面を閉じる操作で停止する。再表示時も再生ボタンを押すまで再生しない。

未変更のエフェクトは設定データを複製せず、従来のエフェクト名・Tintなし・グラデーションOFF・Scale倍率100%をそのまま使用する。
変更されたエフェクトだけを上書き設定として保存する。

現行の追加装飾は既存の複数エフェクト再生機構へ接続する。
属性装飾を最終的に同時重畳とするか、連続再生を使うかは見た目を確認して別途確定する。

## 7. 設定の保持とJSON入出力

エフェクト設定はブラウザの `localStorage` に自動保存し、画面を閉じても同じブラウザでは設定を維持する。
保存キーは `v39-effect-settings-v1` を継続使用し、JSONスキーマの現行バージョンは `3` とする。
旧バージョン1のJSONはグラデーションOFFとして互換読み込みする。

JSON書き出しは、変更済みエフェクトだけを次の形式で保持する。

```json
{
  "schema": "v39-effect-settings",
  "version": 3,
  "effects": {
    "火炎": {
      "baseEffect": "火炎",
      "decorationEffect": "",
      "tint": "",
      "gradientEnabled": true,
      "gradientColorA": "#FF3B1F",
      "gradientColorB": "#FFD54A",
      "gradientDirection": "up",
      "gradientStartPercent": 0,
      "gradientEndPercent": 100,
      "colorStrengthPercent": 100,
      "gradientSpeedPercentPerSecond": 80,
      "scaleMultiplierPercent": 100
    }
  }
}
```

- JSON読み込み時は、現在の実エフェクトカタログに存在する名前だけを反映する。
- 現在のカタログにないエフェクト名はスキップする。
- 基本形状または追加装飾に未登録名が指定されている場合は、安全な既定値へ正規化する。
- グラデーション方向が未対応値の場合は `up` へ正規化する。
- 開始・終了位置と強度は0〜100%に収め、開始・終了が逆のJSONは順序を正規化する。未指定時は開始0%・終了100%・強度100%。
- 旧バージョン2の高さ位置だけを持つ設定は、開始 `max(0, 高さ位置 - 50)`・終了 `min(100, 高さ位置 + 50)` へ移行する。保存・書き出しでは新しい開始・終了項目を使用する。
- グラデーション速度は実装側の許容範囲へクランプする。
- JSON読み込みは現在のエフェクト上書き設定一式を置き換える。
- 読み込んだ内容も `localStorage` へ保存し、その後の戦闘再生から即時反映する。
- JSONはゲーム本体のスキル・属性データの正本にはせず、あくまでユーザーが調整したエフェクト表示設定として扱う。

## 10. 敵攻撃時のカメラ演出

敵ターンの攻撃は、エフェクトだけを即時再生して誰が攻撃したか分からなくならないよう、攻撃前に戦闘構図を作ってから再生する。

基本順序は次のとおり。

```text
攻撃イベント開始
→ 攻撃者と対象を確認できるカメラ構図へ移動
→ 短時間停止
→ 攻撃エフェクト
→ ダメージ表示
→ 次の敵行動
```

- 近距離攻撃では、攻撃距離ごとに細かく倍率を変えず一定の戦闘ズームを使用する。
- 現行調整値では3マス以内を近距離扱い、戦闘ズーム倍率は1.5とする。
- 遠距離攻撃では、攻撃者と対象の両方が画面内へ入る最大倍率を算出し、周囲に2マス相当の余白を取る。
- 遠距離攻撃の後に別の遠距離攻撃が続く場合、微小な倍率差ではズームを変更せず、拡大・縮小の繰り返しを抑える。
- 攻撃前停止は現行500msとする。
- 攻撃者が未発見の場合は、その攻撃者の位置を見せるための構図にはしない。対象側だけを映して着弾を表示し、Fog・索敵による非表示ルールを維持する。
- 敵ターン中に変更したズームは、敵ターン終了時に敵ターン開始前の倍率へ1回だけ戻す。
- カメラ演出は戦闘ダメージ、命中、AP、待機、CTなどのゲーム内ターン処理には影響させない。
- 調整値は `V39_ENEMY_TURN_PRESENTATION_CONFIG` に集約し、演出処理へ同じ数値を重複して直書きしない。
