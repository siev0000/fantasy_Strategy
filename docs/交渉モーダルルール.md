# 交渉モーダルの現行ルール

更新: 2026-10-21 / UI53。画面操作の正本です。履歴・廃止方式は末尾の別資料へ分離しました。

## 入口と画面構成

- 一般村の交流欄は情報・全受注件数と「村で会話・依頼」の入口のみ。直接の休息/交流/受注/報告/属国化/襲撃/別取引ボタンは置きません。
- 村モーダルは「会話 / クエスト / 取引 / 情報」の4タブのみ。同じ目的の上部ショートカットや第2の依頼一覧を作りません。
- negotiation_hub_fixed_layout.htmlを構成の基準とし、仮の相場・台詞・小さい文字をそのまま実データへ移しません。
- 元の資源ヘッダーを最前面へ保ち、その直下から画面を使用。外側padding/枠/縮小幅制限はなし。元の内訳・特産品表示も使えます。
- 見出し・上段会話・4タブ・フッターは固定し、下段本文だけネイティブ縦スクロール。取引の物資一覧は固定高の内側スクロールとし、端では下段本文へ引き継ぎます。
- 上段は相手の台詞/右の人物、下段は自分の人物/右の台詞。人物は既存画像の上半分を共用し、村長は守備兵と独立した代表です。
- 情報タブに村計画・人口・守備・所属・性格・交渉役・スキル・履歴をまとめます。交渉役と使者は別です。
- 閉じる/戻るだけで受注や交渉は確定しません。会話やUI入力は同一セッション内で保持。マップ新規生成で破棄します。

## クエスト

- 新規候補は村計画の実際の不足/脅威から生成。イベント会話の選択肢から新規依頼を追加しません。
- 一覧の左チェックで複数選択し、固定フッターで「まとめて受注」「まとめて支援・報告」「受注・報告」を実行します。
- チェックだけで別画面へ移動したり納品したりしません。「受注して支援」「受注のみ」や即時納品チェックは使いません。受注後の支援・報告を別の明示操作にします。
- 村ごと1件制限はありません。目標/期限/報酬は全依頼別に保存。途中失敗時は選択分全体を巻き戻します。
- 達成条件は共通アイコン＋数量、報酬は共通アイコン＋数量と「友好度 +10」等の文字。内部の生成方式をプレイヤー用カテゴリにしません。
- 旧セーブの番号付き依頼は完了互換のみ。新規候補や別の受注画面を復活させません。

## 報酬と取引の共通UI

- 受注前の依頼カードの「交渉」で報酬表示へ切り替え、「依頼一覧」でチェックと入力を保持して戻ります。
- 取引と報酬は同じ2列バスケットを使用。取引は自国の提供/相手への要求、報酬は達成条件（参照のみ）/相手への要求。
- 金・既知物資・人口を複数追加可能。報酬に1種類制限を設けません。品目追加で既存項目を置き換えません。
- ＋で同じ全画面物資選択モーダルを開きます。分類/検索/アイコン/数量メーター/決定ボタン位置/背景inert/フォーカス循環/Escを共用。報酬専用の小型インライン選択は作りません。
- 選択中もモーダルを閉じず「決定」で戻ります。分類や検索結果数で画面・決定位置を伸縮させません。
- バスケット数量はアイコン右上の直接入力1箇所。選択した1品目だけ下にメーター/増減/削除を表示。選択されていない別品目へ勝手に切り替えません。
- 要求側の物資候補は自国の知識に基づき、相手の在庫/収入を表示・推測させません。報酬の人口候補は村の種族で、保有人数は非表示。
- 取引の提供は出発拠点に在庫または収入があるものだけ。数量/保有数を表示し、予約・維持費不足の見込みはアイコンの「!」と共通状態欄で示します。
- 配送/日程へ物資・収入の重複枠を出しません。使者は通常片側1部隊、双方待ち合わせ時だけ申込側が場所を詳細指定します。
- 報酬は全品目の合計価値で一括交渉、受注時に固定、完了時だけ一括支払い。不足時は納品/完了/移転を取り消します。合意は未受注なら5ターン有効。
- 村の取引タブは既存の取引rendererを直接マウント。他プレイヤーとの独立取引・拠点の取引入口は維持します。

共通描画はv39-trade-items.js、モーダル開閉はv39-trade-picker.js、基本スタイルはv39-trade-dialog.css。報酬だけ別の旧フォームを追加しません。

## AP・スキル・会話

- 会話閲覧・受注/報告・条件編集は追加APなし。報酬交渉とNPC取引の承諾/再開/備蓄確保はAP20。拒否でも消費し、入力不備/AP不足/同条件再試行は追加消費前に拒否します。
- 同ターン・同対象・同条件の交渉制限は提案ID・交渉役・品目順を変えて回避できません。試行をfactionState.negotiationAttemptsに保持します。
- 威圧による報酬交渉は友好度-5。拒否から自動戦闘にせず、襲撃は別の明示操作と確認を要します。
- 村の休息は各参加者AP30、交流は設定された食料、属国化は既存条件。すべてをAP20抽選へ統一しません。
- 情報タブのスキルは習得済みAスキルの対応する即時自己強化のみ。既存のAP/CT/1ターン1回/効果時間を共用します。詠唱/魅了/精神干渉の未対応技を即時使用へ変換しません。
- 性格会話シートの口調・一人称・二人称を代表と交渉役へ適用し保存します。固有回答・実結果は保持。性格AI、遠隔承認、代表専用新画像は未対応です。

## 襲撃後の敵対（UI54）

会話タブの襲撃確認後は村/襲撃者だけを敵対化して画面を閉じ、通常戦闘へ戻ります。友好度-60以下の表示と実戦対象判定を一致させ、守備兵への攻撃/反撃/迎撃を接続。即時の架空略奪・人口被害はありません。詳細は一般村防衛・廃村ルール.md「村への襲撃」。
