# 交渉モーダルの現行ルール

更新: 2026-10-14

## 表示

- フィールドに重ねる専用モーダル。村と取引は同じ会話表示部品を使用する。
- 村会話モーダルは画面全体を使用する。外側/ダイアログのpaddingは0、外枠線と角丸はなし、幅720px・高さ92dvhの縮小制限は使わない。ヘッダーは固定し、本文だけスクロールする。会話カード/操作ボタン自身の余白は別に維持する。
- 左は相手、右は交渉役。既存ユニット画像の上側を切り出し、新しい人物画像データは作らない。村の代表は生存守備兵を仮表示し、不在時は村の種族/ファイター画像を使う。
- 相手のセリフは上、自分の返答は下。既存依頼/取引の結果を発言へ反映し、直近30件の履歴を折りたたんで表示する。
- 自軍の生存する地上キャラから交渉役を変更できる。村の会話では村領域内のキャラを候補にする。取引の交渉役と物資運搬の担当者は別であり、交渉役の変更で運搬担当/部隊を変えない。
- 画面を閉じるだけでは取消・受注・成立にしない。同一画面セッション内では会話位置と取引入力を保持する。新しいマップの生成でUI記憶を消す。会話文/未送信入力のセーブ保存は未対応。
- 上のヘッダーは固定し、本文をスクロールする。スマホでは人物を左右端へ縮め、セリフ・条件の幅を優先する。背後のマップへの入力伝播を遮断する。
- 取引画面では物資編集を優先し、人物/会話/スキルは「会話・スキル」に折りたたむ。開けば同じ会話表示部品が使え、開閉状態を保持する。

## APと確定

- 最新合意: NPCへの交渉・威圧判定は暫定AP20。AP0案は撤回する。数値は `config/v39-negotiation.json`。
- 会話の閲覧、依頼の受注/報告、取引条件の編集、プレイヤー相手の提案/承諾はAP0。スキル使用はそのスキルのAP。村の休息AP30は別ルールのまま。
- 現行でAP20を接続している判定はNPC資源取引の承諾判定、村の備蓄追加交渉、NPC取引の再開交渉。既存の交流/属国化/守護者の条件付き譲渡をすべて確率交渉へ置き換えた意味ではない。
- 判定前に確認を出し、拒否でもAPを消費する。入力不備・AP不足・同条件の再試行は判定前に拒否し、追加消費しない。拒否した取引で予約物資を差し引かない。
- 同じ村への同一条件の交渉は、同ターンに再判定できない。提案IDや交渉役を変えても回避できない。次ターンまたは異なる条件で再判定する。
- 試行は `factionState.negotiationAttempts` に保持し、取引の交渉役は `contract.negotiatorId`。旧提案の交渉役は運搬担当から補完する。

## スキル

- 会話の選択肢に混ぜず、別の「スキル」欄に出す。詳細・AP・使用後AP・交渉AP不足を表示して「使用を確認」で確定する。
- 初回対応は習得済みAスキルの即時自己強化。対象が自身、交渉/威圧の補正、効果時間があり、既存の支援スキル判定を満たすものだけを出す。
- 発動待機/魔法の詠唱が必要なスキル、相手への魅了/精神干渉、会話から攻撃する分岐は未対応。未対応スキルを即時発動へ勝手に変換しない。
- 実行は既存戦闘エンジンを使用し、AP・同スキル1ターン1回・CT・持続効果を共有する。交渉値には未失効の交渉/威圧補正を加える。
- 正式原本へ交渉用Aスキルを新設したわけではない。候補がなければ0件と理由を表示する。検証用スキルは自動テスト内だけで用意する。

## 検証と残作業

`scripts/check-v39-negotiation-ui.mjs`: PC1100/スマホ390、人物表示、交渉役切替、既存エンジンの自己強化/AP/CT、会話/入力保持、AP20・不足・同条件制限、拒否時の予約非消費。

村の固定テスト文や結果表示は仮会話である。正式な番号付きイベントシートによる台詞/選択肢/回答、魅了などの反応分岐、代表専用画像、遠隔オンライン承認は今後の対象。

金の部隊維持費（1人1金、ゾンビ/動物/契約等の除外）と村の休息料金は合意メモであり、この交渉UI修正では実装していない。
