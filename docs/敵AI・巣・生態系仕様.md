# 敵AI・巣・生態系仕様

最終整理: 2026-09-14

この文書は、モンスター敵AI、強敵グループ、巣、逃走、自然回復、敵側の食料・人口・拡張について確定した仕様をまとめる。
現時点で未実装の項目を含む。実装時は `data/source/export/json` の既存データを正本とし、敵専用の固定値を重複定義しない。

---

## 1. 縄張り行動

### 1-1. 共通

- 強敵とその配下は、所属する縄張りを持つ。
- 平常時は縄張り内を探索・徘徊する。
- 配下は所属する強敵と同じ縄張りを共有する。
- 通常の索敵や被攻撃で、群れ全体へ自動的に敵対状態を共有しない。
- 反応は原則として個体単位とする。

### 1-2. 好戦的な敵

- 索敵範囲に敵対対象が入った場合、自分から追跡・攻撃する。
- 攻撃を受けた場合も反撃・追跡する。
- 縄張り外まで追跡できる。
- 追跡限界は「縄張りの外側 + その敵の1回分の移動距離」とする。
- 追跡限界を超えた場合は追跡を終了し、縄張り側へ戻る。

### 1-3. 好戦的ではない敵

- 縄張り外で索敵に入っただけでは、自分から攻撃しない。
- 敵対対象が縄張り内へ侵入した場合は攻撃する。
- 攻撃を受けた場合は反撃する。
- 追跡可能範囲は縄張りの外側1マスまでとする。
- それ以上離れた場合は追跡を終了し、縄張り側へ戻る。

---

## 2. 群れの反応

- 配下1体が攻撃されても、強敵や他の配下は自動参戦しない。
- 強敵が攻撃されても、配下全員が自動参戦するわけではない。
- ただし、敵対対象が巣の周囲1マス以内へ侵入した場合は例外とする。
- 巣の周囲1マス以内への侵入時は、その巣に所属する群れ全体が反応する。
- この群れ反応は「仲間が攻撃されたから共有する」のではなく、「巣の防衛反応」として扱う。

---

## 3. 逃走AI

### 3-1. 巣がある敵

- 好戦的な敵は HP30%以下で逃走状態へ移行する。
- 好戦的ではない敵は HP55%以下で逃走状態へ移行する。
- 逃走時は自分の巣の方向へ移動する。
- 巣の周囲1マス以内にいる場合は逃走しない。
- 巣の周囲まで戻った後は、通常の戦闘AI・巣防衛条件に従う。

### 3-2. 巣がない敵

- 好戦性に関係なく、HP30%以下になった時点で逃走するかを1回だけ判定する。
- 逃走する確率は30%、逃走しない確率は70%とする。
- 毎ターン再抽選はしない。
- 逃走する個体は、現在の敵対対象と反対方向へ移動し続ける。
- 敵対対象がその個体の索敵範囲外になったら、その後さらに1回だけ移動する。
- 追加の1回移動が終わった時点で逃走を終了して停止する。

---

## 4. ターン自然回復

### 4-1. 回復条件

味方・敵で同じ条件を使用する。

- そのターンに戦闘していない。
- そのターンに移動していない。
- 上記2条件を両方満たした場合だけ自然回復する。

### 4-2. 基本回復量

- 基本回復量は最大HPの5%。
- 現在地に回復補正がある場合は、その補正を基本5%へ加算する。
- 最大HPを超えて回復しない。

例:

```text
最大HP1000
基本回復 5% = 50
拠点・巣の回復補正 +10% = 100
合計回復 = 150
```

### 4-3. 現行実装との差分

現行のターン処理では、移動・戦闘の有無に関係なく生存ユニットへ基本5%回復が入るため、実装時に以下を追加する。

- ターン内の移動有無を保持する。
- ターン内の戦闘参加有無を保持する。
- 両方が未実行の個体だけ回復対象にする。
- 味方・敵で同じ共通判定を使用する。

## 5. 巣の位置づけ

- 巣は敵にとっての「村・拠点」に相当する。
- 単なるスポーン地点ではなく、敵側の拠点状態として扱う。
- 巣は所属モンスター、縄張り、食料備蓄、人口、回復補正などの基点になる。
- 巣に回復補正が設定されている場合、プレイヤー側の村・拠点と同じ回復補正の仕組みを使用する。
- 敵専用の別回復式は作らない。

---

## 6. 巣の肉・人口・ユニット経済

### 6-1. 肉の備蓄

- 巣は食料として「肉」を備蓄する。
- 肉は敵側の人口・ユニット・巣拡大を支える資源として扱う。

### 6-2. 消費コスト

- 敵専用の固定食料コストは新設しない。
- 肉の消費量は、該当する種族に既に設定されているコストを正本として参照する。
- コード側へ種族ごとの消費量を重複定義しない。

### 6-3. 人口増加

- 肉の備蓄が一定以上の条件を満たすと、巣の人口が増える。
- 人口増加時の消費は既存の種族コストを使用する。
- 正確な増加閾値・増加人数・判定周期は未確定。

### 6-4. ユニット生成

- 人口・肉などが一定以上の条件を満たすと、新しい敵ユニットを生成する。
- ユニット生成に必要な消費も既存の種族コストを使用し、敵専用の別コスト表は作らない。
- 正確な生成条件・生成頻度・生成対象の選び方は未確定。

### 6-5. 新しい巣への拡大

- 巣の人口・ユニット・備蓄などが一定規模を超えると、新しい巣を作って勢力圏を拡大できる。
- 新しい巣は新しい縄張りと敵個体の活動拠点になる。
- 巣が増えるほど人口・ユニットの維持に必要な肉も増える。
- 周辺から得られる肉が不足すれば、人口増加・ユニット生成・新しい巣の増加が自然に鈍化または停止する構造を目指す。
- 固定の敵最大数だけで増殖を止めるのではなく、食料収支を主要な自然制限として利用する。
- 新しい巣の作成条件、配置可能距離、必要人口、必要備蓄、縄張り競合処理は未確定。

## 7. 強敵グループとの関係

既に確定している強敵生成ルールと巣・縄張りAIを接続する。

- 強敵は「単独型」と「群体型」の2種類。
- `出現数` が設定されている場合は群体型とし、強敵1体 + 配下`出現数`体。
- `出現数` が未設定の場合は70%で単独、30%で群体。
- 未設定から群体になった場合の配下数は2〜4体。
- `出現敵.json` に `配下` が指定されていればその敵を使用する。
- `配下` 指定がなければ強敵と同じ種類を配下として使用する。
- 強敵と配下は同じ巣・縄張りに所属できる。
- 通常時の敵対反応は個体単位、巣周囲1マスの防衛だけ群れ全体反応とする。

## 8. 実装タスク

### 優先度高

- [ ] 敵個体へ縄張り中心・縄張り半径・所属巣IDを接続する。
- [ ] 縄張り内徘徊を敵AIへ接続する。
- [ ] 好戦性による索敵・追跡条件を実装する。
- [ ] 好戦的: 縄張り + 1回分の移動距離まで追跡する。
- [ ] 非好戦的: 縄張り + 1マスまで追跡する。
- [ ] 巣周囲1マス侵入時の群れ防衛反応を実装する。
- [ ] 巣あり/巣なしの逃走AIを実装する。
- [ ] ターン内の移動・戦闘履歴を保持し、自然回復条件へ接続する。
- [ ] 敵側にもプレイヤー側と共通の回復補正計算を適用する。

### 巣・生態系

- [ ] 巣を敵側の拠点状態として正本化する。
- [ ] 巣ごとに肉備蓄・人口・所属ユニット・縄張りを保持する。
- [ ] 種族の既存コストを肉消費へ接続する。
- [ ] 肉備蓄による人口増加を実装する。
- [ ] 人口・備蓄条件による敵ユニット生成を実装する。
- [ ] 一定規模を超えた巣から新しい巣を生成する。
- [ ] 食料不足時に人口増加・ユニット生成・巣拡大が抑制されるようにする。
- [ ] セーブ/ロードで巣、肉、人口、縄張り、所属関係、逃走状態を保持する。

### 未確定で実装前に決める項目

- [ ] 巣が肉を得る具体的な方法と量。
- [ ] 人口増加に必要な肉の閾値、増加量、周期。
- [ ] ユニット生成に必要な人口・肉・周期。
- [ ] 新しい巣を作る人口・備蓄・ユニット数などの閾値。
- [ ] 新しい巣の配置距離と配置可能地形。
- [ ] 複数の巣の縄張りが重なった場合の扱い。
- [ ] 巣が破壊・占領された場合の人口、備蓄、所属敵の扱い。

---

## 9. 実装方針

- 敵だけの特別な定数や別経済式を増やしすぎず、プレイヤー側の拠点・回復・人口・コスト処理と共通化できる部分は共通化する。
- 種族コスト、敵定義、巣種別、回復補正などの値はJSONを正本とする。
- 状態に保存するのは定義のコピーではなく、安定IDと現在値を基本とする。
- ランダムで一度確定する結果（巣なし敵の逃走3:7判定など）はセーブ状態へ保存し、ロードで再抽選しない。
