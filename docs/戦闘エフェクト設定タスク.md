# 戦闘エフェクト設定タスク

作成: 2026-10-08
状態: 🔴 未実装 / 方針整理済み

この資料は戦闘エフェクト設定の実装タスクを整理する補助資料。現行の戦闘・スキル仕様そのものを変更する資料ではない。現在の実装は既存コード・データを正本とし、実装時は `docs/ALL_TASKS_UNIFIED.md` と合わせて扱う。

## 方針

- 属性ごとに完成済みエフェクトを大量に個別制作する方式にはしない。
- 基本となる「攻撃形状エフェクト」と「属性装飾エフェクト」を分離し、組み合わせて使用する。
- 例: `闇の斬撃 = 斬撃エフェクトを黒～紫系へ着色 + 小さい闇エフェクト/粒子を重ねる`。
- 炎・氷・雷なども同様に、基本形状を再利用し、Tint・小型属性装飾・必要な追加エフェクトで差を出す。
- 威力と攻撃範囲・炸裂範囲に応じて、同じ基本エフェクトの表示サイズ・配置を変える。
- スキル名ごとの個別ハードコードを増やさず、可能な限りデータ駆動で `基本形状 + 属性 + サイズ/範囲` を解決する。
- 現行 `playV39MapEffect` が持つ Tint、複数エフェクト列、Scale 等の既存機能を再利用し、同等の再生基盤を作り直さない。

## 実装タスク

- [ ] 現在のスキル定義を全件確認し、各スキルを上記の基本エフェクト候補へ分類する。
- [ ] 分類できないスキルを抽出し、新しい基本形状が本当に必要か確認する。
- [ ] 重複している基本形状を統合し、最終的に用意する基本エフェクト数を確定する。
- [ ] 属性ごとに使用する Tint / 色調と、小型の属性装飾エフェクトを整理する。
- [ ] `闇の斬撃 = 斬撃 + 黒～紫Tint + 小型闇装飾` のような組み合わせ設定をデータとして表現できる形を決める。
- [ ] 威力による基礎Scale変更ルールを決める。
- [ ] 単体 / 範囲 / 炸裂などの対象範囲によるエフェクトサイズ・複数配置ルールを決める。
- [ ] 管理画面に「エフェクト設定」を追加する。
- [ ] 設定画面では、基本エフェクト、属性装飾、Tint、基準サイズ等を確認・設定できるようにする。
- [ ] 設定画面に実エフェクトのプレビューを用意する。
- [ ] UIへ仮データを直接埋め込まず、最初から実際のエフェクトカタログ・設定データを参照する。
- [ ] プレイヤー攻撃・敵攻撃・反撃・範囲攻撃など、既存のエフェクト再生経路から同じ設定を参照する。
- [ ] 基本形状・属性・威力・範囲の組み合わせで代表的なスキルを再生し、PC/スマホで見た目と負荷を確認する。

## 例

- 闇の斬撃: `斬撃 + 黒～紫系Tint + 小型闇エフェクト`
- 炎の斬撃: `斬撃 + 赤～橙系Tint + 火花/小炎`
- 氷の斬撃: `斬撃 + 水色系Tint + 氷片`
- 雷の斬撃: `斬撃 + 青白系Tint + 小型放電`

同じ考え方を飛翔弾・爆発・ビーム・範囲放射等へ展開する。
