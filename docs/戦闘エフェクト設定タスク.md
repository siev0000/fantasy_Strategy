# 戦闘エフェクト設定タスク

作成: 2026-10-08  
状態: 🟡 一部実装済み / 分類・自動Scale等は継続

この資料は戦闘エフェクト設定の実装タスクを整理する補助資料。
**確定仕様は `docs/戦闘エフェクトルール.md` を正本とし、この資料では仕様を二重管理しない。**
現在の実装確認は `frontend/src/v39/combat/v39-effect-player.js`、設定保存は `frontend/src/lib/v39-effect-settings.js`、設定画面は `frontend/src/v39/ui/v39-effect-settings.js` を参照する。

## 実装時に守る確定方針

- 属性・スキルごとの完成エフェクトを大量に個別制作しない。
- `基本形状 + Tint / グラデーション色調 + 属性装飾 + 威力Scale + 範囲Scale / 配置` の組み合わせで表現する。
- スキル名ごとの個別ハードコードを増やさず、可能な限りデータ駆動にする。
- 現行 `playV39MapEffect` の Tint、移動グラデーション、複数エフェクト列、Scale、角度等を再利用し、同等の再生基盤を作り直さない。
- プレイヤー攻撃・敵攻撃・反撃・範囲攻撃で同じ設定を参照する。
- UIへ仮データを直接埋め込まず、最初から実際のエフェクトカタログ・設定データを参照する。

## 基本エフェクトの初期分類候補

**12+6=18種類は確定数ではない。**
現在登録されている全スキルを分類した後に不足・重複を確認して最終決定する。

### 攻撃系 12候補

1. 斬撃
2. 刺突
3. 打撃
4. 爪・牙
5. 飛翔弾
6. 射撃
7. ビーム
8. 波・薙ぎ払い / ブレス
9. 爆発
10. 落下・落雷
11. 雨・連続落下
12. 範囲放射

### 補助系 6候補

1. 回復
2. 強化
3. 弱体・呪い
4. 状態異常
5. シールド
6. 召喚・特殊

## 実装タスク

- [ ] 現在のスキル定義を全件確認し、各スキルを基本エフェクト候補へ分類する。
- [ ] 分類できないスキルを抽出し、新しい基本形状が本当に必要か確認する。
- [ ] 重複している基本形状を統合し、最終的に用意する基本エフェクト数を確定する。
- [ ] 属性ごとに使用する Tint / グラデーション色調と、小型の属性装飾エフェクトを整理する。
- [x] 既存エフェクト名ごとに `基本形状 + 追加装飾 + Tint / グラデーション + 基準Scale倍率` を保存できる設定形式を実装する。
- [x] 2色グラデーション、上 / 下 / 左 / 右の移動方向、移動速度を設定できるようにする。
- [x] 移動グラデーションを `playV39MapEffect` の共通再生経路へ反映する。
- [ ] 威力による基礎Scale変更ルールを決める。
- [ ] 単体 / 範囲 / 炸裂などの対象範囲によるエフェクトサイズ・複数配置ルールを決める。
- [x] 管理画面に `エフェクト設定` を追加する。
- [x] 設定画面で基本エフェクト、追加装飾、Tint / グラデーション、基準Scale倍率を確認・設定できるようにする。
- [x] 設定画面から実マップ上で現在設定のエフェクトをプレビューできるようにする。
- [x] 変更内容をブラウザ `localStorage` へ自動保存する。
- [x] 変更内容をJSONファイルへ書き出し、JSONファイルから読み込んで復元できるようにする。
- [x] 既存の `playV39MapEffect` から同じ設定を参照し、プレイヤー攻撃・敵攻撃・反撃等の共通再生経路へ反映する。
- [ ] 属性装飾を最終的に同時重畳・連続再生のどちらで表現するか、各基本形状と合わせて確定する。
- [ ] 基本形状・属性・威力・範囲の組み合わせで代表的なスキルを再生し、PC/スマホで見た目と負荷を確認する。

## 代表例

- 闇の斬撃: `斬撃 + 黒～紫系Tint / グラデーション + 小型闇エフェクト`
- 炎の斬撃: `斬撃 + 赤～黄系グラデーション（上移動） + 火花 / 小炎`
- 氷の斬撃: `斬撃 + 水色～白系Tint / グラデーション + 氷片`
- 雷の斬撃: `斬撃 + 青～白系Tint / グラデーション + 小型放電`

同じ考え方を飛翔弾・爆発・ビーム・範囲放射等へ展開する。
