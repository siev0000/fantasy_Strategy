# 消耗品携帯・軍隊編成ルール

更新: 2026-10-13

この文書は、個人ユニットおよび軍隊ユニットの消耗品携帯、軍隊編成時の道具枠、デフォルト携帯設定について今回確定した方針をまとめる。
現行コードには未反映の内容を含むため、実装状態とは区別する。
投擲用消耗品の詳細は `投擲・投擲アイテムルール.md` を参照する。

## 1. 消耗品スロット

- 消耗品はスロット方式で携帯する。
- 1スロットには1種類の消耗品を登録し、同じ種類はそのスロット内でスタックする。
- 使用可能な消耗品スロット数は `0〜3枠` とする方向で整理する。道具を携帯できる場合の実用上の枠数は `1〜3枠` を想定する。
- 1スロットあたりの基本スタック上限の正式値は未確定。
- 水薬、解毒薬、聖水、煙玉、投擲用消耗品などは同じ消耗品スロット体系で扱う。
- 道具枠数と、1枠に積める個数（スタック上限）は別の値として扱う。

## 2. 胴装備による道具枠

- 道具枠は、基本的に胴装備によって決定する方向とする。
- 胴装備なしの場合は `0枠` とし、道具を携帯できない。
- 鎧系の胴装備は `1枠` とする。
- 服系の胴装備は `2枠` とする。
- 法衣系の胴装備は `3枠` とする。
- 装備名だけで分類を推測せず、原本の胴装備分類に対応させる。旧「ローブ系は一律3枠」の記述はこの鎧・服・法衣の区分に置き換える。
- この方式により、防具・携帯装具を持たない狼や竜などが「装備なしだから3枠」と自動的に扱われることを避ける。
- モンスターや特殊ユニット向けに専用の携帯装備を用意するかは別途検討する。

## 3. 個人ユニットと軍隊ユニット

- 個人ユニットは本人単位で消耗品スロットと所持数を持つ。
- 軍隊ユニットは、構成人員1人ごとに個別の消耗品を持たせず、軍隊ユニット全体で1組の消耗品スロットと所持数を持つ。
- 軍隊ユニットの装備編成画面に「道具枠」を追加し、武器・防具等と同様に携帯する消耗品を編成できるようにする。
- 軍隊ユニットが道具を使用した場合は、軍隊ユニットをゲーム上の1ユニットとして扱い、その道具の所持数を1消費する方向とする。
- 軍隊人数に比例して同じ道具を大量消費する方式にはしない。

## 4. デフォルト携帯

- 軍隊ユニットの編成データに「デフォルト携帯」の項目を用意する。
- デフォルト携帯には、軍隊ユニット作成時および補充時に持たせたい消耗品の種類と個数を設定する。
- デフォルト携帯は並び順を持ち、上に設定した道具ほど優先度を高くする。
- 使用可能な道具枠がデフォルト携帯の登録数より少ない場合は、上から順に高優先度の道具を道具枠へ割り当てる。
- 軍隊ユニットを新規作成した際は、設定されたデフォルト携帯を使用可能な道具枠の範囲で自動的に入れる。
- デフォルト携帯の支給元は、軍隊ユニットを作成する拠点側の在庫・資源とする。
- 必要な在庫・資源がある分だけ支給し、不足している分は入れない。
- 在庫・資源不足を理由に軍隊ユニット作成そのものを失敗させない。
- 不足した消耗品を自動生成・無償補填しない。
- デフォルト携帯は初期携帯と補充内容の基準であり、作成後にユニットごとの設定を変更できるようにする。
- 在庫不足時に高優先度の道具を入れられない場合、空いた枠を下位優先度の別道具で埋めるかどうかは未確定。

## 5. 補充

- 補充内容は全軍共通ではなく、各ユニットに設定されたデフォルト携帯を参照する。
- 補充時は、現在の所持数とデフォルト携帯の設定数を比較し、不足している分を補充する。
- 補充には拠点側の在庫・必要資源を実際に消費し、無償補充は行わない。
- 在庫・資源が不足している場合は、補充できる分だけ補充する。
- デフォルト携帯の優先順位は補充時にも使用し、上に設定した道具から優先して補充する方向とする。
- 補充を行える場所・タイミング（拠点帰還時の自動補充、手動補充など）は未確定。

## 6. 装備・研究による携帯量補正

- 胴装備は主に道具枠数を決める。
- それ以外の装備効果では、特定カテゴリのスタック上限を増やす方式を利用できるようにする。
- 例として、投擲系装備で投擲用消耗品のスタック上限を増やす、薬系装備で薬のスタック上限を増やす、といった設計を可能にする。
- 魔術研究では、空間魔法を応用した「空間収納」系の研究によって、1枠あたりに携帯できる個数を増加させる案を採用方向とする。
- 空間魔法研究は道具枠そのものを新規に作るのではなく、既に使用可能な道具枠のスタック上限を拡張する方向とする。
- そのため胴装備なしで `0枠` のユニットは、空間収納系研究だけでは道具を携帯できない方向とする。
- 空間収納系研究の研究名、必要魔術Lv、研究段階、具体的なスタック増加量は未確定。
- スロット追加効果を持つ特殊装備を別途用意するかは未確定。

## 7. 在庫不足時の例

デフォルト携帯が次の場合を例とする。

1. 水薬 ×3
2. 解毒薬 ×2
3. 煙玉 ×2

3枠使用可能で、作成拠点の在庫が以下の場合、

- 水薬 ×10
- 解毒薬 ×1
- 煙玉 ×0

新規軍隊ユニットには、

- 水薬 ×3
- 解毒薬 ×1
- 煙玉 ×0

まで支給できる。
不足している解毒薬1個、煙玉2個は支給されず、無償では補われない。

使用可能枠が1枠の場合は、デフォルト携帯の最上位である水薬だけを携帯対象とする。
使用可能枠が2枠の場合は、水薬・解毒薬までを携帯対象とする。
