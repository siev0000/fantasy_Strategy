# 消耗品携帯・軍隊編成ルール

更新: 2026-10-13

この文書は、個人ユニットおよび軍隊ユニットの消耗品携帯、軍隊編成時の道具枠、デフォルト携帯設定について今回確定した方針をまとめる。
現行コードには未反映の内容を含むため、実装状態とは区別する。
投擲用消耗品の詳細は `投擲・投擲アイテムルール.md` を参照する。

## 1. 消耗品スロット

- 消耗品はスロット方式で携帯する。
- 1スロットには1種類の消耗品を登録し、同じ種類はそのスロット内でスタックする。
- 消耗品スロット数、1スロットあたりの基本スタック上限の正式値は未確定。
- 水薬、解毒薬、聖水、煙玉、投擲用消耗品などは同じ消耗品スロット体系で扱う。
- 装備などによってスタック上限を増減できる方向とする。
- 装備変更によって現在所持数が新しい上限を超えた場合の扱いは別途確定する。

## 2. 個人ユニットと軍隊ユニット

- 個人ユニットは本人単位で消耗品スロットと所持数を持つ。
- 軍隊ユニットは、構成人員1人ごとに個別の消耗品を持たせず、軍隊ユニット全体で1組の消耗品スロットと所持数を持つ。
- 軍隊ユニットの装備編成画面に「道具枠」を追加し、武器・防具等と同様に携帯する消耗品を編成できるようにする。
- 軍隊ユニットが道具を使用した場合は、軍隊ユニットをゲーム上の1ユニットとして扱い、その道具の所持数を1消費する方向とする。
- 軍隊人数に比例して同じ道具を大量消費する方式にはしない。

## 3. デフォルト携帯

- 軍隊ユニットの編成データに「デフォルト携帯」の項目を用意する。
- デフォルト携帯には、軍隊ユニット作成時に持たせたい消耗品の種類と個数を設定する。
- 軍隊ユニットを新規作成した際は、設定されたデフォルト携帯を自動的に道具枠へ入れる。
- デフォルト携帯の支給元は、軍隊ユニットを作成する拠点側の在庫とする。
- 拠点在庫に必要数がある分だけ支給し、在庫が足りない分は入れない。
- 在庫不足を理由に軍隊ユニット作成そのものを失敗させない。
- 不足した消耗品を後から自動で生成・無償補填しない。
- デフォルト携帯は「初期携帯内容」を決める設定であり、作成後に各軍隊ユニットの道具枠を変更できるようにする。

## 4. 在庫不足時の例

デフォルト携帯が次の場合を例とする。

- 水薬 ×3
- 解毒薬 ×2
- 煙玉 ×2

作成拠点の在庫が以下の場合、

- 水薬 ×10
- 解毒薬 ×1
- 煙玉 ×0

新規軍隊ユニットには、

- 水薬 ×3
- 解毒薬 ×1
- 煙玉 ×0

を支給する。
不足している解毒薬1個、煙玉2個は支給されず、拠点在庫が増えても作成済み軍隊へ自動補填はしない。

## 5. 装備による携帯量補正

- 消耗品の携帯数は、装備によって増加できる方向とする。
- 基本はスロット数そのものを頻繁に増減させるより、特定カテゴリのスタック上限を増やす方式を優先する。
- 例として、投擲系装備で投擲用消耗品のスタック上限を増やす、薬系装備で薬のスタック上限を増やす、といった設計を可能にする。
- スロット追加効果を持つ特殊装備を用意するかは未確定。
- 具体的な装備名、補正値、適用カテゴリは装備データ作成時に別途確定する。
