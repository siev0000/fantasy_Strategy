# ユニット立ち絵生成ルール

## 1. 用途
本ルールはゲーム内ユニットの立ち絵生成に使用する。
画像生成を行う前に必ず本書を確認すること。

## 2. 基本画風
- ファンタジーRPGのゲームユニット用イラスト。
- アニメ調。
- 写実的・リアル調にはしない。
- 輪郭線を明瞭にする。
- 塗りはセル塗りを基本とし、陰影は簡潔にする。
- 過度な光沢、映画的ライティング、厚塗り、超高密度な装飾を避ける。
- 小さく表示しても種族・装備・シルエットを判別できるデザインにする。
- 既存ユニット画像が提示されている場合は、その画像を画風の最優先参考とする。

## 3. キャラクターの表示
- 原則1ユニットにつき1キャラクター。
- 頭頂から足先まで全身を表示する。
- キャラクターを画面中央付近に配置する。
- 頭・髪・耳・角・翼・尻尾・武器・盾・杖などを含め、キャラクターを構成する要素をキャンバス外へ見切れさせない。
- 翼や長い武器を持つ場合は、それを含めた外接範囲を「全身」として扱う。
- 四辺に余白を確保する。
- 無理に画面いっぱいまで拡大しない。
- 極端なパースや、身体の一部が隠れるポーズを避ける。
- 原則として立ち姿または軽い戦闘待機姿勢とする。

## 4. 背景
- 背景は完全透過。
- 白背景・黒背景・単色背景を描画しない。
- 地面、影、台座、風景、エフェクトなども原則として付けない。
- キャラクター周囲に背景色の縁取りや透過残りを作らない。

## 5. 体格・種族
- 種族設定に定められた身長・頭身・身体的特徴を優先する。
- 全種族を人間と同じ体型へ寄せない。
- 小型種族を単純に人間キャラクターの縮小版にしない。
- 頭身、手足、頭部、耳、鼻、角、体毛、鱗など、その種族を識別する特徴を維持する。
- 例：ゴブリンは約90cm。小柄で、体に対して頭が大きい。大きな尖った耳と目立つ鼻を持つ。
- 獣人は「人間＋獣耳」ではなく、獣寄りの頭部・体毛・手足を持つ。
- オーガは鬼を基本イメージとする。
- 竜人は角や尻尾だけではなく、鱗・爪・竜型頭部などで竜らしさを出す。

## 6. 装備
- 指定されたクラス・役割がある場合は、それを読み取れる装備にする。
- 武器・防具はキャラクターの体格に合わせる。
- 装備で種族固有の特徴を完全に隠さない。
- 小サイズで潰れるだけの細かな装飾を大量に追加しない。
- 指定されていない装備を勝手に重要設定として追加しない。

## 7. 低解像度での使用
- ゲーム内では縮小表示されることを前提とする。
- シルエットを最優先する。
- 顔、武器、種族特徴、主要防具が縮小後にも判別できるようにする。
- 細い線や極端に細かな模様に依存しない。
- 必要に応じて256×256程度への縮小・ドット絵化に耐えられる情報量に抑える。

## 8. 禁止事項
- 身体・翼・武器等の見切れ。
- 背景の描き込み。
- 背景透過漏れ。
- 指示のない複数キャラクター化。
- 種族設定を無視した体格変更。
- 既存画像と大幅に異なる画風への変更。
- 過剰な装飾によるシルエットの崩壊。
- 「小型種族だから既存キャラ全体を縮小しただけ」という処理。

## 9. 生成前手順
1. 対象種族・キャラクターの既存設定を確認する。
2. 参考画像がある場合は実際の画像内容を確認する。
3. 参考画像を確認できていない場合は「確認した」と扱わない。
4. 種族、体格、服装、武器、ポーズなど生成内容をユーザーへ提示する。
5. ユーザーから「生成OK」等の明示的な許可を得る。
6. 許可後にのみ画像生成を実行する。

## 10. 生成後チェック
生成結果について以下をすべて確認する。

- [ ] 全身が入っている
- [ ] 頭・足が切れていない
- [ ] 武器が切れていない
- [ ] 翼・角・耳・尻尾が切れていない
- [ ] 四辺に余白がある
- [ ] 背景が完全透過している
- [ ] 種族の体格が正しい
- [ ] 種族固有特徴が読み取れる
- [ ] 既存ユニットと画風が大きくズレていない
- [ ] 小サイズでもシルエットを識別できる

1項目でも満たさない場合は完成扱いにしない。
