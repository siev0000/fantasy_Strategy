# v39 地形アイコン仕様

> マップ上で地形・特殊地形を判別しやすくするための表示ルール。
> 文字・記号で十分伝わるものは文字アイコンを使い、伝わりにくいものだけ後から画像アイコンへ置き換える。

## 1. 基本方針

- まずは軽量な文字・記号で表示する。
- 色・高度陰影・記号を組み合わせて判別する。
- 通常地形すべてにアイコンを重ねると密度が高くなるため、現段階では特殊地形を優先する。
- 記号だけでは意味が伝わりにくい地形は「画像アイコン化候補」として管理する。
- 画像アイコンへ変更しても地形データや生成ルール自体は変更しない。

## 2. 現在の特殊地形表示

| 地形 | 仮表示 | 画像化候補 | 備考 |
|---|---:|---:|---|
| 沼地 | `≈` | いいえ | 水・湿地の印象を優先 |
| 峡谷 | `峡` | いいえ | 一文字で名称が直接分かる |
| 洞窟 | `●` | はい | 記号単体では洞窟と伝わりにくい |
| 遺跡 | `◇` | はい | 記号単体では遺跡と伝わりにくい。将来用 |

現行マップ生成で `specialMap` に出現する特殊地形は、主に `沼地 / 峡谷 / 洞窟`。
`遺跡` は将来 `specialMap` に追加された場合に同じ表示系をそのまま利用できるよう先行定義する。

## 3. 表示サイズ

旧表示は `11px` でスマホでは小さすぎたため、特殊地形アイコンは現在 `18px / bold` を基準とする。

- 文字色: 明るい色
- 太い暗色ストロークを付ける
- タイル中央表示
- Phaserのカメラズームに合わせて自然に拡大縮小する

## 4. 実装

実装:

`frontend/src/v39-terrain-icons.js`

フィールド生成後:

```text
v39:field-generated
  ↓
v39-terrain-icons.js
  ↓
specialMap[y][x]
  ↓
特殊地形の文字アイコンをPhaser上へ描画
```

旧runtimeが生成する `沼 / 峡 / 洞` の11px文字は削除して、こちらのアイコン表示へ差し替える。

公開確認API:

```js
window.getV39TerrainIconDefinitions()
window.getV39TerrainImageIconCandidates()
window.renderV39TerrainIcons()
```

`getV39TerrainImageIconCandidates()` の現在値:

```text
洞窟 → ●
遺跡 → ◇
```

## 5. 今後の画像アイコン化

画像アイコン化は候補をまとめてから一括で行う。

優先候補:

1. 洞窟
2. 遺跡

追加で記号だけでは判別しづらい地形が増えた場合、この一覧へ追加する。

画像化する場合も、地形名・土地詳細・生成データはそのまま維持し、描画表現だけを差し替える。

## 6. 通常地形について

通常地形は現状、ベース色と高度陰影で区別する。

`森 → 🌲` など、一目で意味が伝わる文字アイコンは候補として有効。ただし森林のように大量配置される地形へ全タイル表示すると画面密度が高くなるため、実際の視認性を確認してから導入する。
