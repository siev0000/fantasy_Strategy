# v39 地形アイコン仕様

> マップ上で地形・特殊地形を判別しやすくするための表示ルール。
> 文字・記号で十分伝わるものは文字アイコンを使い、伝わりにくいものだけ後から画像アイコンへ置き換える。

## 1. 基本方針

- 色・高度陰影・記号を組み合わせて地形を判別する。
- 一目で意味が伝わる通常地形は軽量な文字アイコンを使う。
- 記号だけでは意味が伝わりにくい地形は「画像アイコン化候補」として管理する。
- 画像アイコンへ変更しても地形データや生成ルール自体は変更しない。
- 通常地形の大量表示では `Phaser.Text` をタイルごとに作成せず、アイコンを一度Canvasテクスチャ化して `Image` として使い回す。

## 2. 現在の通常地形表示

| 地形 | 表示 | 用途・意図 |
|---|---:|---|
| 森 | `🌲` | 森林・木材系資源を連想しやすい目印 |
| 山岳 | `⛰` | 山岳地形の視認補助 |
| 雪原 | `❄` | 寒冷・雪原の視認補助 |
| 火山 | `🌋` | 火山地形の視認補助 |
| 砂漠 | `∴` | 砂地の簡易表現 |

平地・荒野・丘陵・河川・湖・海は、現段階ではベース色・高度陰影・河川描画で判別し、通常アイコンは載せない。

## 3. 現在の特殊地形表示

| 地形 | 仮表示 | 画像化候補 | 備考 |
|---|---:|---:|---|
| 沼地 | `≈` | いいえ | 水・湿地の印象を優先 |
| 峡谷 | `峡` | いいえ | 一文字で名称が直接分かる |
| 洞窟 | `●` | はい | 記号単体では洞窟と伝わりにくい |
| 遺跡 | `◇` | はい | 記号単体では遺跡と伝わりにくい。将来用 |

現行マップ生成で `specialMap` に出現する特殊地形は、主に `沼地 / 峡谷 / 洞窟`。
`遺跡` は将来 `specialMap` に追加された場合に同じ表示系をそのまま利用できるよう先行定義する。

## 4. 表示サイズ

通常地形は約20px、特殊地形は約22px相当を基準としてCanvasテクスチャへ描画する。

- タイル中央表示
- 暗色ストロークを付けて背景へ埋もれにくくする
- Phaserカメラのズームに合わせて自然に拡大縮小する
- 同じ地形記号は同一テクスチャを再利用する

## 5. 実装

実装:

`frontend/src/v39-terrain-icons.js`

フィールド生成後:

```text
v39:field-generated
  ↓
v39-terrain-icons.js
  ↓
grid[y][x] / specialMap[y][x]
  ↓
通常地形 + 特殊地形のアイコンをPhaser上へ描画
```

旧runtimeが生成する `沼 / 峡 / 洞` の小さい文字は削除して、こちらの特殊地形アイコン表示へ差し替える。

通常地形アイコンは、各タイルで `scene.add.text()` を生成しない。地形ごとの記号を一度だけCanvasテクスチャ化し、各タイルでは `scene.add.image()` で再利用する。

公開確認API:

```js
window.getV39TerrainIconDefinitions()
window.getV39TerrainImageIconCandidates()
window.renderV39TerrainIcons()
```

`getV39TerrainImageIconCandidates()` の現在値:

```text
洞窟 → ●
遺跡 → ◇
```

## 6. 今後の画像アイコン化

画像アイコン化は候補をまとめてから一括で行う。

優先候補:

1. 洞窟
2. 遺跡

追加で記号だけでは判別しづらい地形が増えた場合、この一覧へ追加する。

画像化する場合も、地形名・土地詳細・生成データはそのまま維持し、描画表現だけを差し替える。

## 7. パフォーマンス方針

83×83のような大きいマップでは最大6889タイルになるため、地形表示用に大量のTextオブジェクトを作らない。

現在は地形ごとに1枚のアイコンテクスチャをキャッシュし、該当タイルへ軽量なImageを配置する。

実機でアイコン数が多いマップに性能問題が出た場合は、次段階として以下を検討する。

- 表示中のタイルだけアイコン表示
- 低倍率時は通常地形アイコンを間引く
- 単一RenderTextureへのまとめ描画

視認性のための地形アイコン追加を、マップ生成ロジックやゲームルールへ影響させない。
