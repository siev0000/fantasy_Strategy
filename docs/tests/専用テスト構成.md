# 専用テスト構成

更新: 2026-10-21 / UI 2026.10.21-53

## 起動方法

「テスト操作」→「専用」→「専用テスト」。関連する検証は次の3分類を開いて選ぶ。開始時は現在のゲームを置き換えるため確認を出す。分類の開閉だけではゲームを変更しない。

| 分類 | 確認項目 |
| --- | --- |
| 村・交流テスト | 会話・報酬交渉 / 村の計画・支援 / 契約・強襲・救援 |
| 取引・物流テスト | 取引・郵送 / 拠点間の物流 / 鉱床輸送・入口警備 / 洞窟への侵入・再巣化 |
| 道具・部隊支援テスト | 薬草・水薬 / 王・指揮官・王の騎士の支援 |

召喚・呼集、モンスター合体、動物軍隊、災害、地形、覇権地は別の入口を残す。

## 統合の範囲

- 重複していた起動ボタンを分類内へ整理した。村の会話・計画・事件は必要な初期状態が異なるため、1つのセーブへ全部を押し込まず、確認項目ごとに起動する。
- 「村長・交渉総合テスト」は「村・交流」→「会話・報酬交渉」。4村・村長・性格・交渉担当・スキルを維持する。
- 「村依頼・悪魔契約テスト」は「村・交流」→「契約・強襲・救援」。一般側・悪魔側の通常支援依頼と人口報酬交渉、仮契約と強襲の検証を維持する。魂要求方式へ戻さない。
- 「村の計画・支援テスト」は「村・交流」→「村の計画・支援」。食料不足、討伐支援、墓地、守備補充の4村を維持する。
- 郵送・物流の初期条件も別々に維持する。単発取引と設定済みの物流ルートを同じ契約として扱わない。

## 旧「輸送・道具・支援」の分離

- 旧ボタンは削除。「道具・部隊支援を開始」は `profile: support` を使う。
- 支援検証王・指揮官・王の騎士・道具試験官の4体を地上へ配置。道具試験官はHP半分、薬草2・水薬2を所持し初期選択する。村依頼・輸送兵・警備兵・鉱床は配置しない。
- 「鉱床輸送・入口警備」は `profile: transport` を使う。検証王・鉱床輸送兵・入口警備兵の3体と地上/鉱床を配置。輸送は設定済み。村依頼・道具試験官・指揮官・王の騎士は配置しない。
- プロファイル未指定の既存ビルダーは、他の専用テストが利用しているため維持する。ユーザー向けの旧混在テストとして再掲しない。
- 地上/鉱床の表示切替は、その鉱床が現在のテストに存在するときだけ表示する。

## 村テストの操作（UI53）

村選択後は交流欄の「村で会話・依頼」から共通モーダルを開きます。クエストはチェックでまとめて受注し、受注後の再チェックで支援・報告します。旧直接受注/報告ボタン、選択肢式の新規依頼、悪魔専用依頼はありません。報酬交渉は取引共通の全画面選択から複数の金・物資・人口を要求できます。
## 儀式施設・召喚表の追加確認（2026-10-23）

テスト操作→専用→「儀式:I / II / III」から直接開始できる（UI73）。召喚・呼集テストが未開始なら置換確認の後にテスト拠点・テストサモナー・4系統の召喚表選択スキルを準備し、指定段階を配置して施設召喚画面を開く。開始済みなら再初期化せず段階のみ切り替える。洞窟表示中は地上へ戻る。「儀式:なし」は同じ拠点から儀式施設を外して拠点画面を表示する。通常プレイへ施設やスキルを自動追加しない。元の「召喚・呼集テスト」ボタンは全体を最初からやり直す入口として残す。

`npm run check:ritual-test-buttons` は390/1100pxで未開始からI/II/IIIを実クリックし、置換キャンセル・段階別施設・召喚可能・待ち時間維持・洞窟からの復帰を確認する。低水準の `setV39RitualTestStage` は既存テスト拠点への適用のみで、自動初期化しない。

IIIは四属性III・死霊III・天使/悪魔祭壇IIIを含む。表上Lv25のアークフレイムソルジャーはLv30、表上Lv30のグレーター種は未解禁。元スキルごとにCTを共有するため、同じ系統の候補を再度使う場合はターンを進める。`npm run check:ritual-facilities` で建設前提・倍率・転生・セーブ/ロードも検証する。

### 施設召喚・撃破後25T（UI70）

同テストで「儀式:I」を選び、拠点→施設→施設選択→施設召喚（または土地→施設召喚）を開く。召喚施設を選択して候補を1体召喚すると、その施設は活動中1/1となる。スキル召喚の効果時間では消えない。撃破時は再召喚まで残り25Tと表示する。「儀式:II/III」で段階を替えても活動中枠や待ち時間をリセットしない。テストを最初から開始すれば全体を作り直せる。

`npm run check:facility-summoning` は同時1体・スキルとの分離・I→II→III改築・工事中保存・撃破後24/25T境界・待機中保存・洞窟切替・390/1100pxの実ボタン操作を確認する。

UI74: 施設召喚は候補選択後に「召喚先を選ぶ」→色付きマスをクリック→「ここに召喚」。Iは施設マス、IIは周囲1マス以内、IIIは周囲2マス以内（施設マスを含む）。`check:facility-summon-placement` で0/1/2範囲・術者なし・味方占有・敵占有・死亡/別ワールド・地形/壁・ラップ・実マスクリック・戻る/中止を検証する。
