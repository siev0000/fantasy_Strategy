# 覇権地の固定奥地テスト

更新: 2026-10-20

## 通常プレイへの接続

- 通常生成する覇権地の守護者と配下は、候補設定・Lvを維持して固定12×12の奥地へ配置する。地上には既存の覇権地画像と占有7マスを残す。
- 発見済みの覇権地7マス内で「基本」の「○○の奥地へ」を使う。地上へ戻る地点は実際に入ったマスを保持する。退出準備1ターンと保存はテストと共通。
- 未訪問の奥地はターン処理を休止し、来訪前に環境効果で守護者が倒れることを防ぐ。プレイヤーまたはNPCが入った後は、別ワールドを表示していても通常の処理対象とする。
- 守護者と配下が残る間は、地上で調査し直しても取得できない。撃破して帰還後、土地/交流欄の「奥地攻略後に覇権地を取得」で7マスを既存拠点へ所属させる。既存の到達/再調査の自動取得判定も同じ攻略条件を使う。
- 既存の守護者依頼と友好度70での譲渡も維持し、離れた奥地の生存守護者を参照する。譲渡後は奥地の守備隊を解除。取得直後の即勝利ではなく、確保5ターン・妨害中は進捗1減少の共通ルールを使う。
- NPC勢力は発見後に覇権地へ到達すると奥地へ入り、現地の移動・攻撃判断を行う。排除後は出口へ戻り、同じ退出待機を経て地上の取得を試みる。別ワールド閲覧中にNPCの移動で表示を奪わない。
- 旧セーブで地上に残る守護者は入場時にも移設できる。既に譲渡済みの土地を再生成したり、守備隊を再出現させたりしない。

## 実装済み

- テストモードの「テスト」→シナリオ→「鉱床・道具・部隊支援」の「覇権地・4入口テスト」から開始。共通の地上16×14へ4つの入口を配置し、選び直すたびにゲームをリセットする必要はない。開始確認時のみ現在のゲームを置き換えるので必要なデータは先に保存する。
- 入口マスへ移動し、「基本」の「○○に入る」を押す。各奥地の下側に「出口」の丸い表示を設置。出口マスで「地上へ戻る ⌛1」を押すと、部隊はAPを使い切ってその場で退出準備に入る。ターンを終了し、敵の行動・環境効果を受けてから元の地上入口へ戻る。他の入口へも移動できる。出入りしても各エリアと部隊の状態を保持。入口位置・開始位置も同じconfigのtestHubへ集約する。
- 退出の所要時間は同じconfigのexitTurns（現在1）。準備はセーブに保持し、読み込みで即時退出させない。先頭死亡・出口からの移動・地上の空き不足は中止。部隊全員が重複しない空きマスへ配置できた場合のみ退出する。死亡した同行者や別ワールドへ移された者は連れ出さない。取り消しは可能だが消費APは戻さない。洞窟の従来の即時退出は今回変更しない。
- 地上の入口は矢印の専用マーカーではなく、通常プレイと同じ覇権地の画像・周囲7マスの占有表示を共用する。各地点の下地も山岳/森/火山/海に合わせる。宇宙の海は中央と西隣に徒歩用の陸路を残す。確認用なので守護者や領土の自動取得は付けない。
- 太陽の山・黄昏の樹・星の火口・宇宙の海は、それぞれ固定12×12の別マップ。ランダム抽選は行わない。配置と効果は `config/v39-hegemony-areas.json` に集約。
- 通常ゲームと同じフィールド・部隊・移動・戦闘UI、洞窟と共通のワールド保存/切替を使う。洞窟専用の射程補正・鉱床化・次階層は付けない。
- 操作ユニット2体をLv30、移動力120以上で配置。設定元はtestHub.unitLevel/minimumMovement。移動力下限はtestOnlyの個体だけに適用し、共通ステータス再計算で維持する。開始時にHPを20減らし、回復を確認できるようにする。敵・守護者はこの確認テストでは未配置。
- 特殊マスは地形の見た目と色付きの枠で区別し、土地タブの環境欄に名前と効果を表示。火口は通常の溶岩描画を共用し、樹は薬草の群生地と同じアイコンに黄色い枠を付ける。
- マップの配置・効果マス・ワールド・最終適用ターンは既存セーブに含める。読み込み後も表示を復元する。

| エリア | 特殊マス | 現在の効果 |
| --- | --- | --- |
| 太陽の山 | 黄色：陽光 | このマスからの光属性攻撃の威力1.2倍。影のマス・他属性は補正なし |
| 黄昏の樹 | 薬草アイコン＋黄色：生命の根 | ターン経過でHP5回復、最大HPまで |
| 星の火口 | 溶岩表示：灼熱の地面 | ターン経過で炎・威力20のダメージ。中央に安全な通路を残す |
| 宇宙の海 | 青：水域 | 中央は陸路、周囲は河川と海。通常の水域通行条件を使用 |

数値は試験用の調整値。回復・被害は敵味方共通、死亡者・別ワールドは対象外。同じターンに再実行しても重複適用しない。火口の被害は既存の属性耐性・防御・盾/障壁・ダメージ表示へ接続。回復は活動ログへ出す。通過時の追加ダメージは今回付けない。

溶岩と薬草は外観を共用し、効果判定は奥地専用設定を使用する。通常の溶岩の通行制限・割合ダメージ・流動冷却、通常群生地の追加回復/採取を重ねない。固定テストの地上・奥地では自然災害の抽選と地形ターン変化を停止する。中央の陸路と効果マスは初期配置のまま残る。

## 後続作業

- 守護者依頼の正式シート移行と、各守護者固有の会話・戦術の追加。現在の修繕/見張り/討伐の仮依頼は維持する。
- 通常NPCを含めた長期の攻略バランス調整。入場/退出・攻撃準備・取得の接続と、常に攻略に成功することは区別する。

検証: `scripts/check-v39-hegemony-areas.mjs`。390px/1100pxで固定寸法、入口/帰還、保存復元、環境表示、回復/炎被害、同ターン重複防止、光補正を確認。

退出検証: `scripts/check-v39-world-exits.mjs`。敵の実攻撃を受けてからの退出、先頭死亡/移動の中止、待機の保存復元、別ワールド表示中の処理、重複禁止を確認。

通常接続: `scripts/check-v39-hegemony-campaign.mjs`（奥地配置・攻略前の取得拒否・撃破/交渉譲渡・5ターン勝利・保存）、`scripts/check-v39-npc-campaign.mjs`（NPCの入場・移動/攻撃準備・退出/取得、一般村迎撃）。
