# 洞窟イベントテスト

更新: 2026-10-04

## 現行の範囲

- 開始画面の洞窟テスト探索ゲームだけ、地下1階の入口から上2マス・右1マス（x+1、y-2）にドワーフの鍛冶師を配置する。壁の場合は入口から短い通路を確保する。
- ドワーフ_ユニット集.webp（4列×3行）の9番を切り出して表示する。調整用のnpcArtworkSlotを8に変更すれば8番へ切り替えられる。
- NPCはドワーフ/ファイターの既存クラスデータで生成した会話専用ユニット。敵一覧・プレイヤー部隊には入れず、敵AIや討伐対象にならない。通常ゲームの洞窟と後続階層には追加しない。
- 同じマスまたは隣接1マスで、NPCの画像か行動「ドワーフに話す」から会話する。初期の部隊配置はNPCのマスを避ける。
- 行動欄には「話す」のみを置く。会話中は下部UI全体を専用画面へ切り替える。左に相手の画像・会話文、右に購入/製作/装備/依頼の選択肢を表示し、一覧から選んだ項目の詳細と実行ボタンを出す。左右は独立スクロール。
- 右側は会話メニュー→項目一覧→個別詳細の切替式。一覧と詳細を同時に積み上げない。「戻る」で詳細→一覧→会話メニューの順に戻る。画面切替時はスクロールを先頭へ戻す。
- 左側の会話文は、購入/製作/装備/依頼一覧と選択項目に応じて切り替える。依頼詳細では納品数/討伐数/到達階と報酬、受注/受領状態を会話で案内する。「戻る」でも前の画面の会話文へ戻る。
- 会話を閉じる/やめる/Escape/下部タブ切替で会話を終了する。通常の下部UIは破棄せず選択状態を維持する。離れた場合や操作キャラが変わった場合も閉じ、遠隔購入/納品/報酬受取は拒否する。

## 武器

- 商品は既存の装備JSONから武器1に対応する武器を抽出する。性能・品質は既存の装備生成を使用する。
- 購入は携帯金、製作は携帯金と選択キャラの部隊運搬品の鉱石を消費する。資源は拠点から遠隔で引き落とさない。
- 得た武器は既存の運搬品に追加し、会話画面から選択キャラへ装備できる。元の武器は運搬品に戻す。HPを全回復させない。固定装備のモブは装備変更不可。
- 携帯金はイベントテスト専用。拠点資金・ヘッダーの金とは別で、初回に100を支給する仮設定。正式な経済/在庫連携は今後の仕様調整対象。

## 依頼

| 依頼 | 条件（テスト用仮値） | 金報酬 |
| --- | --- | --- |
| 鍛冶用の鉱石 | 鉱石3個を納品 | 30 |
| 宝石の納品 | 宝石1個を納品 | 40 |
| 洞窟の生物を討伐 | 受注後に3体討伐 | 40 |
| 住処の種族の討伐 | 1階の住処種族を受注後に2体討伐 | 30 |
| 地下3階へ到達 | 3階への到達記録 | 50 |

- 複数依頼を並行受注できる。納品は報酬受取と同時に運搬品から必要量を消費する。
- 討伐は所属プレイヤーの実際の戦闘ログから、敵の生存HP→死亡と実状態の死亡を確認して計上する。友軍被害や他勢力の討伐は計上しない。ワールドID+敵IDで二重計上を防ぐ。
- 詳細を見るだけでは受注しない。「受注」ボタンで進捗を0から開始する。討伐と階層到達は受注後の行動のみ計上し、受注前の最高到達階層は依頼達成に使わない。納品は受注後の所持数を表示し、既に携帯している資源も納品できる。
- 一覧と詳細に未受注/受注中/報告可能/受領済みと進捗を表示する。報酬は1階の鍛冶師へ戻って受け取る。各依頼の報酬は1回限り。
- 数値は `frontend/src/lib/v39-gameplay-balance.js` の `V39_CAVE_EVENT_BALANCE`。JSONにないテストの仮定義として分離し、生成JSONへ独自の行・列を追加しない。

## 保存と実装境界

- NPCはマップの `caveEventNpc` に保存する。再訪時は保存済みのNPCを使用する。
- 勢力の `caveEvents[洞窟シード]` に携帯金、受注/進捗/受領状態、計上済み討伐ID、最高到達階層を保持する。ロードで初期支給・報酬を再付与しない。
- 購入/製作武器と材料は既存の部隊運搬品に保存する。装備後は通常のユニット装備データになる。
- これは洞窟テスト用イベント機能であり、一般村イベントJSONの正式な共通イベントエンジンへの接続を完了したとは扱わない。イベントの正式なシート格納・価格・生産時間・品質/商品更新・依頼追加条件は後続作業。
