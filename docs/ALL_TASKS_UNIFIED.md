同時操作の競合はホスト／サーバーへの受信順を先着順とし、後着命令は更新後の状態で再判定する。

- [ ] 個体の運搬上限を `基本運搬量 × SIZ補正`、部隊上限を個体上限合計とし、満載時は所属巣への帰還を優先する
- [ ] 通常消費換算2ターン未満で人口-1%/T、1ターン未満で人口-2%/Tかつ自然HP回復停止、0.5ターン未満で人口-5%/TかつHP以外のステータス・技能値15%低下 + AP100から80、食料0で最大HP5%/Tの飢餓ダメージを適用する
- [ ] 食料状態改善後は各ペナルティを即時全解除せず、1ターンごとに1段階ずつ正常側へ回復させる
- [ ] 人口減少とフィールド上の既存ユニット数を別管理し、人口減少だけで既存ユニットを直接削除しない
- [ ] 巣の人口増加をプレイヤー拠点側の人口増加ルールと共通化する
- [ ] 巣のユニット生成条件・コストをプレイヤー側と共通化し、その巣に設定されたモンスター種だけを生成する
- [ ] 新規個体は巣マスを優先し、占有時は周囲1マスへ出し、全て埋まっていれば巣内で出現待ちにして空き発生時に出現させる
- [ ] 巣の人口・所属個体数増加に応じ、縄張り拡張1段階ごとに外周を1マス追加して半径+1する
- [ ] 縄張りが衝突した敵対巣同士を通常戦闘させ、同種の敗者巣は勝者巣へ吸収する
- [ ] 巣破壊時は物資を回収可能な戦利品にし、生存所属ユニットはそのまま残して巣なし個体へ移行し、その他の巣状態を消滅させる
- [ ] 新しい巣の作成条件・コストをプレイヤー側の拠点新設ルールを基準に共通化する
- [ ] 探索情報、探索役状態、巣食料状態、食料不足段階、回復段階、出現待ち個体、縄張り、所属関係をセーブ/ロードで保持する

目標は、最低5～10ターン自律して破綻せず行動できること。
