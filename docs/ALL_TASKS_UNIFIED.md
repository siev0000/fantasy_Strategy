### Task 2.5: 居住地攻撃システム
- **状態**: 🔴 未着手
- **優先度**: 🟠 中
- **説明**: 村・町・都市への攻撃時の防御・ダメージシステム
- **完了条件**:
  - [ ] 居住地の段階（村/町/都市）に応じたボーナスを実装
  - [ ] 物資不足時に居住地HPが減少する
  - [ ] 物資で居住地HPを回復できるようにする
  - [ ] 領土の「回復量」が自領土内ユニットのHP回復に反映される
- **仕様**:
  - 居住地HP = 基本値 × (1 + 規模倍率)
  - 攻撃時ダメージ = 敵攻撃力 × 規模補正
  - 物資回復: 食料 100 消費 = HP +50

    - 各領土が「回復量」ステータスを持つ（基本値: +5/ターン）
    - 自領土内のユニットは毎ターン「回復量」分のHP回復
    - 薬草群生地発見で +10/ターン
    - 医療施設構築で +20/ターン
  - 物資不足時のペナルティ: HP -10/ターン
- **依存タスク**: Task 2.1（遭遇システム）, Task 2.6（探索）, Task 2.8（施設効果）

  - 木材（通常木・黒木・特木）
  - 金属（鉄・銀鉄・青金鋼・赤黒鋼）
  - 貴金属（金・銀）
  - 宝石
- **領土ステータス**:
  - **回復量** (新規追加)
    - 基本値: +5/ターン
    - 自領土内のユニットが毎ターンこの値分HP回復
    - 薬草群生地発見で +10/ターン
    - 医療施設構築で +20/ターン
    - 合計で最大 +60/ターン（複数ボーナス重複可）
- **特別地形発見による効果**:
  - 薬草群生地: 領土回復量 +10/ターン
  - 金山: 貴金属産出 +50/ターン
  - 銀鉱脈: 貴金属産出 +30/ターン
  - その他レア地形は要定義
- **物資不足時のペナルティ**:
  - 食料不足: 人口 -1/ターン、治安 -2
  - 建設資源不足: 建設速度 -50%
- **物資消費による領土回復**:
  - 食料 100 消費 = 居住地HP +50（即座回復）
